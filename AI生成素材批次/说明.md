# AI生成素材批次归档说明

此目录用于保存每个批次 AI 生成素材的归档副本，批次目录名与 `docs/02_竖切版本/竖切美术资源生产指南.md` 中的批次标题保持一致。

- `Batch01A_VN风格小样生产包`：VN 基础背景与 neutral 立绘锚点。
- `Batch01B_VN当前可见表情与场景生产包`：当前竖切可见 VN 背景与表情差分。
- `Batch02_VN_UI高清皮肤生产包`：VN 对话层 UI atlas 和面板素材。
- `Batch09_SideCombat动作与特效视频生产包`：用参考图先生成固定机位动作/VFX 视频，再抽帧、清理 alpha 并拼接运行时帧序列；完整规则见该批次目录内的 Markdown 文档。

运行时正式资源仍保留在 `WheatearEditor/assets/vertical_slice/` 下；此目录只做批次归档和追溯，不作为游戏运行时引用路径。
