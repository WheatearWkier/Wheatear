# 《Wheatear 异世界项目》关卡与副本策划方案 v0.2

## 0. 文档定位

本文档负责把总纲中的章节、战斗系统、敌人机制和养成循环落到“可制作、可配置、可测试”的关卡与副本结构上。

它不替代以下文档：

- [游戏企划总纲](../总纲/游戏企划总纲.md)：负责世界观、人物、主线剧情和系统总览。
- [战斗系统设计](../系统设计/战斗系统设计.md)：负责横板战斗规则、技能树、连招、断限追击和数值公式。
- [敌人与Boss机制表](../系统设计/敌人与Boss机制表.md)：负责小怪、精英怪、Boss、圣兽、七大罪和国师的机制。
- [引擎架构说明](../引擎架构/引擎架构说明.md)：负责引擎层级、模块边界和可扩展原则。

本文档的核心用途：

- 给剧情策划确认每章进入哪些副本。
- 给战斗策划确认每个副本教什么机制。
- 给关卡设计确认房间、波次、敌人组合和 Boss 节奏。
- 给程序确认未来编辑器里需要哪些数据字段。
- 给资源整理确认每个副本应该打包哪些素材，而不是粗暴搬运全部资源。

架构边界：

- 第一章假玩法继续归现有 `ArcadeCombat` 模块，只承担剧情误导和笑点。
- 第二章开始的正式横板战斗归未来 `SideCombat` 模块。
- 视觉小说、据点 UI、路线选择和战斗副本之间通过剧情标记、场景跳转和副本结果数据连接。
- 副本、敌人、掉落、评分、解锁条件都应尽量数据化，后续由 Wheatear 编辑器配置。

## 1. 文档回顾结论

### 1.1 总纲结论

现有总纲已经确定游戏的主体验是：

`剧情对话 -> 做选择 -> 提升好感度 / 获得线索 -> 进入据点 UI -> 强化角色 / 装备 / 魔剑 / 支援 -> 选择继续剧情或刷副本 -> 进入战斗 -> 获得经验、装备、材料、剧情变量 -> 回到剧情或据点`

所以副本不是孤立的战斗地图，而是剧情、养成和战斗之间的中转器。每个副本都必须回答五个问题：

- 为什么现在必须打这个副本。
- 这个副本教玩家什么战斗能力。
- 这个副本给玩家什么材料、装备、经验或好感推进。
- 玩家打完后回到哪里。
- 这个副本后续是否值得重刷。

### 1.2 战斗结论

现有战斗文档已经明确：

- 核心爽点是空中连击。
- 断限追击是高手玩法，不是通关门槛。
- 普通玩家应该能靠读招、闪避、防御、支援和短连招稳定通关。
- 跳跃不只是躲避按钮，也是一段空中攻击入口；第二章就要教玩家跳起来按 `J` 进行跳斩续空。
- 每一个主动攻击和支援攻击都要有连招接口。
- 技能树五个分支都要服务连招、破防、生存、支援或资源循环。

因此关卡设计不能只堆敌人血量。每个房间都要给玩家一个明确练习点，例如：

- 用上挑把敌人带入空中。
- 用跳跃躲远程。
- 用跳斩维持浮空，让玩家感到“空中还能继续打”。
- 用白魔法续航。
- 用剑盾支援保护断限失败。
- 用黑魔法破防或压制 Boss 保护条。
- 用青龙机动、白虎破甲、朱雀爆发、玄武防守、天使复活处理对应试炼。

### 1.3 敌人结论

敌人与 Boss 文档已经把敌人分成小怪、中型怪、远程、盾怪、法师、支援怪、精英、章节 Boss、圣兽、七大罪和国师。

关卡设计要按“教学 -> 混合 -> 压力 -> Boss 检查”的顺序使用这些敌人：

- 第一次出现某个敌人时，只搭配低压力环境。
- 第二次出现时，和另一类敌人混编。
- 第三次出现时，加入地形、机关或精英怪形成压力。
- Boss 战检查玩家是否理解本章核心机制，但不强制高级断限。

### 1.4 当前阶段取舍

完整游戏可以先规划 16 章，但制作顺序应该先做竖切版：

- 序章 VN。
- 第一章假玩法。
- 第二章正式横板新手教程。
- 据点 UI。
- 一个可重刷材料副本。
- 一个带 Boss、掉落、结算、回到据点的完整循环。

等这条链路跑通，再扩展后续章节。

## 2. 总体关卡原则

### 2.1 副本长度

主线副本首通长度建议：

| 副本阶段 | 首通时长 | 熟练重刷时长 |
| --- | --- | --- |
| 新手副本 | 5-8 分钟 | 3-5 分钟 |
| 普通主线 | 8-12 分钟 | 4-7 分钟 |
| 章节 Boss 副本 | 10-15 分钟 | 5-8 分钟 |
| 圣兽试炼 | 12-18 分钟 | 6-10 分钟 |
| 七大罪战场 | 15-22 分钟 | 8-12 分钟 |
| 最终国师战 | 20-30 分钟 | 不以重刷为核心 |

设计理由：

- Galgame 玩家不一定愿意一次战斗太久。
- 横板动作玩家需要足够空间练连招。
- 可重刷副本必须短，否则刷材料会疲劳。
- 主线副本可以稍长，但中途要有房间分段和检查点。

### 2.2 副本节奏

标准主线副本采用五段式：

1. 入场剧情：解释目标，放置本章角色互动。
2. 低压教学：只出现一种新敌人或新机制。
3. 混合战斗：旧敌人与新敌人组合。
4. 精英检查：用一个精英怪确认玩家理解机制。
5. Boss / 剧情收束：完成章节情绪和系统解锁。

可刷副本采用三段式：

1. 快速入场。
2. 随机或半随机 2-4 个战斗房间。
3. 精英或小 Boss 结算。

试炼副本采用四段式：

1. 机制展示。
2. 机制压力。
3. 角色关系剧情。
4. 圣兽或特殊 Boss 检查。

### 2.3 难度原则

普通通关线：

- 不要求断限追击。
- 不要求长时间空中无限连。
- 不要求完美装备。
- 允许玩家通过升级、装备强化和支援技能补足操作。

高手奖励线：

- 断限追击给更高评分、更多奥义槽、额外材料概率和更短击杀时间。
- 高连击能提升评价，但不能成为剧情通关门槛。
- Boss 保护条不能让普通玩家觉得“打不到”，也不能让高手无限压制没有代价。

失败原则：

- 主线失败后允许从最近检查点或 Boss 前重试。
- 失败不扣除关键剧情资源。
- 可刷副本失败不给完整掉落，但可保留少量经验，降低挫败感。
- 教程副本失败时应给更清晰提示，而不是直接惩罚。

## 3. 副本类型

| 类型 | 用途 | 是否可重刷 | 典型奖励 |
| --- | --- | --- | --- |
| 剧情副本 | 推进主线，首次展示场景和敌人 | 通关后可解锁回放版 | 首通材料、剧情变量、角色加入 |
| 教程副本 | 教新系统、新技能、新敌人 | 可重刷但奖励低 | 基础材料、教学成就 |
| 材料副本 | 刷装备和技能材料 | 是 | 指定材料、装备、经验 |
| 好感事件副本 | 和某位队友绑定的小规模战斗 | 部分可重刷 | 好感、支援等级、专属材料 |
| 圣兽试炼 | 解锁四圣兽祝福 | 是，但首通奖励唯一 | 圣兽祝福、对应角色大幅好感 |
| Boss 复战 | 给高手练连招和刷稀有掉落 | 是 | Boss 材料、稀有装备词条 |
| 七大罪战场 | 后期大型机制战 | 通关后可挑战高难 | 高级装备、满好感推进 |
| 逃亡事件副本 | 以剧情压迫和限制条件为核心 | 通常不可重刷 | 剧情变量、据点转移 |

## 5. 据点 UI 与副本入口

每段主线结束后，玩家进入据点 UI。它不是大地图，而是章节间功能界面。

基础入口：

- 继续剧情：进入下一段 VN 或主线副本。
- 副本选择：重刷已解锁副本。
- 魔剑技能树：消耗材料、等级和好感条件解锁技能。
- 装备强化：消耗材料强化武器、防具、饰品。
- 队友关系：查看好感事件和支援技能等级。
- 队伍支援：配置战斗中可用的队友头像和技能。
- 路线确认：查看当前主线目标和未完成事件。
- 图鉴资料：敌人、材料、剧情回放。

据点 UI 的副本按钮应显示：

- 副本名称。
- 推荐等级。
- 主要掉落。
- 本次能否获得首通奖励。
- 推荐支援角色。
- 该副本训练的核心技巧。
- 当前可获得的关键材料是否足够升级某个技能。

设计重点：

- 玩家不要为了升级技能去猜材料从哪里来。
- 材料副本入口要直接标明“可产出哪些技能需要的材料”。
- 好感度提升给支援升级，不消耗材料，避免恋爱线变成刷材料。
- 魔剑技能可以要求好感门槛，但好感门槛应来自剧情和队友事件。

## 7. 重点副本详案

### 7.1 CH02_MAIN_BearAwakening：魔剑觉醒

定位：

- 正式横板战斗第一关。
- 从第一章假玩法的粗糙感切换到真正战斗手感。
- 教玩家“本游戏的战斗核心不是站桩砍，而是上挑、跳跃后空中普攻、空中追击和支援衔接”。

房间结构：

| 房间 | 类型 | 内容 | 教学点 |
| --- | --- | --- | --- |
| R0 | 剧情 | 黑熊母熊追击，真青梅伪装成魔剑士导师登场 | 交付魔剑 |
| R1 | 教学 | 平地小型魔物 3-4 只 | 移动、普攻三段、受击反馈 |
| R2 | 教学 | 低速远程敌人 2 只 + 近战敌人 2 只 | 一段跳躲远程、闪避穿插 |
| R3 | 教学 | 黑熊母熊残战 | 上挑、跳斩、火球补 hit |
| R4 | 剧情 | 魔剑自动吸收材料，黑熊丈夫登场 | 掉落吸收、Boss 预告 |
| R5 | Boss | 黑熊丈夫三阶段 | 读招、短空连、第一次 Boss 破防 |
| R6 | 结算 | 回到据点雏形 | 技能树、材料、重刷入口 |

关键演出：

- 主角一开始握剑很慌，只会平 A。
- 黑熊母熊死后材料靠近魔剑并被自动吸收。
- 黑熊丈夫登场时，导师用冷静语气指导主角，偶尔暴露青梅才知道的小习惯。
- Boss 结束后打开第一个魔剑技能树节点。

普通打法：

- 闪避黑熊冲撞。
- 普攻三段后接上挑。
- 跳斩 1-2 hit 后落地。
- 火球术补尾刀。

高手打法：

- 完美闪避冲撞后反击。
- 上挑后跳斩延迟落地。
- 利用火球保持 hit，不追求断限。

### 7.2 CH03_MAIN_BorderVillage：边境村救援

定位：

- 第一个正式队友加入章节。
- 让玩家理解“好感度和战斗不是分开的”。
- 白魔法队友提供治疗、护盾和支援续连，但不替玩家打完战斗。

房间结构：

| 房间 | 类型 | 内容 | 教学点 |
| --- | --- | --- | --- |
| R0 | VN 入场 | 村庄受袭，白魔法少女被依赖又被忌惮 | 角色矛盾 |
| R1 | 战斗 | 小魔物 + 弓箭魔物 | 跳跃躲远程 |
| R2 | 支援教学 | 白魔法少女临时支援 | 治疗、护盾、支援 CD |
| R3 | 混合战斗 | 弓箭魔物 + 冲撞敌人 | 护盾保护起手 |
| R4 | 精英 | 荆棘树卫 | 清支援目标、火焰技能 |
| R5 | Boss | 变异树妖 | 续航、清召唤物、核心破防 |
| R6 | 结算 | 白魔法队友加入 | 好感度和支援等级解锁 |

普通打法：

- 先清远程。
- 使用白魔法护盾抵消失误。
- 等树妖核心暴露后短连输出。

高手打法：

- 用护盾抗小伤保持连击。
- 火球和空中追斩同时压树妖核心。
- 在召唤枝条出现时用范围技能顺带清场。

### 7.3 CH07_MAIN_PalaceAssault：进攻王宫

定位：

- 第一部系统成熟点。
- 正式解锁断限追击。
- 玩家第一次面对“两个 Boss 串联 + 王宫机制装置”的大型主线副本。

房间结构：

| 房间 | 类型 | 内容 | 教学点 |
| --- | --- | --- | --- |
| R0 | VN 入场 | 队伍准备攻入王宫，假青梅线索加深 | 情绪推进 |
| R1 | 战斗 | 禁卫军阵型 | 阵型拆解、剑盾支援 |
| R2 | 机关 | 反魔法装置 + 宫廷法师 | 目标优先级 |
| R3 | 精英 | 圣骑士精英 | 破甲、防御、反击 |
| R4 | Boss 1 | 骑士团长 | 多阶段、断限窗口 |
| R5 | 剧情过场 | 王宫青梅表现出傀儡感 | 反转铺垫 |
| R6 | Boss 2 | 国王傀儡 | 支援组合、装置清理 |
| R7 | 结算 | 王宫真相推进 | 高阶技能树、空界连锁前置 |

断限设计：

- 骑士团长第一次进入保护临界时，导师提示“不要让他落地”。
- 系统只要求玩家看见断限窗口，不强制成功。
- 成功断限给明显演出、额外评分和少量材料加成。
- 失败后 Boss 落地恢复，但不会导致必死。

普通打法：

- 拆反魔法装置。
- 清宫廷法师。
- Boss 保护后等落地重新立回。

高手打法：

- 骑士团长保护临界时触发断限。
- 用黑魔法压保护条，用剑盾防断限失败反击。
- 打出第一轮空中长连。

### 7.4 ACT1_FINAL_TrueSweetheartDuel：真青梅与最终魔剑士对决

定位：

- 第一部情绪和战斗的顶点。
- 主角不是说服青梅，而是用她亲手交出的魔剑和她亲手教出的魔剑术击败她。
- 战斗胜利代表主角夺回关系主动权，也代表青梅从操控者变成承认错误、依赖主角的正宫。

房间结构：

| 房间 | 类型 | 内容 | 教学点 |
| --- | --- | --- | --- |
| R0 | VN 入场 | 导师揭示真青梅身份 | 真相爆发 |
| R1 | 战斗 | 记忆傀儡 | 回顾现实世界伏笔 |
| R2 | 战斗 | 魔剑幻影 | 检查第一部技能 |
| R3 | 机关 | 傀儡锁链与控制装置 | 位移、破装置 |
| R4 | Boss | 真青梅 | 空中对决、断限、全支援 |
| R5 | 结算 | 青梅屈服，关系重塑 | 青梅正宫支援 |

Boss 阶段：

| 阶段 | HP | 机制 | 情绪 |
| --- | --- | --- | --- |
| P1 | 100%-70% | 模仿主角基础魔剑技 | 冷静、自信 |
| P2 | 70%-40% | 召唤记忆傀儡和锁链 | 执念暴露 |
| P3 | 40%-15% | 空中高速对决，频繁断限窗口 | 不甘与崩溃 |
| P4 | 15%-0% | 防线破碎，攻击变急躁但破绽变大 | 被主角正面压倒 |

普通打法：

- 读招闪避。
- 利用短空连和支援技能打稳定输出。
- 不强制连续断限。

高手打法：

- 利用青梅给出的断限窗口打空界连锁。
- 用青梅自己的招式镜像节奏反制她。
- 以高评分结束第一部。

### 7.5 ACT2_ESCAPE_RoyalCollapse：王宫崩落逃亡

定位：

- 第一部结束后的大反转。
- 玩家以为已经进入后宫结局，国师突然真正发动。
- 重点不是击杀 Boss，而是让玩家意识到国师比之前所有敌人都更危险。

房间结构：

| 房间 | 类型 | 内容 | 教学点 |
| --- | --- | --- | --- |
| R0 | 剧情 | 国师刺杀国王，借敌人之口揭示青梅洗脑真相 | 反转 |
| R1 | 逃亡 | 王宫崩塌，保护青梅和王妃 | 限制条件 |
| R2 | 生存 | 受控士兵与召唤物不断刷新 | 不恋战、清路 |
| R3 | 压迫演出 | 国师远程改写战场 | 展示威胁 |
| R4 | 结算 | 逃出王宫，建立第二部据点 | 圣兽祝福目标 |

失败条件：

- 主角死亡。
- 保护目标被击倒。
- 倒计时结束仍未到达出口。

设计重点：

- 国师此时不让玩家打赢。
- 他通过台词、战场改写、召唤和控制展示“之前一直在示弱”。
- 青梅洗脑真相由国师嘲讽和魔法残响揭示，不靠青梅主动坦白。

### 7.6 CH12_MAIN_AngelAwakening：天使祝福与魔剑完全觉醒

定位：

- 王妃身份不是主动坦白，而是被敌方法阵和天使记忆试炼揭示。
- 魔剑完全觉醒后必须给玩家一个试刀 Boss。
- 天使祝福提供战斗内额外生命，作为最终战前的关键容错。

| 房间 | 类型 | 内容 | 教学点 |

| R1 | 战斗 | 追兵 + 圣性法阵 | 保护王妃、破法阵 |

- 高手可以在这里完整测试空界连锁、五祝福融合和终极支援。

普通打法：

- 天使净化破盾。
- 短空连输出。
- 触发复活后继续战斗。

- 满级魔剑技能轮转。
- 用断限追击长时间滞空。

## 8. 掉落与经济

### 8.1 掉落分层

| 层级 | 来源 | 用途 |
| --- | --- | --- |
| 普通材料 | 小怪、材料副本 | 装备基础强化、T0/T1 技能 |
| 精英材料 | 精英怪、材料副本末尾 | T1/T2 技能、装备词条解锁 |
| Boss 材料 | 章节 Boss、Boss 复战 | 关键技能、装备突破 |
| 圣兽材料 | 四圣兽试炼和对应材料副本 | 祝福分支技能 |
| 天使材料 | 第十二章和圣堂回响 | 最终技能、复活相关装备 |
| 七罪材料 | 后期战场 | 最终装备和特殊词条 |

### 8.2 掉落原则

- 首通必须给关键材料，避免玩家卡主线技能。
- 重刷副本给随机材料和装备词条，承担养成深度。
- Boss 复战给稀有材料，但不能强迫玩家刷很多次才能推进主线。
- 不同技能需要不同材料组合，让玩家有路线规划。
- 好感度负责支援技能升级，不消耗刷本材料。

### 8.3 材料与技能绑定

| 技能方向 | 主要材料来源 | 设计目的 |

| 剑盾联动 | 要塞撤离线、破碎要塞 | 防御、反击、失败保护 |
| 黑魔法联动 | 封锁废墟、咒书残库 | 破防、减益、保护条压制 |
| 青龙祝福 | 青龙试炼、风雷遗迹 | 追击、空中机动 |
| 白虎祝福 | 白虎试炼、铁裂谷 | 破甲、压制 |
| 朱雀祝福 | 朱雀试炼、灰烬花园 | 爆发、复燃 |
| 玄武祝福 | 玄武试炼、地脉堡垒 | 防御、霸体 |
| 天使祝福 | 天使觉醒、圣堂回响 | 复活、净化、最终容错 |

### 8.4 评分奖励

副本评分建议采用 S / A / B / C。

评分项：

- 通关时间。
- 受击次数。
- 最大连击数。
- 是否使用推荐技能或支援。
- 是否触发断限追击。
- 是否完成副目标。
- 是否保护目标。

注意：

- 支援使用不应被惩罚，因为队友支援是游戏核心。
- 断限追击只提供加分和额外掉落概率，不作为 S 评价的唯一条件。
- 新手副本评分要求宽松，避免玩家刚入门就被评价打击。
- 后期 Boss 复战可以给高手更严苛的评分挑战。

## 10. 竖切版本建议

为了真正能在 Wheatear 编辑器里做出游戏，建议第一个可玩竖切只做以下内容：

### 10.1 必做内容

- 主菜单。
- 序章 VN。
- 第一章假玩法。
- 第二章正式横板教程。
- 据点 UI。
- 魔剑基础技能树 6-8 个节点。
- 白板装备 3-5 件。
- 一个可重刷材料副本：`CH02_MAT_BeastPath`。
- 一个 Boss：黑熊丈夫。
- 完整掉落、结算、升级、回到据点、继续剧情。

### 10.2 竖切验收标准

玩家应该能完成以下流程：

1. 从主菜单进入新游戏。
2. 看完序章 VN。
3. 进入第一章假玩法并被剧情吐槽。
4. 进入第二章正式横板教程。
5. 获得魔剑并打赢黑熊丈夫。
6. 回到据点 UI。
7. 用材料解锁或升级一个技能。
8. 重刷黑林兽道获得材料和装备。
9. 回到据点继续强化。
10. 进入下一段剧情入口。

这条链路打通后，游戏就不再只是 demo，而是拥有完整产品骨架。

### 10.3 竖切暂不做内容

- 全部后宫路线。
- 全 60 个魔剑技能。
- 全部圣兽章节。
- 七大罪最终战。
- 完整装备词条库。
- 复杂随机地图。

这些可以在核心循环稳定后扩展。

## 11. 编辑器落地建议

### 11.1 副本面板

未来 WheatearEditor 可以增加 `Dungeon` 面板：

- 左侧：副本列表和筛选。
- 中部：副本基础信息、章节、入口场景、出口场景。
- 右侧：房间序列、敌人组合、奖励表、剧情标记。
- 底部：引用资源检查、打包资源预览、数据校验结果。

### 11.2 关卡房间编辑

房间可以先不做复杂可视化地图编辑器，第一版只做数据驱动：

- 选择房间布局。
- 配置敌人波次。
- 配置触发器。
- 配置清场条件。
- 配置入场和通关脚本。

等 SideCombat 稳定后，再做可视化摆放。

### 11.3 打包资源关联

每个副本都应维护 `PackageAssetTags`：

- 场景资源。
- 背景图。
- 角色立绘。
- 战斗 Sprite。
- 敌人 Sprite。
- 音效。
- 音乐。
- 粒子材质。
- UI 图标。
- 掉落图标。

打包时从入口场景、剧情跳转、副本定义、敌人定义、掉落表和 UI 引用递归收集资源，最终写入 `.wtpack`。这样不会把整个 `assets` 目录粗暴搬到 Build 目录。

### 11.4 数据校验

编辑器保存副本时应检查：

- `DungeonId` 是否唯一。
- 入口场景是否存在。
- 出口场景是否存在。
- 所有敌人 ID 是否存在。
- Boss ID 是否存在。
- 掉落表是否存在。
- 首通奖励是否包含关键剧情材料。
- 可重刷副本是否配置重刷奖励。
- `PackageAssetTags` 是否能解析到真实资源。
- 推荐等级是否小于下一章主线推荐等级。
- 本章新增技能是否至少有一个副本能产出对应材料。
