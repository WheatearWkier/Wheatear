# 编辑器模块内容编辑流程

更新时间：2026-07-29

本文记录 WheatearEditor 当前针对游戏模块内容的编辑方式，目标是让策划和程序都能直接在编辑器里微调竖切内容，而不是只能靠代码生成场景文件。

## VN 模块

- 在场景中选中带有 `VisualNovelComponent` 的实体。
- 右侧 `Properties` 面板会显示 `Visual Novel` 组件。
- `Script Path` 用来指定 `.vn` 剧本文本资源。
- `VN Script Editor` 会直接读取这个脚本文件，可以从顶部 `View / VN Script Editor` 打开，也可以在组件面板点击 `Open VN Script Editor` 打开当前脚本。
- `Timeline` 页签用于按行管理剧情流程：台词、角色登场、背景、BGM、选择项、标签、跳转、结束命令都能在右侧编辑区改。
- `Characters / BGM` 页签用于集中检查人物命令和音乐切换命令，适合快速维护角色、表情、BGM 插入点。
- 修改对话文本、人物、表情、BGM、跳转命令、选择项后，点击 `Save` 会写回脚本文件。
- 点击 `Reload` 可以放弃当前面板文本，重新从磁盘读取。

VN 脚本支持 `@music <path> "<display name>"` 或 `@bgm <path> "<display name>"`，运行时会切换循环 BGM，并在左上角弹出音乐名提示。当前实现是时间线表格式编辑，适合快速改台词和流程；后续可以继续升级为节点式 VN 编辑器。

## 横板战斗模块

- 在场景中选中带有 `SideCombatLevelComponent` 的实体。
- 右侧 `Properties` 面板会显示 `Side Combat Level` 组件。
- 常用场景参数，例如场地范围、地面高度、结算跳转命令，可以直接在组件字段里改。
- `Tuning Path` 用来指定战斗调参 YAML。
- 点击 `Open Side Combat Tuning Editor`，或者从顶部 `View / Side Combat Tuning Editor` 打开独立调参窗口。
- `Feel` 页签用于高频手感参数：移动、跳跃、重力、滞空、上挑、空中普攻、空中追击、断限追击。
- `Rules` 页签用于战斗规则：连击掉落、受击无敌、伤害公式、音量反馈、Boss 保护槽、敌人 AI、拾取物、纵深移动和阴影。
- `Attacks` 页签用于逐个招式编辑 hitbox、伤害、前摇、后摇、取消窗口、击飞、滞空、保护槽增长、特效帧和音效。
- `Skills` 和 `Progression` 页签用于维护技能显示、输入、招式绑定、章节解锁和不同关卡 profile 的可见系统。
- 修改后点击 `Save` 会写回同一个 `side_combat_tuning.yaml`。
- 需要精修 YAML 时，可以展开 Inspector 里的 `Raw Side Combat Tuning YAML` 作为文本级兜底。

当前实现是“专用调参面板 + YAML 兜底编辑”。YAML 仍是运行时唯一数据源，避免面板数据和运行数据分裂。

## 事件脚本模块

- 在场景中创建一个流程控制实体，例如 `FlowController`。
- 右侧 `Properties` 点击 `Add Component / Scripting & Audio / Event Script`。
- `Script Path` 指向 `.wts` 文件，例如 `assets/events/vertical_slice_flow_sample.wts`。
- `Start Event` 填默认启动事件名，通常是 `on_start`。
- `Run On Start` 表示场景运行时自动执行该事件；如果只想由按钮或剧情触发，可以取消勾选。
- `Run Once` 表示同一组件生命周期内只执行一次，适合一次性剧情事件。
- 组件下方内置 `.wts` 文本编辑器，可以直接修改并保存脚本。
- UI 按钮可以通过 `event:open_skill_tree` 触发当前场景的流程事件；需要精确指定实体时使用 `event:@<UUID>:open_skill_tree`。

`.wts` 只负责流程编排。大量战斗数值仍写在 `side_combat_tuning.yaml`，VN 台词仍写在 `.vn`，场景切换通过引擎 `SceneTransitionService` 请求，不直接依赖 `WheatearSandbox`。

## 层级选中同步

- 从 Scene Viewport 点选实体后，左侧 `Scene Hierarchy` 会自动滚动到对应实体。
- 对应行保持 ImGui 选中高亮。
- 如果当前搜索条件或 `UI` 过滤导致选中实体不可见，Hierarchy 会提示该实体被过滤隐藏，并提供清空过滤按钮。

## 直接打开编辑器

新增脚本：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\Build-WheatearEditor.ps1
```

脚本会构建 `WheatearEditor`，并复制输出到：

```text
Builds\Windows\Editor\WheatearEditor.exe
```

之后可以直接打开这个 exe，不需要每次从 Visual Studio 启动。
