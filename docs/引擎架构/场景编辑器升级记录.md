# 场景编辑器升级记录

更新时间：2026-07-29

本文记录 WheatearEditor 的本轮工业化升级方向和已落地内容。目标是让编辑器逐步从“能加载场景”升级为“能直接手调场景和 UI 的生产工具”。

## 本轮目标

- 解决旧版 Dear ImGui 接口过旧、控件能力不足、API 与源码混杂的问题。
- 让 UIWidgetComponent 可以在 Scene Viewport 中直接选中、移动和缩放。
- 改善 Scene Hierarchy 和 Inspector 的查找、分类、锚点、层级、布局预设等编辑体验。
- 为后续撤销重做、多选、对齐吸附、Prefab、UI 蓝图化打基础。

## 第三方库升级

- Dear ImGui：升级到官方 docking 分支 1.92.9。
- ImGuizmo：同步官方 master 新版源码。
- ImGui OpenGL/GLFW backend：从旧 examples 路径迁移到新版 backends 路径。
- ImGui 静态库构建：补入新版核心文件 imgui_tables.cpp。

升级原因：

- 旧版 imgui.h 标记为 1.79 WIP，但 imgui.cpp 中混有 docking/tables 代码，源码状态不干净。
- 旧版 API 缺少新版表格、Docking、输入事件和纹理接口能力。
- 新版 ImGui 明确移除了 GetKeyIndex、旧 ImageButton 纹理接口等旧写法，需要项目侧同步适配。

## 已落地编辑器能力

### 编辑器命令与撤销复原

- 新增通用 `CommandHistory`，支持 `Ctrl+Z` 撤销、`Ctrl+Y` / `Ctrl+Shift+Z` 复原。
- 创建、删除、复制实体进入撤销栈。
- Add Component、Remove Component、Reset Component 进入撤销栈。
- Inspector 常用字段修改进入撤销栈。
- Viewport Gizmo 移动、旋转、缩放结束后生成撤销记录。
- UI 控件拖动和缩放进入撤销栈。
- 文本 UI 在拖拽缩放时同步调整字号，并和 UI 尺寸变化合并为同一条撤销记录。

### 编辑器布局持久化

- ImGui 布局配置从运行目录迁移到 `%LOCALAPPDATA%/Wheatear/Wheatear Editor/imgui.ini`。
- 重新构建并覆盖 `Builds/Windows/Editor/WheatearEditor.exe` 后，用户自定义 Docking 布局不会重置。
- 构建脚本复制编辑器输出时会排除旧的 `imgui.ini`，避免把临时布局带入打包目录。
- 首次启动且没有已有 `imgui.ini` 时，编辑器会自动铺默认 Docking 布局。
- `View / Reset Window Layout` 可以主动恢复默认窗口布局。

### Viewport 相机归位

- Viewport 内双击左键会把编辑器相机对齐到场景 `Primary` Camera 的位置和朝向。
- 编辑器相机保持透视编辑投影，不继承运行时相机的正交投影，避免归位后继续拖动视窗时操作异常。
- 同步后 Scene Hierarchy 会选中对应 Camera 实体，使左侧高亮明确表示当前对齐的是哪台相机。
- `View / Focus Primary Camera` 提供同样的菜单操作。

### Scene Viewport UI 编辑

- 选中 UIWidgetComponent 后，Viewport 内显示 UI 边框。
- 可显示全部 UI 控件轮廓，方便检查层级和遮挡。
- 可点击 Viewport 内 UI 控件进行选中，按 SortOrder 从上到下命中。
- 可拖动 UI 控件主体移动位置。
- 可拖动八方向 handle 缩放 UI 控件。
- 支持 ParentEntity(UUID) 父控件坐标换算，子 UI 在父区域内按局部坐标编辑。
- 选中有 ParentEntity 的控件时显示父区域边界。
- Ctrl 拖拽时按细网格吸附，方便做像素级对齐。

### Scene Hierarchy

- 增加搜索框，能按实体名过滤。
- 增加 UI-only 过滤，适合专门调 UI 场景。
- 实体名前增加类型前缀：[UI]、[Camera]、[3D]、[2D]、[Entity]。
- 创建 UI 菜单新增 Canvas。
- 除 Canvas 外，其他 UI 控件只能在选中 Canvas 或 Canvas 子控件时创建，避免产生孤儿 UI。
- 创建 UI 控件时设置默认 SortOrder，减少新建后遮挡顺序混乱。

### Inspector UIWidget 编辑

- UIWidgetComponent 位置和尺寸改为更宽松的归一化编辑范围。
- 增加锚点九宫格，减少手填 Anchor 的成本。
- 增加常用布局预设：全屏、顶部栏、底部栏、左侧栏、右侧栏、居中面板。
- 增加微调按钮，方便小步移动。
- 增加 Bring Front / Send Back，快速调整 UI 层级。
- ParentEntity 对象槽支持选择和清空。

### UI Canvas 专属编辑视窗

- 选中 `UICanvasComponent` 后，Inspector 中提供 `Edit Canvas` 按钮。
- 新增 `UI Canvas Editor` 窗口，只显示 UI 画布，不显示场景世界物体。
- Canvas Editor 支持点击选择 UI、拖动移动、拖 handle 缩放。
- Canvas Editor 只显示当前 Canvas 下的子控件；选中某个子控件时，其所属 Canvas 会以高亮背景提示。
- `Use Selected Canvas` 支持从 Canvas 子控件反查所属 Canvas。
- 主 Viewport 可勾选 `Hide UI In Scene Viewport` 暂时隐藏 UI，方便编辑被 UI 挡住的场景物体。

### UI 父子层级显示

- 创建 UI 控件时，如果当前选中 Canvas 或 UI 父控件，会自动写入 `ParentEntity`。
- Scene Hierarchy 会按 `ParentEntity` 把子 UI 缩进显示到父 UI 下方。
- Canvas 默认展开，方便直接查看页面结构。
- 删除 UI 父节点时，右键删除会把子 UI 一起放入撤销操作，避免遗留不可见孤儿控件。

### 新版 ImGui API 适配

- GetKeyIndex 写法替换为 ImGui::IsKeyPressed(ImGuiKey_A)。
- ImageButton 全部适配新版显式 str_id + ImTextureRef 接口。
- ImTextureID 强转从旧 reinterpret_cast 改为整数句柄 static_cast。
- ImGuiViewport::GetWorkPos/GetWorkSize 改为 WorkPos/WorkSize 字段。
- 旧 ImGuiTreeNodeFlags_AllowItemOverlap 改为 ImGuiTreeNodeFlags_AllowOverlap。
- 旧 ImFont::FontSize 访问改为 ImGui::GetFrameHeight。

## 当前限制

- UI 编辑暂不支持多选、框选、对齐、等距分布。
- UI resize 当前按矩形编辑，未处理旋转后控件的真实旋转包围盒。
- UI 父子层级目前基于 `ParentEntity`，还不是完整的通用实体 Transform 父子系统。
- UI 父子层级暂不支持在 Hierarchy 中拖拽改父。
- Inspector 还没有属性改动脏标记、批量编辑、组件搜索。
- Viewport UI 编辑还没有独立工具栏，例如移动、缩放、锚点、吸附模式开关。

## 后续路线

1. 增加 UI 对齐工具：左对齐、右对齐、居中、顶部、底部、等距分布。
2. 增加多选和框选：可同时移动、缩放一组 UI 控件。
3. 增加 Hierarchy 拖拽改父：支持 UI 节点拖到 Canvas 或其他 UI 节点下。
4. 增加 Inspector 属性表格化：常用字段固定、扩展字段折叠、长文本区域自动换行。
5. 增加保存提示和脏状态：场景未保存时显示标记，关闭/切换前提醒。
6. 增加 Prefab/模板控件：常用 UI 面板、按钮组、技能栏、背包格可复用。
7. 增加编辑器布局预设：程序、策划、UI、动画、关卡不同工作区。
8. 继续把 VN 和 Side Combat 的第一版专用编辑器升级为更完整的节点/表格工具，并补资源选择器、字段校验和批量编辑。
9. 继续扩展 UUID 对象槽覆盖面，把更多按钮、动画、玩法目标字段做成可选择实体的 Inspector 控件。
10. 继续评估第三方库升级迁移：每次升级前先确认 API 适配成本、构建产物变化和打包体积影响，升级后必须完成全工程构建与核心场景烟测。
