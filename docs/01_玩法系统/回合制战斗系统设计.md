# Wheatear 回合制战斗系统设计 v0.1

## 0. 定位

`TurnCombat` 是插在“类元气假玩法”和“2D 横板真玩法”之间的第三种玩法模块。它的目标不是替代正式横板战斗，而是提供一个节奏过渡：玩家先经历一个看起来更像传统 RPG 的战斗试炼，再进入真正的横板动作教程。

参考方向：
- 战斗站位参考《梦幻西游》式斜向站位：我方左下，敌方右上。
- UI 信息层级参考 Falcom《轨迹》系列：行动顺序、当前行动者、命令面板、技能说明、状态条分区明确。
- 角色技能幻想参考奥拉星/传统 RPG：技能有目标规则、MP 消耗、伤害/治疗/防御职责。

流程接入：
- `fake_combat_victory -> VerticalSliceTurnCombat.wt`
- `turn_combat_victory -> VerticalSlicePostFake.wt`
- `turn_combat_retry -> VerticalSliceTurnCombat.wt`

`TurnCombatSystem` 只负责回合制战斗内部逻辑，不直接知道后续剧情。胜利/失败通过 `VictorySceneCommand` / `DefeatSceneCommand` 发事件脚本命令，由 `vertical_slice_flow.wts` 决定跳转。

## 2. 当前玩法规则

当前竖切规则：
- 速度排序生成行动队列。
- 可控角色是主角，队友会自动行动，体现“队友支援力量”。
- 玩家点击底部命令选择技能，再点击场上目标。
- 技能支持单体敌人、单体友方、自身、敌方全体、友方全体。
- HP 为 0 后单位倒下并从行动有效目标中移除。
- 我方全灭失败，敌方全灭胜利。

当前技能：
- `slash`：无消耗单体斩击。
- `aether_edge`：消耗 MP 的魔剑单体重击。
- `white_vow`：单体治疗，预览白魔法队友定位。
- `shield_oath`：自身防御，减少本回合受到的伤害。
- `black_flare`：敌方全体黑魔法。
- `focus_wait`：等待并回复 MP。
- `claw / wild_pounce / dark_orb`：敌方基础攻击、强攻击、魔法攻击。

## 3. UI 规则

回合制 UI 采用“图标优先、文字辅助”的规则：
- 顶部显示当前行动者和行动顺序。
- 中部保留战斗场景和站位。
- 底部显示命令栏，命令用图标和短标签表达。
- 右侧/底部详情区显示当前技能说明。
- 目标选择通过场上目标标记和透明点击区域完成。

这套 UI 后续可以继续升级为：
- 行动顺序头像队列。
- 技能 hover tooltip。
- 技能冷却/MP 不足灰罩。
- 状态图标：防御、倒下、强化、弱化。
- 结算掉落图标化。

## 4. 表现

当前竖切已经接入：
- 像素角色站位素材。
- `idle / attack / hit / down` 角色序列帧，路径通过 `TurnCombatantComponent` 的帧模板字段配置。
- 技能图标。
- 目标标记。
- 行动特效图：斩击、魔剑、治疗、护盾、黑魔法、聚气、爪击。
- 运行时动画：状态切帧、行动者前冲、受击闪烁、全屏轻闪、场上特效缩放/旋转。
- BGM：`turn_battle_bgm.wav`
- 音效：斩击、命中、魔法、治疗、格挡/聚气。

后续若要提升打击感，可以把单张特效图升级为序列帧，并把 `TurnSkillDefinition` 中的 `EffectPath` 扩展为 `EffectFramePattern / FrameCount / FrameRate`。

## 5. 编辑器支持

Inspector 中可以添加和编辑：
- `TurnCombatLevelComponent`
- `TurnCombatantComponent`

可调字段包括：
- 胜负跳转命令。
- 行动时长、开场淡入、胜负等待时间。
- UI 绑定实体名。
- 单位 HP/MP/ATK/Magic/DEF/Speed。
- 单位队伍、槽位、是否玩家可控。
- 技能槽 ID。
- 状态条、目标按钮、目标标记绑定。
- 动画帧模板：`IdleFramePattern / AttackFramePattern / HitFramePattern / DownFramePattern`。
- 动画帧数和帧率。

后续可以继续加一个 `Turn Combat Tuning Editor`，把技能库从 C++ 内置表迁移到 YAML，这样策划可以直接编辑技能数值和目标规则。

## 6. 后续路线

短期：
- 把技能库外置成 `turn_combat_tuning.yaml`。
- 做技能 hover tooltip 和 MP 不足灰罩。
- 做敌方行动预告和行动顺序头像。
- 把自动队友行动扩展为可配置 AI 策略。

中期：
- 接入好感度：高好感队友提高技能倍率、降低 MP 消耗或追加效果。
- 接入装备属性：主角攻防魔速影响回合制数值。
- 接入掉落和结算：回合制也能给材料、经验和剧情变量。

长期：
- 可作为部分章节的特殊战斗：圣兽试炼、国师幻境、王宫棋盘战。
- 与横板战斗形成对比：回合制强调策略和队伍配合，横板强调操作和空连。
