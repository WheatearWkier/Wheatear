# 《Wheatear 异世界项目》装备系统与掉落词条表 v0.1

## 0. 文档定位

本文档负责定义装备、材料、掉落、词条、强化和刷本收益。

它承接以下既定规则：

- 魔剑是主角唯一核心武器，不被普通武器替代。
- 副本可以重刷，重刷价值来自材料、装备、评分和练连招。
- 好感度不靠刷材料提升，支援升级主要来自剧情选择、角色事件和主线推进。
- 断限追击是高手奖励，不是普通通关门槛。
- 装备要服务战斗风格，而不是只堆 ATK / DEF。

本文档服务未来正式 `SideCombat` 模块、据点 UI、背包系统、装备强化面板、掉落结算面板和打包资源收集。

## 1. 装备系统目标

装备系统要解决四件事：

- 让副本重刷有明确收益。
- 让不同玩家可以形成不同战斗风格。
- 让普通玩家通过装备获得容错，但不能绕过核心机制。
- 让高手玩家通过装备放大空连、断限、支援组合和评分收益。

装备不应该解决的事：

- 不用装备替代魔剑技能树。
- 不用装备让玩家跳过剧情好感门槛。
- 不用装备把断限追击变成无脑常驻。
- 不用装备制造“刷不到就不能通关”的硬卡点。

## 2. 装备槽位

初版建议保持槽位克制，避免系统太重。

| 槽位 | 是否掉落 | 主要作用 | 设计边界 |
| --- | --- | --- | --- |
| 魔剑 | 不掉落 | 主角核心武器、技能树、剧情成长 | 只能升级，不能替换 |
| 防具 | 掉落 | HP、DEF、MDEF、抗性、生存风格 | 不提供过高输出 |
| 饰品 1 | 掉落 | 资源、冷却、连击、支援辅助 | 可偏输出或机制 |
| 饰品 2 | 掉落 | 同上 | 第六章后开放第二槽 |
| 队友信物 | 剧情获得 | 角色事件、特殊支援、纪念道具 | 不作为刷本装备核心 |

阶段开放：

| 阶段 | 开放槽位 |
| --- | --- |
| 第二章 | 魔剑、防具、饰品 1 |
| 第四章 | 队友信物面板 |
| 第六章 | 饰品 2 |
| 第一部终章 | 青梅正宫信物 |
| 第十二章 | 王妃 / 天使信物 |

当前竖切实现备注：

- `Equipment.wt` 里先落地的是六个固定场景槽位：武器、防具、戒指、护符、足部、特殊。
- 武器槽显示名已经统一为 `武器`，不再写 `副武器`；`special` 仍显示为 `特殊`。
- 背包格由运行时装备数据分页生成，不在场景里预铺占位素材。

设计理由：

- 前期只给少量槽位，让玩家先学战斗。
- 中期开放第二饰品，让流派组合开始明显。
- 队友信物主要服务剧情和支援，不让它和刷装备系统混成一团。

## 3. 装备品质与阶段

### 3.1 品质

| 品质 | 颜色建议 | 主属性 | 副词条数 | 特殊效果 | 来源 |
| --- | --- | --- | --- | --- | --- |
| 普通 | 灰 | 1 | 0 | 无 | 小怪、商店、教程 |
| 优良 | 绿 | 1 | 1 | 无 | 小怪、材料副本 |
| 稀有 | 蓝 | 1 | 2 | 低概率 | 精英怪、副本结算 |
| 史诗 | 紫 | 1 | 3 | 有 | Boss、S 评价、圣兽试炼 |
| 圣遗 | 金 | 1 | 3-4 | 固有机制 | 圣兽、天使、七大罪 |
| 大罪 | 红 | 1 | 4 | 高风险高收益 | 七大罪挑战 |

品质原则：

- 普通和优良负责过渡，不需要复杂词条。
- 稀有开始让玩家能选择流派。
- 史诗和圣遗可以改变玩法节奏，但不能破坏基础规则。
- 大罪装备必须有代价，例如资源消耗提高、受击惩罚、异常风险等。

### 3.2 装备阶段

装备阶段和章节推荐等级绑定。

| 阶段 | 章节 | 装备等级范围 | 主要主题 |
| --- | --- | --- | --- |
| T0 | 第二章 | Lv 1-8 | 基础生存、短空连 |
| T1 | 第三-五章 | Lv 8-22 | 白魔法、剑盾、黑魔法支援 |
| T2 | 第六-七章 | Lv 22-32 | 破屏障、王宫、初级断限 |
| T3 | 第一部终章 | Lv 30-36 | 青梅、誓约、空界前置 |
| T4 | 第八-十一章 | Lv 36-48 | 四圣兽祝福 |
| T5 | 第十二章 | Lv 48-52 | 天使祝福、最终觉醒 |
| T6 | 第十三-十六章 | Lv 52-60 | 七大罪、国师最终战 |

装备等级只控制数值预算，不控制剧情解锁。剧情解锁仍然依赖章节标记和好感标记。

## 4. 属性体系

### 4.1 主属性

| 属性 | 用途 | 主要来源 |
| --- | --- | --- |
| HP | 生命上限 | 等级、防具 |
| MP | 魔法资源 | 等级、饰品 |
| SP | 剑技和闪避资源 | 等级、饰品 |
| ATK | 近战伤害 | 等级、魔剑 |
| MATK | 魔法伤害 | 等级、魔剑 |
| DEF | 物理防御 | 等级、防具 |
| MDEF | 魔法防御 | 等级、防具 |

### 4.2 副属性

| 副属性 | 作用 | 设计上限 |
| --- | --- | --- |
| 暴击率 | 提高爆发 | 普通装备总和不超过 25% |
| 暴击伤害 | 提高暴击收益 | 普通装备总和不超过 +60% |
| 冷却缩减 | 降低主动技能 CD | 总和软上限 20% |
| 支援冷却缩减 | 降低队友支援 CD | 总和软上限 18% |
| SP 回复 | 提高剑技循环 | 不允许无限闪避 |
| MP 回复 | 提高魔法循环 | 不允许无成本弹幕 |
| 魔剑槽获取 | 提高断限和奥义节奏 | 总和软上限 25% |
| 空中伤害 | 强化空连 | 只作用于空中命中 |
| 破甲效率 | 提高破防速度 | 对 Boss 有衰减 |
| 保护条压制 | 降低 Boss 保护增长 | 总和软上限 20% |
| 异常抗性 | 抵抗减速、封技、控制 | 后期关键 |
| 掉落加成 | 提升材料和装备掉落 | 不影响首通关键奖励 |

软上限说明：

- 超过软上限后继续生效，但收益按 50% 或更低折算。
- 这样允许玩家堆某个方向，但不会让一个词条打穿系统。

## 5. 数值预算

装备数值按预算生成，避免拍脑袋。

```text
ItemPowerBudget = (BaseBudgetByTier + ItemLevel * 4) * RarityRate * SlotWeight
```

建议参数：

| 参数 | 说明 | 建议 |
| --- | --- | --- |
| `BaseBudgetByTier` | 阶段基础预算 | T0=20, T1=45, T2=75, T3=95, T4=125, T5=150, T6=180 |
| `RarityRate` | 品质倍率 | 普通 1.00, 优良 1.12, 稀有 1.28, 史诗 1.45, 圣遗 1.65, 大罪 1.85 |
| `SlotWeight` | 槽位权重 | 防具 1.20, 饰品 0.85, 信物 0.60 |

属性换算建议：

| 属性 | 预算消耗 |
| --- | --- |
| HP +10 | 1 |
| MP +3 | 1 |
| SP +2 | 1 |
| DEF / MDEF +1 | 1.4 |
| 暴击率 +1% | 3 |
| 暴击伤害 +4% | 3 |
| 冷却缩减 +1% | 5 |
| 支援冷却缩减 +1% | 4 |
| 魔剑槽获取 +1% | 4 |
| 空中伤害 +1% | 3 |
| 保护条压制 +1% | 5 |
| 异常抗性 +1% | 2 |

设计要求：

- 防具的预算主要落在 HP、DEF、MDEF、抗性。
- 饰品的预算主要落在资源、冷却、连击、支援和特殊机制。
- 装备提供风格差异，魔剑和等级提供基本战力。

## 8. 掉落规则

### 8.1 掉落来源

| 来源 | 材料 | 装备 | 说明 |
| --- | --- | --- | --- |
| 小怪 | 常见材料小概率 | 普通 / 优良低概率 | 提供刷本底噪 |
| 中型怪 / 远程怪 | 常见材料中概率 | 优良低概率 | 对应敌人主题 |
| 支援怪 | 功能材料中概率 | 饰品低概率 | 鼓励优先击杀 |
| 精英怪 | 精英材料必掉 | 稀有中概率 | 副本重刷核心 |
| Boss | Boss 材料首通必掉 | 稀有 / 史诗高概率 | 章节奖励 |
| 圣兽 Boss | 圣兽材料首通必掉 | 圣遗概率 | 祝福装备 |
| 七大罪 Boss | 大罪残片必掉 | 大罪装备概率 | 后期挑战 |
| 副本结算 | 按评分给材料 | 按评分抽装备 | 统一结算体验 |

### 8.2 建议掉率

| 来源 | 装备掉率 | 稀有以上概率 | 备注 |
| --- | --- | --- | --- |
| 小怪 | 1%-3% | 极低 | 前期可更低 |
| 中型怪 | 3%-6% | 低 | 不刷屏 |
| 精英怪 | 20%-35% | 5%-12% | 刷本核心 |
| 主线 Boss 首通 | 100% | 30%-50% | 保证爽点 |
| Boss 复战 | 60%-80% | 20%-35% | 可刷 |
| 圣兽试炼首通 | 100% | 60% 以上 | 主题装备 |
| 七大罪挑战 | 100% | 70% 以上 | 后期追求 |

评分加成：

| 评分 | 材料倍率 | 装备额外抽取 |
| --- | --- | --- |
| C | 1.00 | 无 |
| B | 1.10 | 低概率 |
| A | 1.25 | 1 次小抽取 |
| S | 1.45 | 1 次高权重抽取 |

断限奖励：

- 首次断限成功：本场评分加成。
- 多次断限：额外稀有权重，但有递减。
- 空界连锁完成：额外 Boss 材料概率。
- 这些奖励不能替代首通关键掉落。

### 8.3 保底规则

保底用于降低刷本焦虑。

| 内容 | 保底建议 |
| --- | --- |
| 关键技能材料 | 主线首通必给 |
| 精英材料 | 材料副本每次至少 1 个 |
| Boss 材料 | 首通必给，复战 2-3 次至少 1 个 |
| 主题装备 | 材料副本 5 次至少 1 件稀有 |
| 圣遗装备 | 圣兽试炼首通至少 1 件主题稀有或史诗 |
| 大罪装备 | 高难七罪挑战 3 次至少 1 件 |

## 9. 强化与进阶

### 9.1 装备强化

装备可强化到当前阶段上限。

| 阶段 | 强化上限 |
| --- | --- |
| T0 | +3 |
| T1 | +5 |
| T2 | +7 |
| T3 | +8 |
| T4 | +10 |
| T5 | +12 |
| T6 | +15 |

强化消耗：

- 通用材料。
- 阶段材料。
- 金钱。
- +8 之后需要对应精英或 Boss 材料。

强化原则：

- +0 到 +5 成本低，帮助普通玩家补容错。
- +8 之后是追求型成长，不作为主线必需。
- 失败不降级，避免刷本体验变坏。

### 9.2 装备进阶

进阶用于保留喜欢的装备。

| 进阶 | 条件 | 效果 |
| --- | --- | --- |
| 品质进阶 | 同主题材料 + 精英材料 | 提高品质预算，可能增加副词条 |
| 词条重铸 | 重铸石 + 金钱 | 重随机一个副词条 |
| 词条锁定 | 稀有材料 | 重铸时保留指定词条 |
| 套装突破 | Boss 材料 | 解锁套装效果 |

初版竖切只做强化，不做重铸和词条锁定。重铸属于中后期系统。

## 10. 魔剑升级与装备关系

魔剑升级和装备强化要分工明确。

魔剑负责：

- ATK / MATK 主成长。
- 技能树节点。
- 魔剑槽。
- 断限、空界连锁、终式奥义。
- 剧情觉醒。

普通装备负责：

- HP、DEF、MDEF、生存容错。
- SP / MP 回复。
- 支援冷却和强度。
- 特定敌人抗性。
- 空连和断限的手感修正。
- 掉落和评分效率。

不允许：

- 普通装备直接解锁魔剑技能。
- 普通装备替代好感门槛。
- 普通装备直接给无限断限。
- 普通装备让一段跳规则失效。

## 14. 数据校验规则

编辑器保存装备和掉落表时应检查：

- 每个装备必须有合法槽位。
- 每个装备必须有合法阶段和品质。
- 魔剑不能进入随机掉落表。
- 好感信物不能被普通小怪掉落。
- 第十二章前不能掉落天使词条。
- 第七章前不能掉落断限窗口词条。
- 主线首通掉落必须包含关键材料。
- 材料副本必须至少掉落一种对应技能线材料。
- 词条数不能超过品质上限。
- 断限窗口、保护条压制、支援冷却等关键词条必须遵守软上限。

## 15. 后续实现顺序

建议实现顺序：

1. 背包和材料计数。
2. 装备模板和装备实例。
3. 装备穿戴后属性合并。
4. 副本掉落表。
5. 战斗结算奖励。
6. 据点装备强化 UI。
7. 词条随机。
8. 套装效果。
9. 重铸和词条锁定。

竖切只需要做到第 1-6 步。词条随机可以先做固定模板，等刷本闭环稳定后再扩展。
