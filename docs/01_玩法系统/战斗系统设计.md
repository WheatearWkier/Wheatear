# 《Wheatear 异世界项目》战斗系统与魔剑技能树 v0.6

## 0. 设计定位

这份文档是正式横板战斗的细化设计，负责把总纲中的魔剑技能树、空中连击、断限追击和数值框架落到可实现的策划规则上。

敌人与 Boss 的具体机制、逐章配置和掉落分布见 [敌人与Boss机制表](敌人与Boss机制表.md)。

核心判断：

- 本游戏不是纯技能轰炸游戏，核心爽点必须是空中连击。
- 断限追击是空中连击之上的高手玩法，不是普通玩家通关必需能力。
- Boss 不能被无脑无限连，但普通玩家通过读招、破防、支援、装备和等级也能打过。
- 高手玩家用空连和断限缩短战斗时间，打出更高评分和更爽的演出。
- 技能树必须服务连招，而不是堆一堆孤立技能。
- 从第二章开始就要能打连击，不能等到后期技能齐了才有连击体验。
- 基础空中普攻，也就是“跳斩 / 空中斩”，是核心战斗动词，不是后期技能树才解锁的技能。
- `J` 键在地面是三段斩，在空中自动变成跳斩；技能树负责强化跳斩、派生空中追斩和空中取消，而不是让玩家先买了技能才能在空中连击。
- 每一次主动释放的攻击，包括主角剑技、魔法、魔剑融合技和攻击型支援，都必须至少提供一种连招接口。

工程实现边界：

- 战斗模块可以先实现完整底层能力，包括浮空、受控状态、Boss 保护条、魔剑槽、断限追击和空界连锁。
- 章节、技能树、教程和 UI 决定玩家什么时候看见和使用这些能力。
- 第二章只正式开放基础横板战斗、三段斩、上挑、跳斩、火球、支援和短空连；Boss 保护条作为隐藏防无限连规则运行，不正式显示。
- 第六章开始显性教学 Boss 保护条。
- 第七章再正式开放断限追击。
- 后期圣兽、天使和七大罪章节再强化断限、空界连锁和高空空连。
- 结算页、技能树页、装备页和据点页已经由 `ProgressionSystem` 驱动，UI 动效由 `UIAnimatorComponent` 接管，页面跳转不再依赖临时 HUD 文本。

玩家分层：

| 玩家类型 | 主要打法 | 通关能力 | 奖励 |
| --- | --- | --- | --- |
| 普通玩家 | 地面立回、短空连、支援保命、抓 Boss 破防窗口 | 可以通关 | 时间较长、评分普通 |
| 熟练玩家 | 稳定上挑、空中追击、技能取消、支援衔接 | 更快通关 | 高评分、更多材料 |
| 高手玩家 | 长空连、断限追击、空界连锁、奥义收尾 | 高效通关高难 Boss | 最高评分、稀有掉落加成 |

## 1. 连招职责模型

每个技能都要明确自己在连招中的职责。一个技能可以有多个职责，但不能所有技能都只写“造成伤害”。

| 职责 | 说明 | 典型技能 |
| --- | --- | --- |
| 起手 | 从立回状态打开敌人防御或硬直 | 三段斩、疾风冲刺斩、冰刃术 |
| 浮空 | 把敌人从地面打到空中 | 裂空挑斩、朱雀炎柱 |
| 续连 | 延长敌人硬直和浮空时间 | 空中追斩、火球术、青龙雷阵 |
| 追击 | 让主角重新接近被打远或浮空的敌人 | 疾风冲刺斩、青龙追风斩、青龙穿云斩 |
| 控场 | 控制小怪位置，减少被围攻 | 回旋断骨斩、暗影禁锢、魔力爆发 |
| 破防 | 打开盾兵、魔法屏障、Boss 破防窗口 | 破甲重斩、破咒冲击、白虎破军斩 |
| 保护 | 让玩家在失误或高压时活下来 | 白光符印、白光护身斩、玄武地脉结界 |
| 收尾 | 在连招末尾造成高伤害并结束回合 | 魔剑终式·天坠、天使裁决·五祝一闪 |
| 断限 | 高手在 Boss 即将脱离连击时重置空中追击 | 断限追击、空界连锁 |
| 资源 | 回复或强化 SP、MP、魔剑槽、奥义槽 | 完美闪避、青龙空界、魔力爆裂斩 |

设计规则：

- 普通技能尽量不要随便把敌人砸落地，除非它是明确收尾技。
- 起手技能伤害不宜过高，否则玩家会只用起手技能打地面循环。
- 续连技能保护条增长要低于高爆发技能，让高手愿意研究空连。
- 收尾技能伤害高，但通常会结束浮空或大幅增加 Boss 保护条。
- 破防技能可以让普通玩家获得稳定输出窗口，避免断限成为唯一解。
- 主动攻击不能是孤立按钮。每个主动攻击至少要满足“可前接、可后接、可起手、可续连、可追击、可收尾、可破防、可提供保护窗口”中的一项。
- 攻击型支援也必须服务连招：要么制造硬直，要么补 hit，要么聚怪，要么破防，要么延长空中窗口。
- 非攻击型支援不强行造成伤害，但必须通过治疗、护盾、净化、霸体、复活等方式帮助玩家继续连招或重新进入连招。

## 2. 连招规则

### 2.1 普通敌人

普通敌人可以被完整浮空、吸附、击退和倒地。它们的主要作用是让玩家练习基础连招。

推荐规则：

- 小型敌人：容易被浮空，保护条低或没有保护条。
- 中型敌人：可浮空，但重量较高，浮空时间短。
- 大型敌人：默认不高浮空，只能轻微离地或进入破防硬直。
- 精英敌人：拥有简化版保护条，防止被无限控死。

### 2.2 Boss

Boss 默认不能被无限连死，但必须给玩家空连空间。

Boss 状态：

- 正常状态：可以被打硬直，但很难长时间浮空。
- 破防状态：可以被稳定浮空和连击。
- 保护临界：Boss 快要脱离连击，触发断限窗口。
- 保护恢复：普通玩家会回到立回，高手可以尝试断限。
- 强制反击：断限失败或贪输出时触发。

普通玩家打法：

`读招 -> 闪避 -> 破防 -> 短空连 -> 收尾 -> 远离 -> 下一轮`

高手打法：

`读招 -> 破防 -> 浮空 -> 续连 -> 保护临界 -> 断限追击 -> 再续连 -> 空界连锁 -> 奥义收尾`

### 2.3 取消规则

技能之间的衔接靠取消规则保证手感。

| 取消类型 | 说明 | 解锁 |
| --- | --- | --- |
| 普攻取消 | 普攻段可接上挑、冲刺斩、火球 | 第二章 |
| 落地取消 | 落地硬直缩短，可接普攻、闪避、上挑 | 第三章 |
| 完美闪避取消 | 完美闪避后可直接反击或释放剑技 | 第四章 |
| 技能取消 | 部分剑技可取消到魔法或融合技 | 第六章 |
| 空中取消 | 空中追斩可接魔法、追击剑技或断限 | 第七章 |
| 断限刷新 | 断限成功后刷新空中攻击和空中取消次数 | 第七章后 |

工程落地规则：

- 每个主动攻击都要配置 `startup / lifetime / recovery / cancelWindowStart / cancelWindowEnd / movementScale`。
- `startup` 决定玩家或敌人按下技能后多久真正生成攻击框；Boss 和精英怪必须留出可读前摇。
- `cancelWindowStart / cancelWindowEnd` 决定技能可接下一招的窗口，前期基础技能要给足可连空间，收尾技可以更重。
- `movementScale` 决定出招时还能保留多少位移，空中续连技能通常高于地面重击，Boss 大招通常接近锁定。
- 单位进入受击硬直、浮空控制或死亡时，未完成的攻击动作会被取消；只有后续明确配置的霸体、空中反击或反制技能可以例外。

### 2.4 基础空中普攻与跳斩规则

这次规则更新后，空中连击的底层不再是“玩家先解锁一个空中追斩技能”，而是：

`跳跃 -> J 空中普攻 / 跳斩 -> 维持浮空 -> 接魔法、上挑派生、支援或落地取消`

基础输入映射：

| 输入 | 地面状态 | 空中状态 | 设计定位 |
| --- | --- | --- | --- |
| `J` | 三段斩 | 跳斩 / 空中普攻 | 前期就可用的空中续连核心 |
| `K` | 一段跳 | 一段跳后的空中高度控制 | 躲避远程、进入空连，不提供常驻二段跳 |
| `S + J` | 裂空挑斩 | 空中追斩 / 下压追击 | 地面负责起浮空，空中负责把将要掉下来的目标留住 |
| `U` | 火球术 / 魔法弹 | 空中魔法弹 | 低保护补 hit，防止连招断线 |
| `I` | 队友支援 | 空中可呼叫支援 | 给新手容错，给高手延长窗口 |
| `L` | 断限追击 | 断限追击 | 第七章后开放的高阶空连刷新机制 |

HUD 规则：

- `J` 普攻和 `K` 跳跃属于基础动作，不进入技能栏。
- 技能栏只显示有冷却、消耗、支援、指令技或章节解锁语义的动作：当前竖切为 `S+J / U / I / L`。
- 技能栏优先使用图标表达；空间紧张时不写长说明，鼠标悬浮图标再显示 tooltip。
- `Space` 可以作为测试兼容跳跃键，但正式文案按 `K` 一段跳记载。

跳跃手感规则：

- `jumpBufferTime` 记录玩家刚按下跳跃的一小段时间，避免移动、动作收束或落地瞬间漏输入。
- `coyoteTime` 允许角色刚离地的一小段时间仍然执行一段跳。
- 二者只改善输入响应，不改变“基础只有一段跳”的系统边界。

跳斩设计规则：

- 跳斩从第二章默认可用，不消耗技能点，不消耗普通二段跳次数。
- 跳斩命中后给敌人少量上浮、少量横向校正、较长硬直和短暂主角滞空。
- 跳斩伤害低于地面三段斩，保护条增长也更低，它的核心价值是维持连招。
- 跳斩不能把 Boss 无脑越打越高；Boss 正常状态只给轻微滞空，破防状态才明显可空连。
- 跳斩空挥不应强行悬停，避免玩家在空中无代价逃课；只有命中才给滞空奖励。
- 空中连续跳斩有次数或衰减限制。断限成功后可以刷新空中攻击次数，这是高手玩法奖励。

技能树与跳斩的关系：

- ME-03 不再表示“解锁空中攻击”，而表示“强化空中追斩派生”。
- MO-03 `空斩滞留` 强化跳斩命中后的主角滞空，不提供普通二段跳。
- MO-07 `追击锁定` 强化跳斩和空中追斩的方向修正。
- LI-04 `空击刷新` 只在断限成功后刷新空中攻击次数。

这样基础玩家从第二章就能打：

`三段斩 1-2 -> 裂空挑斩 -> 跳跃 -> 跳斩 -> 火球术 -> 落地继续`

高手再把这个基础链条扩展成：

`上挑 -> 跳斩维持 -> 空中追斩 -> 魔法补 hit -> 支援定身 -> 断限追击 -> 空击刷新`

空连高度与下坠节奏：

- 空连不是把角色和敌人固定在空中，而是“每次命中都争取时间，但整体仍然缓慢下坠”。
- 每一次空中普攻、空中追斩或空中魔法命中后，都可以给敌人硬直和少量滞空，但同时让主角和敌人下降一点。
- 地面上挑、特定升空技能、部分支援和断限后的再起浮空，才负责把连招高度重新抬上去。
- 断限追击本身的核心不是白送二段跳，而是在快要坠落时重置跳跃、空中攻击次数、空中取消次数和短暂滞空窗口，让高手能接一个升空技能再跳起来继续连。
- 低空空连是有风险的。如果高度低于地面怪的攻击威胁线，其他小怪的爪击、冲撞、投射物或 Boss 地面震波可以打断玩家。
- 高空空连是高手奖励。玩家把 Boss 或精英怪打到足够高后，普通地面怪摸不到玩家，但空中敌人、对空技能和 Boss 特定反制仍然可以形成压力。
- 因此高度本身是一种战斗资源：低空容易起手但危险，高空安全但需要技术、资源和断限时机维持。

示例高级循环：

`上挑起浮空 -> 跳跃 -> 跳斩 / 空中魔法维持但缓慢下坠 -> 快落地前断限追击 -> 跳跃次数刷新 -> 升空技能再次抬高 -> 再跳斩续空`

### 2.5 主动攻击连招接口规则

所有主动攻击必须写清楚两个接口：

- `前接接口`：这个技能从哪些动作、状态或支援后面接出来。
- `后接接口`：这个技能命中后可以继续接什么。

如果一个技能没有后接接口，它必须是明确的收尾技，并且要有足够高的伤害、破防、奥义槽收益或安全位移作为补偿。

主动攻击最低要求：

| 技能类型 | 最低连招要求 |
| --- | --- |
| 剑技 | 至少可接普攻、上挑、魔法、闪避或另一剑技中的一种 |
| 魔法 | 至少能补 hit、制造硬直、减速、浮空、破防或接融合技中的一种 |
| 魔剑融合 | 必须能作为强续连、破防爆发或收尾，不能只是单段伤害 |
| 攻击型支援 | 必须能插入主角连招，且不强制打断主角动作 |
| 防御型支援 | 必须给主角创造继续连招或重新起手的窗口 |
| 奥义 | 可以结束连招，但应当能从空界连锁、破防窗口或支援控制后自然接出 |

前期要求：

- 第二章必须已经能打出基础空连。
- 第三章到第五章每加入一名队友，都要让玩家获得一种新的连招接口，而不是只获得一个独立按钮。
- 第六章到第七章开始把 Boss 保护和断限加到原有连招之上。
- 第八章以后强化连招上限，但不能让前期技能失去价值。

## 3. 技能树重构原则

五个分支不是五套互不相关的技能，而是五种连招功能。

| 分支 | 核心作用 | 连招贡献 |
| --- | --- | --- |
| 近战 | 起手、浮空、破防、物理收尾 | 决定主角手感骨架 |
| 魔法 | 续连、控场、属性、远程补 hit | 让空连不断线 |
| 魔剑融合 | 爆发、派生、阶段性主力输出 | 负责把剑和魔结合成爽点 |
| 机动 | 闪避、追击、取消、滞空 | 让玩家接得上、追得上、落地不难受 |
| 断限 | 重置空中追击、突破 Boss 保护 | 给高手上限 |

设计结论：

- 近战分支必须保证基础连段永远好用。
- 魔法分支必须至少有一半技能能在空中或浮空场景中发挥作用。
- 魔剑融合分支负责“这招很帅很痛”，但不能全部都是收尾。
- 机动分支要保证一段跳也能玩出空战，不靠普通二段跳。
- 断限分支只提高上限，不把普通通关锁死。

### 4.6 支援技能连招接口

支援技能不是额外按钮，而是连招系统的一部分。攻击型支援必须能插入连招；防御和治疗型支援必须能让玩家继续连招或重新起手。

支援释放原则：

- 支援技能默认不打断主角当前动作。
- 支援技能可以在主角攻击、空中、受击保护、技能后摇、断限窗口中被呼叫，但不同支援有不同限制。
- 攻击型支援至少提供硬直、补 hit、破防、吸附、浮空、减速中的一种。
- 防御型支援至少提供格挡、护盾、霸体、受身、复活、净化中的一种。
- 支援技能的好感度成长优先增加连招接口和容错，而不是单纯增加伤害。

支援连招硬规则：

- 攻击型支援不能把敌人无意义打飞到玩家追不到的位置。
- 支援造成击飞时，必须提供追击修正、吸附、减速或滞空。
- 支援造成控制时，对 Boss 要降低控制时间，但保留连招接口价值。
- 支援的主要价值是“打开窗口、延长窗口、保护窗口”，不是替玩家自动打完战斗。

## 5. 推荐连招路线

### 5.1 第二章基础教学连

目标：让玩家理解“地面起手 -> 上挑 -> 空中追击 -> 魔法补 hit -> 落地”的核心。

连段：

`三段斩 1-2 -> 裂空挑斩 -> 跳跃 -> 跳斩 -> 火球术 -> 落地取消 -> 疾风冲刺斩`

用途：

- 打黑熊丈夫。
- 教会玩家浮空不是装饰，而是安全输出时间。
- 教会玩家跳起来后按 `J` 不是空挥，而是基础空中续连。
- 不需要断限。

### 5.2 第三章保命空连

连段：

`冰刃术 -> 疾风冲刺斩 -> 三段斩 -> 裂空挑斩 -> 跳斩 -> 白光治疗 / 圣铃护盾 -> 火焰剑气 -> 白光护身斩`

用途：

- 白魔法队友入队后，新手可以用护盾保证连招安全。
- 支援不是单纯回血，而是在空中连招中给主角一个继续输出的安全窗口。
- 适合打变异树妖或魔化野猪王。

### 5.3 第四章破盾连

连段：

`冰刃术 -> 护卫突进 -> 破甲重斩 -> 冰封斩 -> 裂空挑斩 -> 跳斩 -> 雷矢 -> 雷刃突进`

用途：

- 对付盾兵、堕落骑士、要塞守卫。
- 教玩家先破盾再浮空。
- 剑盾支援负责聚怪或制造反击窗口，而不是只负责防御。

### 5.4 第五章黑魔法压制连

连段：

`暗影锁链 -> 黑炎术 -> 疾风冲刺斩 -> 裂空挑斩 -> 跳斩 -> 黑炎标记 -> 黑炎剑气 -> 魔力爆裂斩`

用途：

- 对付法师小队和审判法师。
- 引入减益、控场和保护条压制。
- 黑魔法支援负责把敌人留在连招里，同时为后续破防和断限做铺垫。

### 5.5 第七章初级断限连

连段：

`破咒冲击 -> 王宫断罪连 -> 暗影锁链 -> 裂空挑斩 -> 跳斩 -> 空中追斩强化 -> 火球术 -> Boss 保护临界 -> 断限追击 -> 跳斩刷新 -> 魔力爆裂斩`

用途：

- 正式教学 Boss 保护条。
- 普通玩家可以不接断限，Boss 落地后继续立回。
- 高手玩家接断限后多打一轮。

### 5.6 第一部终章青梅战

普通打法：

`闪避读招 -> 破甲重斩 -> 黑炎术 -> 上挑 -> 短空连 -> 魔力爆裂斩 -> 拉开`

高手打法：

`完美闪避 -> 反击踏斩 -> 裂空挑斩 -> 跳斩 -> 雷矢 -> 王宫断罪连 -> 断限追击 -> 青梅誓约断限 -> 跳斩刷新 -> 魔剑终式·天坠`

设计重点：

- 这场战斗检验第一部所有基础。
- 玩家不需要断限也能赢，但断限会明显更爽、更快、更高评分。

### 5.7 青龙祝福高速连

连段：

`完美闪避 -> 青龙风步 -> 青龙追风斩 -> 裂空挑斩 -> 跳斩 -> 青龙雷阵 -> 青龙穿云斩 -> 断限追击`

用途：

- 教玩家高速追击和魔剑槽循环。

### 5.8 白虎祝福破防连

连段：

`破防诅咒 -> 黑炎术 -> 破甲重斩 -> 白虎裂牙 -> 白虎破军斩 -> 裂空挑斩 -> 跳斩 -> 奥义`

用途：

- 对付傲慢、高防御 Boss。

### 5.9 朱雀祝福逆转连

连段：

`朱雀炎柱 -> 跳斩 -> 朱雀涅槃斩 -> 火焰剑气 -> 断限追击 -> 魔剑终式·天坠`

用途：

- 濒死时反杀，兼顾回血和护盾。

### 5.10 玄武祝福防守连

连段：

`玄武地脉结界 -> 盾墙格挡 -> 守护反震 -> 玄甲反震斩 -> 破甲重斩 -> 裂空挑斩 -> 跳斩`

用途：

- 对付暴怒、高压突进和大体型 Boss。

### 5.11 第十二章满级试刀连

连段：

`圣裁羽雨 -> 天使净化 -> 青龙追风斩 -> 裂空挑斩 -> 跳斩 -> 青龙雷阵 -> 断限追击 -> 踏界步 -> 朱雀涅槃斩 -> 空界连锁 -> 魔剑终式·天坠 -> 天使裁决·五祝一闪`

用途：

- 打堕天试验体。
- 给玩家第一次完整体验满级魔剑。

### 5.12 国师最终战推荐连

普通打法：

`清召唤物 -> 天使净化 -> 破防诅咒 -> 短空连 -> 支援保命 -> 奥义收尾`

高手打法：

`完美闪避 -> 青龙风步 -> 黑炎标记 -> 黑炎术 -> 白虎裂牙 -> 裂空挑斩 -> 跳斩 -> 青龙雷阵 -> 誓约剑痕 -> 断限追击 -> 空界连锁 -> 踏界步 -> 天使回环·空界终焉 -> 五祝一闪`

设计重点：

- 普通打法靠稳，高手打法靠上限。
- 国师要给断限窗口，但不能让断限成为唯一解。

## 6. 数值策划框架

### 6.1 基础属性

主角属性：

| 属性 | 含义 |
| --- | --- |
| HP | 生命值 |
| MP | 魔法资源 |
| SP | 闪避、冲刺、剑技资源 |
| ATK | 物理攻击，影响近战和部分融合技 |
| MATK | 魔法攻击，影响魔法和部分融合技 |
| DEF | 物理防御 |
| MDEF | 魔法防御 |
| Break | 破防强度 |
| Guard | 防御稳定度 |
| Crit | 暴击率 |
| Combo | 连击评分修正 |

敌人属性：

| 属性 | 含义 |
| --- | --- |
| HP | 生命 |
| ATK / MATK | 物理 / 魔法攻击 |
| DEF / MDEF | 物理 / 魔法防御 |
| Poise | 韧性，影响硬直和破防 |
| LaunchWeight | 浮空重量 |
| ProtectionMax | Boss 保护条上限，默认 100 |
| ProtectionRegen | 脱离连击后的保护恢复速度 |
| BreakWindow | 破防窗口时长 |

### 6.2 伤害公式

近战伤害：

```text
RawDamage = ATK * SkillCoef
DefenseRate = 100 / (100 + EnemyDEF)
FinalDamage = RawDamage * DefenseRate * ElementRate * StateRate * ComboScale * RandomRange(0.95, 1.05)
```

魔法伤害：

```text
RawDamage = MATK * SkillCoef
DefenseRate = 100 / (100 + EnemyMDEF)
FinalDamage = RawDamage * DefenseRate * ElementRate * StateRate * ComboScale * RandomRange(0.95, 1.05)
```

融合技伤害：

```text
RawDamage = (ATK * 0.6 + MATK * 0.6) * SkillCoef
DefenseRate = 100 / (100 + (EnemyDEF + EnemyMDEF) * 0.5)
FinalDamage = RawDamage * DefenseRate * ElementRate * StateRate * ComboScale * RandomRange(0.95, 1.05)
```

说明：

- `SkillCoef` 是技能倍率。
- `ElementRate` 是属性克制，建议范围 0.75 到 1.35。
- `StateRate` 是状态倍率，例如破防 1.25、背击 1.10、Boss 弱点 1.40。
- `ComboScale` 是连击衰减，防止无限连伤害爆炸。
- 随机波动控制在 5%，避免数值手感飘。

### 6.3 连击衰减

连击衰减只限制超长连招伤害，不降低爽感和评分。

| Hit 数 | ComboScale |
| --- | --- |
| 1-20 | 1.00 |
| 21-40 | 0.92 |
| 41-70 | 0.84 |
| 71-100 | 0.76 |
| 101 以上 | 0.68 |

断限追加规则：

- 每次连续断限后，伤害额外乘以 0.92。
- 最低伤害倍率不低于 0.55。
- 连击评分、奥义槽和稀有掉落评分不衰减，反而提高。

这样设计后：

- 普通玩家不会因为不会断限而被卡死。
- 高手玩家能更快打死 Boss，但不会快到破坏 Boss 设计。
- 高手仍然能获得评分和奖励优势。

### 6.4 Boss 保护条公式

Boss 保护条用于限制无脑无限连。

```text
ProtectionGain = SkillProtection * BossWeightRate * HitStateRate * RepeatRate * ControlRate
ProtectionAfterHit = CurrentProtection + ProtectionGain - ProtectionSuppression
```

推荐参数：

| 参数 | 说明 | 建议 |
| --- | --- | --- |
| SkillProtection | 技能保护增长 | 低 3-6，中 7-12，高 13-22 |
| BossWeightRate | Boss 体型修正 | 轻型 0.8，普通 1.0，重型 1.2 |
| HitStateRate | 浮空状态修正 | 地面 0.8，浮空 1.0，破防 0.65 |
| RepeatRate | 重复技能修正 | 连续重复同技能 +15% |
| ControlRate | 控制技能修正 | 冻结、禁锢、强吸附 +20% |
| ProtectionSuppression | 保护压制 | 黑魔法、白虎、青梅断限提供 |

保护条到 100 后：

- 普通情况：Boss 开始坠落或进入恢复。
- 玩家窗口：0.30 秒左右断限输入机会。
- 成功断限：保护条降低到 45-60，并刷新空中追击。
- 失败断限：Boss 恢复并可能反击。

普通通关保障：

- Boss 必须有稳定破防窗口。
- 破防窗口内短空连和收尾技足以造成有效伤害。
- 断限只是延长窗口，不是打过 Boss 的唯一方法。

### 6.5 硬直与浮空

推荐内部参数：

```text
HitstunTime = SkillHitstun * (100 / (100 + EnemyPoise))
LaunchVelocity = SkillLaunchPower - EnemyLaunchWeight
AirHoldTime = SkillAirHold + AirNormalHitBonus + PassiveAirHoldBonus
AirHeightNext = AirHeight + LaunchHeightDelta - AirActionFallStep - GravityFall
```

建议：

- 小怪 LaunchWeight 20-40。
- 精英 LaunchWeight 45-70。
- Boss 正常状态 LaunchWeight 90-120。
- Boss 破防状态临时 LaunchWeight 降低 35-50。
- 断限成功时强制进入可浮空状态，不完全依赖 LaunchWeight。
- 空中攻击不应无限维持同一高度，每次命中默认都有 `AirActionFallStep`。
- 断限成功后刷新跳跃和空中动作次数，同时给短暂 `BreakLimitHangTime`，但再次抬高高度仍应依赖上挑、升空剑技、支援或魔法浮空。

基础跳斩建议参数：

| 参数 | 建议 |
| --- | --- |
| `AirNormalDamageCoef` | 0.32-0.42 ATK |
| `AirNormalHitstun` | 0.22-0.34 秒 |
| `AirNormalLaunchPower` | 轻型敌人 18-26，Boss 正常状态只给轻微维持 |
| `AirNormalHoldBonus` | 命中后主角滞空 0.08-0.14 秒 |
| `AirNormalProtectionGain` | 低，约 3-5 |
| `AirNormalWhiffHold` | 0 或极低，避免空挥逃课 |
| `AirNormalChainLimit` | 常规 2-3 次；断限成功后刷新 |
| `AirNormalFallStep` | 每次命中后主角和目标下降约 0.10-0.22 个高度单位 |
| `GroundThreatHeight` | 低于此高度时，地面小怪和 Boss 地面攻击可打断空连 |
| `HighAirSafetyHeight` | 高于此高度时，普通地面怪攻击够不到玩家 |
| `BreakLimitHangTime` | 断限成功后短暂停滞 0.18-0.32 秒，用来接再升空技能 |
| `BreakLimitJumpReset` | true，断限成功后刷新一次跳跃，不等同于常驻二段跳 |
| `BreakLimitAirActionReset` | true，断限成功后刷新跳斩、空中追斩、空中魔法次数 |

调参目标：

- 小怪可以被跳斩稳定留在空中。
- 精英怪需要上挑或支援配合，不能只靠跳斩无脑控。
- Boss 正常状态可以被跳斩续住一点点，但真正长空连必须依赖破防、支援、保护窗口或断限。
- 初次空连通常处于低空区，仍可能被旁边小怪干扰。
- 熟练玩家通过断限和再升空技能把连招高度抬高后，可以获得更安全的输出环境。

### 6.6 资源公式

基础资源：

- SP 初始上限 100，闪避 18，冲刺 12，剑技 20-35。
- MP 初始上限 100，魔法 18-40。
- 魔剑槽初始 3 格，第二部可扩展到 5 格。
- 奥义槽 100 点。

魔剑槽获得：

```text
GaugeGain = DamageDealt * 0.015 + HitCountGain + PerfectDodgeBonus + AirComboBonus
```

建议：

- 普通命中每 hit +1。
- 空中命中每 hit +1.3。
- 完美闪避 +10。
- 断限成功 +15。
- 青龙祝福后空中命中额外 +15%。

奥义槽获得：

```text
UltimateGain = DamageDealt * 0.01 + BossBreakBonus + ComboRankBonus
```

建议：

- Boss 破防 +10。
- 50 Hit +10。
- 100 Hit +20。
- 空界连锁完成 +25。

### 6.7 好感度数值

好感度不靠刷材料升级，主要来自剧情选择和角色事件。

支援技能倍率：

```text
SupportPowerRate = 1.00 + Affection * 0.003
SupportCooldownRate = 1.00 - Affection * 0.002
```

示例：

- 好感 0：支援强度 100%，冷却 100%。
- 好感 50：支援强度 115%，冷却 90%。
- 好感 100：支援强度 130%，冷却 80%。

阶段解锁：

| 好感 | 解锁 |
| --- | --- |
| 30 | 支援技能 Lv2 |
| 60 | 支援技能 Lv3，解锁魔剑联动技能 |
| 80 | 断限或 Boss 机制辅助 |
| 100 | 后宫确认、终极支援或组合奥义 |

### 6.8 等级成长

推荐初版等级上限：

- 第一部：Lv 1-30。
- 第二部圣兽篇：Lv 31-45。
- 七大罪最终篇：Lv 46-60。

升级经验公式：

```text
ExpToNext = Round(80 * Level^1.45 + 20 * Level)
```

基础成长建议：

| 属性 | 每级成长 |
| --- | --- |
| HP | +18 到 +28 |
| MP | +3 到 +6 |
| SP | +1 到 +3 |
| ATK | +3 到 +5 |
| MATK | +3 到 +5 |
| DEF | +2 到 +4 |
| MDEF | +2 到 +4 |

设计目标：

- 刷级能降低难度，但不能替代所有机制。
- 同级普通 Boss 战目标时长 2.5 到 4 分钟。
- 高手使用断限和空界连锁可缩短 25% 到 40%。
- 装备落后时仍可靠技术过关，但容错降低。

### 6.10 敌人预算公式

敌人 HP 和伤害不要直接拍固定值，推荐按章节预期战力倒推。

普通玩家预期 DPS：

```text
ExpectedDPS = ((ExpectedATK * 0.55) + (ExpectedMATK * 0.45)) * ActionRate * SkillAccessRate * AccuracyRate
```

建议初始参数：

| 参数 | 说明 | 建议 |
| --- | --- | --- |
| `ActionRate` | 每秒有效动作效率 | 前期 1.6，中期 1.9，后期 2.2 |
| `SkillAccessRate` | 当前章节技能丰富度 | 前期 1.0，中期 1.25，圣兽后 1.55，满级 1.8 |
| `AccuracyRate` | 普通玩家命中和空窗损耗 | 小怪 0.85，精英 0.72，Boss 0.60 |

敌人 HP：

```text
EnemyHP = ExpectedDPS * TargetTTK * RankHPFactor * DifficultyRate
```

说明：

- `TargetTTK` 使用本节敌人生命目标表。
- `RankHPFactor` 使用敌人与 Boss 文档中的层级系数。
- `DifficultyRate` 普通 1.0，困难 1.2，挑战 1.45。
- 高手玩家实际 DPS 会更高，所以击杀时间自然缩短，不需要单独给高手一套 HP。

敌人伤害：

```text
PlayerEHP = PlayerHP * (1 + PlayerDEF / 100)
TargetHitDamage = PlayerEHP / ExpectedMistakesToDeath
EnemySkillDamage = TargetHitDamage * SkillDangerRate * DifficultyRate
```

推荐失误承受次数：

| 敌人层级 | 普通攻击失误次数 | 大招失误次数 |
| --- | --- | --- |
| 小怪 | 10-14 次 | 无 |
| 中型怪 / 远程怪 | 7-10 次 | 4-6 次 |
| 精英怪 | 5-7 次 | 3-4 次 |
| 小 Boss | 5-6 次 | 2-3 次 |
| 主线 Boss | 4-6 次 | 2-3 次 |
| 七大罪 / 国师 | 4-5 次 | 1-3 次 |

破防槽：

```text
BreakGauge = ExpectedBreakOutputPerRotation * RotationsToBreak
```

推荐：

- 小怪通常没有破防槽。
- 防御怪 1 轮破甲技能可破。
- 精英怪 2 轮破甲 / 黑魔法组合可破。
- 主线 Boss 2-3 轮机制应对可破。
- 七大罪 Boss 需要对应祝福或支援组合才能高效破。

Boss 保护条预算：

```text
ProtectionMax = BaseProtectionByRank * BossMechanicRate
ProtectionRecoveryDelay = 1.2s to 2.0s after combo ends
ProtectionDecayPerSecond = 12 to 25 when neutral
```

建议：

- 主线 Boss 默认 `ProtectionMax = 100`。
- 七大罪 Boss 可提高到 `120`，但必须给更清晰的破防窗口。
- 国师最终形态可到 `120-140`，但召唤物死亡要给玩家资源补偿。
- 保护条不是惩罚空连，而是控制节奏。高手断限可以突破一部分，普通玩家靠破防窗口也能通关。

### 6.11 技能材料成本

技能材料成本按阶段递增，不按技能数量平均摊。

| 阶段 | 技能成本目标 |
| --- | --- |
| T0 | 主线赠送或 1-2 次副本可解锁 |
| T1 | 每个技能 2-4 次副本材料 |
| T2 | 每个技能 4-6 次副本材料，关键技能需要 Boss 材料 |
| T3 | 第一部 Boss 材料 + 剧情条件 |
| T4 | 圣兽材料 + 对应后宫好感 |
| T5 | 天使之泪 + 四圣兽祝福 + 最终试炼 |
| T6 | 不再消耗魔剑材料 |

设计原则：

- 基础连招技能必须便宜，避免玩家不会玩。
- 断限入门技能必须主线保证解锁，不能被材料卡住。
- 断限强化和空界连锁可以贵，因为它们是高手上限。
- 好感门槛用来绑定角色关系，不作为刷材料惩罚。

## 7. 技能树实现建议

## 8. v0.10 竖切手感实现规范

本轮竖切战斗按“机甲小子式带纵深横板动作”继续收束，形成以下工程规范：

- 战斗核心使用自定义 kinematic 控制器，不把跳跃、浮空、击退、受击硬直交给通用物理引擎自动求解。
- `RuntimeGroundPosition` 负责 X 轴推进和 Y 轴纵深走位，`RuntimeAirHeight` 负责离地高度；这三者一起构成横板带纵深的命中判定空间。
- 普通攻击和跳跃是基础动作，不占主动技能栏；主动技能栏只放 `U / I / L` 等有冷却、图标和 tooltip 的技能。
- 地面 `S+J` 是正式上挑，空中 `S+J` 是追斩；它们是指令技，可以进入教程提示，但不作为冷却技能格。
- 每个攻击数据都必须同时考虑五类字段：动作时间、命中判定、浮空/滞空、取消窗口、反馈表现。
- 每个主动攻击都要能服务连击：不是只有后期技能能连，前期的 `basic1/2/3`、`air_basic`、`launcher`、`air_chase`、`magic_bolt`、`ally_support` 都要有明确连击角色。

当前手感调参入口：

| 参数 | 作用 |
| --- | --- |
| `player.jumpImpulse` | 主角跳跃初速度，越大跳得越高 |
| `player.gravity` | 下落加速度，越大下落越快 |
| `player.jumpBufferTime` | 提前按跳的宽容时间 |
| `player.coyoteTime` | 离地后仍允许起跳的宽容时间 |
| `attacks.*.startup` | 出招前摇 |
| `attacks.*.recovery` | 后摇 |
| `attacks.*.cancelWindowStart/End` | 可取消到下一动作的窗口 |
| `attacks.*.hitStun` | 敌人受击硬直，影响能否续连 |
| `attacks.*.launchVelocity` | 击飞方向和力度 |
| `attacks.*.attackerAirImpulse` | 空中命中后给主角的滞空/上抬 |
| `attacks.*.attackerAirFallStep` | 空中命中后主角下坠步进 |
| `attacks.*.targetAirFallStep` | 空中命中后目标下坠步进 |
| `attacks.*.hitPause` | 命中停顿时间 |
| `attacks.*.cameraShake` | 命中镜头震动强度 |

试玩调参建议：

1. 先只调 `jumpImpulse` 和 `gravity`，把“跳起来能舒服追上上挑目标”确定下来。
