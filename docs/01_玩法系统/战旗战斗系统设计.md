# 战旗战斗系统设计

更新时间：2026-07-30

本文档记录竖切版本新增的战旗假玩法。它当前承担两件事：

1. 剧情节奏上作为假玩法之一，让玩家在进入正式横板战斗前经历一次“看起来像另一种游戏”的短战斗。
2. 引擎能力上验证 Wheatear 可以制作格子战棋/战旗游戏，为后续独立战棋项目预留模块基础。

参考方向是《天地劫》一类格子战旗：清晰的格子地图、单位移动范围、攻击范围、技能图标、行动顺序与状态面板。当前实现保持像素风，不追求最终商业美术，但必须是可玩的完整占位。

## 1. 模块边界

战旗模块独立于现有三种玩法：

| 模块 | 职责 |
| --- | --- |
| `TacticalCombatLevelComponent` | 棋盘尺寸、UI 绑定、阶段状态、胜败跳转、格子高亮颜色 |
| `TacticalUnitComponent` | 单位阵营、格子坐标、数值、移动/攻击范围、技能槽、动画帧 |
| `TacticalCombatSystem` | 命令消费、行动阶段、移动/攻击判定、敌方 AI、UI 更新、特效和音效 |
| `CommandBus` | 消费 `tactic:` 前缀命令 |
| `WheatearEditor` | Inspector 中编辑棋盘、单位、技能槽和动画帧路径 |

它不会混入 `TurnCombat` 或 `SideCombat`。以后如果做正式战棋游戏，可以继续在这个模块上扩展寻路、地形、职业、AI 和剧情事件。

## 2. 当前玩法规则

当前竖切场景是 `TacticalCombat.wt`。据点场景 `Hub.wt` 已加入“战旗试炼”入口，按钮通过 `event:go_tactical_combat` 调用事件脚本，再切换到战旗场景。

基础流程：

```text
开场淡入 -> 我方回合 -> 点击我方单位 -> 移动/选择技能/待机 -> 敌方回合 -> 循环 -> 胜利或失败跳转
```

当前规则：

| 规则 | 当前实现 |
| --- | --- |
| 棋盘 | 8x6 UI 格子棋盘 |
| 移动 | 曼哈顿距离，默认不穿过占用格，当前未做复杂地形 |
| 攻击 | 单体攻击，按技能射程判定 |
| 技能 | 魔剑斩、灵枪、白脉治疗、守备、敌兵斩、暗术 |
| 回合 | 我方所有可控单位行动后进入敌方回合 |
| 敌方 AI | 简单接近最近敌人，进入射程后攻击 |
| 胜利 | 敌方全灭，跳回据点 |
| 失败 | 我方全灭，重载战旗场景 |

当前用 UI 格子按钮驱动操作：每个格子都是一个透明按钮，点击后发送 `tactic:cell:x:y`。技能按钮发送 `tactic:skill:slot0`、`tactic:skill:slot1`、`tactic:skill:slot2`、`tactic:skill:wait`。

## 3. 数值公式

当前伤害用于演示，不作为最终数值：

```text
物理伤害 = max(6, 攻击 * 技能倍率 - 防御 * (1 - 穿透))
魔法伤害 = max(6, 魔法 * 技能倍率 - 防御 * 0.45 * (1 - 穿透))
守备减伤 = 受到伤害 * 0.55
治疗量 = max(8, 施法者魔法 * 治疗倍率)
```

后续正式化时要把技能库从 C++ 内置表迁到数据表，例如 `assets/sandbox/data/tactical_combat_skills.yaml`。当前先硬编码，是为了快速完成可运行竖切。

## 4. 美术与音频资源

资源目录：

```text
WheatearEditor/assets/sandbox/tactical_combat/
```

已生成资源：

| 目录 | 内容 |
| --- | --- |
| `backgrounds/` | 战旗背景图 |
| `tiles/` | 普通格、移动格、攻击格、选中格 |
| `characters/` | 我方/敌方像素单位，含 idle/attack/hit/down 帧序列 |
| `effects/` | 斩击、魔法、治疗、守备、暗术特效帧 |
| `ui/icons/` | 技能命令图标 |
| `ui/panels/` | 顶栏、状态栏、详情栏、命令栏、按钮底板 |
| `audio/` | BGM、选择、移动、斩击、魔法、治疗、守备、受击、胜利音效 |

命名规则和其他玩法保持一致：

```text
characters/unit_<role>_<action>_<frame2>.png
effects/vfx_tac_<skill>_<frame2>.png
ui/icons/cmd_tac_<action>.png
audio/tac_<event>.wav
```

## 5. 编辑器使用

在 `WheatearEditor` 里可以给实体添加：

- `Tactical Combat Level`
- `Tactical Unit`

常调字段：

| 字段 | 用途 |
| --- | --- |
| `GridWidth / GridHeight` | 棋盘尺寸 |
| `BoardOrigin / CellSize` | 棋盘在 Canvas 上的位置和格子大小 |
| `GridX / GridY` | 单位所在格子 |
| `MoveRange / AttackRange` | 单位移动和普通攻击范围 |
| `BasicSkillId / Skill1Id / Skill2Id` | 单位技能槽 |
| `IdleFramePattern / AttackFramePattern / HitFramePattern / DownFramePattern` | 单位动画帧路径 |
| `VictorySceneCommand / DefeatSceneCommand` | 胜败后的跳转 |

当前战旗场景完全走 Canvas UI，因此它适合验证 UI 棋盘、点击和回合逻辑。后续如果做正式战棋，可以把棋盘升级为世界空间 TileMap 或专门的 TacticalGridRenderer。

## 6. 后续升级方向

优先级建议：

1. 把技能库迁到 YAML 数据表。
2. 加入地形：平地、森林、高台、阻挡、增益格。
3. 加入寻路：BFS/A*，移动范围不再只是曼哈顿距离。
4. 加入行动顺序或敌我阶段规则选项。
5. 加入单位职业和属性克制。
6. 加入战旗专用编辑器面板：棋盘刷格、放置单位、预览范围。
7. 用 Sprite Sheet Picker 把当前单帧序列升级成 sheet 切片。
