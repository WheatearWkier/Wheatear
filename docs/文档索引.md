## 推荐阅读顺序

1. 先看 [商业游戏化路线图](路线/商业游戏化路线图.md)，确认当前制作优先级。
2. 再看 [游戏企划总纲](总纲/游戏企划总纲.md)，理解游戏整体。
3. 再看 [战斗系统设计](系统设计/战斗系统设计.md)、[敌人与Boss机制表](系统设计/敌人与Boss机制表.md)、[关卡与副本策划方案](关卡与副本/关卡与副本策划方案.md)，理解核心玩法。
4. 准备做第一个可运行版本时，看 [竖切实现清单](竖切版本/竖切实现清单.md)。
5. 调整编辑器和引擎能力时，看 [引擎架构说明](引擎架构/引擎架构说明.md)、[场景编辑器升级记录](引擎架构/场景编辑器升级记录.md) 和 [WheatearEditor操作手册](引擎架构/WheatearEditor操作手册.md)。
6. 调整空连、战斗 HUD 或装备技能 UI 时，看 [机甲小子空连机制参考分析](参考分析/机甲小子空连机制参考分析.md) 和 [机甲小子UI布局参考分析](参考分析/机甲小子UI布局参考分析.md)。
