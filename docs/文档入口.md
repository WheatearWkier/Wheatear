# Wheatear 文档入口

更新时间：2026-08-17

## 维护规则

- `docs` 下 Markdown 文件名使用中文；少量项目名、模块名或通用缩写可以保留在中文文件名内。
- 策划案、系统设计、操作手册、美术方案、参考分析和引擎创新设计默认保留；有重复时先合并到同类文档，再删除旧拆分文件。
- 一次性日志、临时排错记录和构建输出不长期放在 `docs`；沉淀后的结论进入对应设计文档。
- 新增文档时同步更新本入口，并优先放入现有分区，避免重新堆出一层散乱目录。
