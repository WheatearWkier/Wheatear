# Wheatear 文档入口

更新时间：2026-10-24

`docs` 是 Wheatear 引擎、工具链和游戏项目的设计说明库。目标是**一套内容只有一个权威来源**：教程按层拆章，项目按建造顺序成篇，历史记录只保留决策，不再维护并行的“合订本 / 设计书 / 速查版”。

## 维护规则

- 一个主题只保留一个权威正文；不要新增“合订本 / 精简版 / 并行设计书”。需要顺读时在入口页给阅读顺序，而不是复制全文。
- 新增、重命名或删除文档时，同步更新本入口和所在目录的 `README.md`。
- 章节正文写“当前实现 + 源码入口 + 边界”，历史过程写入《引擎演进与决策记录》，不要混进架构说明。
- 策划案、美术规范、参考资料和竖切记录属于项目资产，清理时优先合并同类项，不删除仍被引用的内容。
- 文档内相对链接必须可解析；合并后及时修正旧链接。
