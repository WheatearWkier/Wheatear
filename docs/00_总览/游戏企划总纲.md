# 《Wheatear 异世界项目》游戏企划总纲 v0.1

## 0. 文档定位

这份文档是本游戏的企划母稿，用来统一世界观、人物、剧情、系统、战斗机制和后续资源需求。当前阶段优先使用 Markdown 保存，因为它方便版本管理、对比修改，也方便后续直接拆成引擎功能和游戏内容任务。

推荐工作流：

- 母稿：`docs/总纲/游戏企划总纲.md`。
- 对外阅读版：内容稳定后再导出为 `.docx` 或 PDF。
- 复杂剧情管理：后续可以引入 Obsidian、Notion、Articy Draft 等工具。
- 数值和资源表：后续可以用 Excel / CSV 管理，并由编辑器读取。

当前原则：

- 先把游戏做成能完整通关的竖切版本。
- 再扩章节、角色、技能、敌人、关卡和资源。
- 所有设计都要服务于“真的能在 Wheatear 引擎编辑器里做出游戏”。

## 1. 项目定位

游戏类型：

- Galgame / 视觉小说。
- 2D 横板清版动作战斗。
- 异世界冒险。
- 好感度影响战斗能力。
- 主角单人主控，多名异性队友作为支援技能参与战斗。

参考方向：

- 叙事结构：传统 Galgame 剧情推进、选项、好感度、角色关系。
- 战斗风格：参考 Baldr Sky Dive、功夫派、机甲旋风、时空猎人一类经典横板战斗的爽感。
- 第一关设计：保留现有类元气骑士 / 坦克大战模块，作为故意误导玩家的“假第一关”。

核心卖点：

- 视觉小说剧情和横板战斗不是割裂的，好感度会直接影响技能冷却、伤害、治疗、护盾、Boss 保护条等战斗表现。
- 基础战斗容易上手，高手机制有研究深度。
- 普通玩家可以正常通关，高手玩家可以通过“断限追击”打出超长空中连招。
- 前期像套路异世界，后期逐渐反转到王权、骑士、魔法制度和青梅真相。

## 2. 高概念

主角和异性青梅竹马在现实世界的上学路上被突然袭击，两人被捅后陷入昏迷。主角醒来后发现自己身处一个异世界。

这个异世界以魔法为尊，但魔法并不是人人都会。普通人主要使用近战武器、弓箭、投石、陷阱等手段战斗。能使用魔法的人通常是精英、贵族、军方资产、魔法组织成员，或者危险的独立强者。

主角醒来后发现自己身处异世界。想到青梅也被捅，主角心急如焚，到处寻找她。终于见到“青梅”时，她却被一个大魔法师掠走。主角由此踏上寻找青梅的旅程。后期揭示，被掳走的其实是假青梅傀儡；真正的青梅一直以王国骑士团魔剑士导师的身份留在主角身边，亲手把魔剑交给他，并指导他成长为魔剑士。

旅途中，主角会遇到多名异性队友。她们分别擅长白魔法、黑魔法、剑盾护卫等能力，而且都很像主角现实世界中的异性好友。她们暂时不作为可切换主控角色，而是以头像和支援技能的形式出现在主角 UI 下方。玩家按对应队友技能键，就可以借助她们的力量。

最终真相是：青梅其实是异世界人。她曾经使用穿越魔法来到现实世界，和主角一起长大，并深深爱上了主角。因为控制欲、占有欲和不安全感，她自导自演了现实世界袭击和异世界重逢，希望把主角带回自己的世界并永远占有他。

第一部表面结局中，主角在魔剑士对决中正面击败真青梅，把她精心布置的舞台、傀儡和控制欲全部打碎。青梅在战败后彻底屈服，明白主角本来就爱她，也不敢再用骗局和支配欲操纵主角。青梅成为带有扭曲恋爱感的小鸟依人正宫，其他异性队友也逐渐进入后宫关系。

但这并不是最终完结。真正的大反转是：青梅的扭曲并非完全出自本性，而是从小到大受到大魔法师国师的洗脑与诱导。国师在主角和青梅最终对决后的战乱时刻刺杀国王，发动提前布置在王国七个方位的七大罪怪物，使用近乎无穷无尽的魔力控制王国。主角带着青梅和国王妻子逃亡，进入第二部“国师夺国与圣兽觉醒篇”。

## 3. 世界观

世界类型：

- 剑与魔法异世界。
- 魔法是稀缺资源，也是身份、阶层、军事力量和政治权力的象征。
- 普通人靠武器、体能和战术生存。
- 魔物横行，但魔物并不是最终敌人。

力量阶层：

- 普通人：剑、盾、弓、投石、陷阱。
- 精英战士：熟练掌握武器和战技。
- 魔法师：拥有元素魔法、诅咒、治愈、屏障等能力。
- 魔剑士：极少数能把魔法和近战融合的人。
- 王国骑士：后期登场的国家机器，拥有纪律、装备、阵型和反魔法技术。
- 王权系统：掌控魔法制度、身份秩序和世界规则的深层势力。

叙事递进：

- 前期：魔物威胁，让玩家以为这是传统打怪异世界。
- 中期：魔法师势力登场，让玩家以为黑幕是魔法组织。
- 后期：国王、骑士、贵族和王国制度登场，揭示真正控制世界秩序的是王权结构。
- 最终：青梅身份揭晓，主角来到异世界并不是偶然。

核心矛盾：

- 这个世界把魔法当作阶层工具。
- 主角的魔剑士天赋打破了既有秩序。
- 青梅的爱是真实的，但她用错误的方式占有主角。
- 主角的旅程既是寻找青梅，也是看清世界真相。

## 4. 剧情大纲

章节结构需要回答：

- 本章发生什么剧情。
- 新增什么角色。
- 解锁什么系统。
- 敌人从什么类型升级到什么类型。
- Boss 是谁。
- 本章结束时玩家获得什么。
- 本章对主线反转有什么推进。

### 序章：现实世界与穿越

- 主角和青梅走在上学路上。
- 两人关系自然亲密，像普通青梅竹马。
- 突然有人袭击，两人被捅。
- 主角陷入昏迷。
- 画面转入异世界。

新增角色：

- 主角。
- 青梅。

解锁系统：

- VN 对话。
- 基础选项。
- 场景切换。

反转推进：

- 开局袭击表面上是意外，后期会揭示它其实是青梅设计的一部分。

### 第一章：假的开始与假青梅被掳

- 主角在异世界醒来。
- 他还没有理解世界规则，也没有觉醒真正的魔剑士力量。
- 第一场战斗使用当前已有的类元气骑士 / 坦克大战模块。
- 画面和玩法可以故意显得简陋，让玩家误以为这是一个很粗糙的游戏。
- 战斗后主角狠狠吐槽这场战斗，直接把玩家的第一印象转化成剧情包袱。
- 主角短暂见到“青梅”。
- 大魔法师突然出现，把“青梅”掳走。
- 魔法师为了阻止主角追赶，放出黑熊母熊追杀主角。
- 主角此时还没有魔剑，也不会真正战斗，只能狼狈逃跑。
- 第一章以主角被黑熊逼入绝境作为 cliffhanger。

新增角色：

- 被掳走的“青梅”。
- 大魔法师。
- 黑熊母熊。

解锁系统：

- 假玩法战斗。
- 主线追寻动机。
- 逃亡和生存压力。

Boss：

- 黑熊母熊：第一章不要求完整击败，主要负责制造压力。

章末收益：

- 明确主线目标：救回被掳走的“青梅”。
- 玩家和主角都以为青梅真的被魔法师抓走。

反转推进：

- 此时主角和玩家都以为被掳走的是青梅本人。
- 后期揭示：被掳走的是假青梅傀儡，用来推动主角踏上寻找之路。

### 第二章：真青梅送魔剑与真正的新手教程

- 黑熊母熊继续追杀主角。
- 危急时，一个很像青梅的异世界原住民出现。
- 她自称来自王国骑士团，是一名魔剑士。
- 她把一把魔剑交给主角，声称这是“只有合适的人才能使用的武器”。
- 主角握着不会用的魔剑，在危急中靠本能用平 A 近战砍翻黑熊。
- 黑熊死亡后掉落材料，魔剑自动吸收靠近剑身的升级材料。
- 主角刚松一口气，更大的黑熊出现。它是前面母熊的丈夫，作为真正新手教程的压力点登场。
- 魔剑士导师开始指导主角使用魔剑，并作为主角的指导者同行。
- 这一章的战斗场景是正式横板战斗的新手教程。
- 教学内容包括移动、一段跳、闪避、普攻、上挑、空中追击、剑技、火球和队友支援预告。
- 导师表面上冷静专业，偶尔流露出只有青梅才会知道的细节。

新增角色：

- 魔剑士导师。

解锁系统：

- 正式 2D 横板战斗。
- 魔剑获得。
- 材料掉落。
- 魔剑自动吸收材料。
- 一段跳。
- 闪避。
- 普攻连段。
- 上挑。
- 空中攻击。
- 初级剑技。
- 初级魔法。
- 据点 UI 雏形。

Boss：

- 黑熊母熊：让主角第一次用魔剑砍赢。
- 黑熊丈夫：作为正式新手教程 Boss。

章末收益：

- 获得魔剑。
- 获得第一批魔剑升级材料。
- 主角掌握魔剑的基础用法。
- 魔剑开启低阶技能树。
- 解锁第一个可重刷副本。

反转推进：

- 导师其实就是真青梅。
- 她假装是原住民和骑士团魔剑士，亲手送出魔剑，并近距离指导主角成长。
- 她想亲眼体验主角为了“青梅”而战、为了“青梅”变强的过程。

### 第三章：白魔法队友

- 主角和导师来到被魔物袭击的边境村。
- 村中有一名会白魔法的少女，她很像主角现实世界里的异性好友。
- 她被村民依赖，却因为魔法稀有而被地方势力盯上。
- 主角帮助她保护村庄。
- 她加入队伍，成为第一个正式支援队友。

新增角色：

- 白魔法队友。

解锁系统：

- 好感度系统。
- 支援技能栏。
- 治疗支援。
- 护盾支援。
- 队友头像 UI。

敌人类型：

- 小魔物。
- 弓箭魔物。
- 会冲撞的大型魔物。

Boss：

- 变异树妖或魔化野猪王。

章末收益：

- 获得白魔法支援。
- 解锁治疗、护盾和基础好感度事件。
- 魔剑技能树开放白魔法联动技能条件。

反转推进：

- 玩家开始发现队友们都像主角现实世界的异性好友。
- 这不是巧合，后期会和青梅的穿越魔法、记忆投影或傀儡系统有关。

### 第四章：剑盾护卫队友

- 主角一行经过王国边境要塞。
- 一名剑盾护卫少女正在保护难民撤离。
- 她很像主角现实世界里的另一位异性好友。
- 她重视纪律和责任，起初不信任主角这个来历不明的魔剑士。
- 主角通过战斗证明自己不是只会冲动救青梅的人。
- 她加入队伍，作为防御型支援。

新增角色：

- 剑盾护卫队友。

解锁系统：

- 防御型支援。
- 紧急格挡。
- 反击支援。
- 短暂霸体。
- 濒死保护预告。

敌人类型：

- 盾兵魔物。
- 投石怪。
- 低阶王国逃兵或受控骑士。

Boss：

- 堕落骑士或要塞守卫队长。

章末收益：

- 获得剑盾支援。
- 解锁失败保护类支援机制。
- 魔剑技能树开放防御、霸体、反击类联动技能条件。

反转推进：

- 王国骑士团不再只是正义组织。
- 导师自称来自骑士团，但她对骑士团内部情报的掌握过于异常。

### 第五章：黑魔法队友

- 主角追查大魔法师的线索，进入被封锁的魔法废墟。
- 废墟中有一名被视为危险人物的黑魔法少女。
- 她很像主角现实世界里的第三位异性好友。
- 她擅长诅咒、减益和控场，性格更危险，也更接近中期魔法师冲突的核心。
- 主角选择相信她，并一起击破追捕她的魔法师小队。

新增角色：

- 黑魔法队友。

解锁系统：

- 黑魔法支援。
- 破防。
- 减速。
- 禁锢。
- Boss 保护条压制预告。

敌人类型：

- 法师学徒。
- 法阵陷阱。
- 屏障魔法师。
- 召唤魔物。

Boss：

- 追捕黑魔法队友的审判法师。

章末收益：

- 获得黑魔法支援。
- 解锁破防、减益和控场玩法。
- 魔剑技能树开放黑炎、暗影、Boss 保护条压制类联动技能条件。

反转推进：

- 魔法师并非独立反派。
- 魔法师组织背后有王国命令。

### 第六章：魔法师老巢与王宫消息

- 主角带领队伍攻入大魔法师的老巢。
- 玩家以为这一章会救回青梅。
- 战斗重点从魔物转向正式魔法师集团。
- 主角击败守门法师、实验魔物和大魔法师部下。
- 最终得知：青梅已经被献到王宫，成为国王预定的妻子。
- 大魔法师并不是最终黑幕，而是国王的手下。
- 国王迷恋异世界人，故意掳走“青梅”。

新增角色：

- 大魔法师。
- 王国使者。

解锁系统：

- 中级副本。
- 精英怪机制。
- Boss 保护条正式教学。
- 初级断限追击预告。

敌人类型：

- 精英魔法师。
- 魔法傀儡。
- 实验魔物。
- 法阵炮台。

Boss：

- 大魔法师。

章末收益：

- 获得大魔法师材料。
- 魔剑开启中阶技能树。
- 解锁王宫主线。

反转推进：

- 魔法师只是国王棋子。
- 被献到王宫的“青梅”身份仍然可疑。
- 导师对这件事的反应过于平静，埋下她才是真青梅的伏笔。

### 第七章：进攻王宫

- 主角带领众人向王宫进发。
- 敌人从魔法师升级为王国骑士、禁卫军、宫廷法师和圣骑士。
- 队友们的好感度与支援技能在这一章集中发挥。
- 玩家需要综合使用治疗、格挡、破防、魔剑技能和断限追击。
- 王宫中的“青梅”表现得越来越像没有自我意识的傀儡。

新增角色：

- 国王。
- 王国骑士团高层。
- 假青梅傀儡。

解锁系统：

- 高阶副本。
- 队友支援组合。
- 断限追击正式解锁。
- 多阶段 Boss。

敌人类型：

- 王国骑士。
- 禁卫军。
- 宫廷法师。
- 圣骑士。
- 反魔法装置。

Boss：

- 王国骑士团长。
- 国王。

章末收益：

- 获得王宫材料。
- 魔剑开启高阶技能树。
- 解锁空界连锁前置条件。

反转推进：

- 王宫青梅是假青梅，是傀儡。
- 国王也是受控制的傀儡。
- 真正控制局面的人不是国王，而是一直陪在主角身边的魔剑士导师。

### 第一部终章：真青梅与最终魔剑士对决

- 魔剑士导师揭示自己才是真青梅。
- 她来自异世界，曾经穿越到现实世界和主角一起长大。
- 她制造了开局袭击、假青梅被掳、魔法师追逐、王宫献妻等一连串舞台。
- 她这么做不是为了伤害主角，而是想体验主角为了她战斗、为了她成长、为了她冲破整个世界的过程。
- 她的爱是真的，但控制欲和占有欲极端扭曲。
- 主角得知真相后非常愤怒。
- 最终 Boss 战是主角对战魔剑士青梅。
- 这场战斗既是实力对决，也是情感对决。
- 主角通过战斗击破她的控制欲、幻术、傀儡魔法和内心防线。
- 主角用她亲手送出的魔剑、亲手教出的魔剑术，把她正面打败。
- 这场战斗的情绪重点不是温柔说服，而是主角愤怒地让她为操纵自己付出代价。
- 青梅被打到屈服，承认自己再也不敢用骗局、傀儡和支配欲耍弄主角。
- 青梅在败北后变成小鸟依人、百依百顺但仍保留病娇余味的正宫。
- 其他异性队友接受后宫关系，队伍进入最终后宫结局。

解锁系统：

- 空界连锁最终形态。
- 青梅正宫支援。
- 第一部终极魔剑技能。

敌人类型：

- 青梅制造的魔剑幻影。
- 记忆傀儡。
- 王宫残余控制装置。

最终 Boss：

- 魔剑士真青梅。

章末收益：

- 青梅正宫确认。
- 后宫关系确认。
- 魔剑第一阶段高阶觉醒。
- 主角真正掌握自己的力量，并夺回这段关系里的主动权。

反转完成：

- 被掳走的青梅是假青梅傀儡。
- 国王是傀儡。
- 魔法师是国王手下，但国王又被青梅控制。
- 真青梅一直在身边指导主角。
- 主角寻找青梅的旅程，本质上是青梅为主角设计的成长舞台。

### 第二部序章：国师夺国与逃亡

- 主角刚刚击败真青梅，玩家以为故事进入后宫结局。
- 真青梅屈服后，精神状态开始恢复，显露出更接近本性的温顺、依赖和逆来顺受。
- 前面被误以为是傀儡或弱者的大魔法师，其实一直在示弱。
- 国师趁主角、青梅、王国军和王宫陷入混乱时刺杀国王。
- 国师当着主角的面嘲讽青梅：她从小就被自己洗脑，所谓“想让主角为她而战”的扭曲执念，也是他一点点种进她心里的。
- 青梅在国师的话语和魔法残响刺激下出现记忆破碎，主角由此得知她并非天生扭曲，而是被长期诱导和污染。
- 国师提前在王国七个方位布置七大罪怪物，并发动王国级控制魔法。
- 他的魔力近乎无穷无尽，一人成军，能够创造魔物、召唤魔物、控制傀儡和重写战场。
- 主角情急之下带着青梅和国王妻子逃出王宫。
- 国王妻子后续加入主角后宫，并成为魔剑最终觉醒的重要钥匙。
- 逃亡后，青梅告诉主角：魔剑还没有达到最大潜能，必须获得上古圣兽青龙、白虎、朱雀、玄武四种力量的祝福。

新增角色：

- 国师 / 大魔法师真身。
- 国王妻子 / 王妃。
- 七大罪怪物。

解锁系统：

- 第二部世界状态。
- 逃亡据点。
- 圣兽祝福主线。
- 七大罪威胁地图。

敌人类型：

- 国师召唤魔物。
- 被王国级魔法控制的士兵。
- 七大罪污染区域怪物。

Boss：

- 无完整 Boss 战，以逃亡和剧情压迫为主。

章末收益：

- 青梅正宫加入。
- 王妃暂时同行。
- 解锁四圣兽主线。

反转推进：

- 国师才是真正大反派。
- 青梅的扭曲来自国师长期洗脑。
- 国王、魔法师、假青梅都只是国师计划的一部分。

### 第八章：青龙祝福

- 主角一行进入东方上古之地。
- 这里以风、雷、速度、空中机动和连击试炼为核心。
- 对应后宫角色：青梅正宫。
- 青梅在这一章逐步从“战败屈服”转向“主动依赖主角、愿意把力量交给主角”。
- 试炼重点是让玩家熟悉高速位移、空中追击和断限追击强化。

解锁系统：

- 青龙祝福。
- 空中追击距离强化。
- 魔剑槽回复效率强化。
- 青梅正宫支援升级。

Boss：

- 青龙试炼化身。

章末收益：

- 魔剑获得青龙祝福。
- 青梅好感和正宫支援大幅提升。
- 空界连锁前置能力强化。

### 第九章：白虎祝福

- 主角一行进入西方上古之地。
- 这里以杀伐、破甲、近战爆发和正面压制为核心。
- 对应后宫角色：黑魔法队友。
- 黑魔法队友的破防、诅咒和暗影力量与白虎杀伐之力产生共鸣。
- 试炼重点是破盾、破甲、压制高防御敌人。

解锁系统：

- 白虎祝福。
- 破甲伤害强化。
- 黑魔法支援升级。
- Boss 保护条压制强化。

Boss：

- 白虎试炼化身。

章末收益：

- 魔剑获得白虎祝福。
- 黑魔法队友好感大幅提升。
- 解锁高阶破防类魔剑技能。

### 第十章：朱雀祝福

- 主角一行进入南方上古之地。
- 这里以火焰、复苏、魔力爆发和生命燃烧为核心。
- 对应后宫角色：白魔法队友。
- 白魔法队友的治愈能力与朱雀的复苏之火产生共鸣。
- 试炼重点是持续战斗、恢复节奏和濒死逆转。

解锁系统：

- 朱雀祝福。
- 治疗转护盾。
- 火焰魔剑融合技。
- 白魔法支援升级。

Boss：

- 朱雀试炼化身。

章末收益：

- 魔剑获得朱雀祝福。
- 白魔法队友好感大幅提升。
- 解锁复苏、护盾和火焰爆发类魔剑技能。

### 第十一章：玄武祝福

- 主角一行进入北方上古之地。
- 这里以守护、霸体、反击、抗性和长期防线为核心。
- 对应后宫角色：剑盾护卫队友。
- 剑盾护卫队友的守护意志与玄武之力产生共鸣。
- 试炼重点是防御窗口、格挡反击、霸体对抗和持久 Boss 战。

解锁系统：

- 玄武祝福。
- 格挡反击强化。
- 霸体时间强化。
- 剑盾支援升级。

Boss：

- 玄武试炼化身。

章末收益：

- 魔剑获得玄武祝福。
- 剑盾护卫队友好感大幅提升。
- 解锁防御、霸体、反击类魔剑技能。

### 第十二章：天使祝福与魔剑完全觉醒

- 主角集齐四圣兽祝福后，发现魔剑技能树仍然没有完全点亮。
- 主角感到疑惑，青梅也无法解释最后缺失的力量。
- 国师留下的追兵袭击逃亡据点，敌方用于侦测圣性血脉的法阵突然对王妃产生反应。
- 法阵称呼王妃为“未觉醒的天使容器”，追兵也露出异常贪婪和恐惧的反应。
- 众人进入天使记忆试炼，才逐渐确认王妃并非普通王妃，而是天使转生。
- 试炼记忆揭示：国王因为诅咒或身体缺陷，从未真正占有王妃。
- 王妃仍保留天使转生者所需的纯净性。
- 王妃与主角缔结神圣伴侣契约，流下“天使之泪”。
- 天使之泪补全魔剑最后缺失的祝福。
- 王妃正式加入后宫。
- 至此，魔剑技能树彻底点满。
- 魔剑完全觉醒后，国师追兵召唤出“堕天试验体”。
- 这一战给玩家第一次随心所欲使用满级魔剑、天使祝福和终极支援技能的机会。

解锁系统：

- 天使祝福。
- 魔剑最终技能树。
- 王妃后宫关系确认。
- 终极支援技能。
- 天使复生：每场战斗可额外复活一次，或在受到致命伤害时保留 1 点 HP 并触发短暂无敌。

Boss：

- 天使记忆试炼。
- 堕天试验体：魔剑完全觉醒后的试刀 Boss。

章末收益：

- 魔剑彻底觉醒。
- 主角进入最终战前完全体。
- 后宫主力角色关系基本确立。
- 玩家实际体验满级魔剑、天使复生和终极支援技能。

反转推进：

- 王妃不是单纯被救出的国王妻子，而是被敌方法阵和天使记忆试炼揭示出的天使转生。
- 魔剑真正需要的最后一块力量不是圣兽，而是天使祝福。

### 第十三章：七大罪第一战场

- 主角返回被国师控制的王国边境。
- 这一阶段开始，魔剑已经无法继续升级。
- 玩家成长重点转为等级、装备、支援组合、好感度补满和战术理解。
- 第一战场采用一敌二 Boss 结构。

敌人类型：

- 傲慢污染骑士。
- 怠惰沉睡魔物。
- 国师召唤物。

Boss：

- 傲慢怪物。
- 怠惰怪物。

战术要求：

- 傲慢怪物需要破甲、打断和高爆发。
- 怠惰怪物会减速、封技能、拖慢节奏，需要青龙祝福和支援净化。

章末收益：

- 高级装备。
- 大量经验。
- 后宫角色好感推进。

### 第十四章：七大罪第二战场

- 主角进攻被国师污染的贸易城市。
- 城市被贪婪和暴食污染，资源、生命和魔力都被吞噬。
- 第二战场继续采用一敌二 Boss 结构。

Boss：

- 贪婪怪物。
- 暴食怪物。

战术要求：

- 贪婪怪物会偷取玩家资源和掉落，需要玄武防护与装备抗性。
- 暴食怪物会吞噬召唤物、弹幕和地形，需要朱雀爆发打出窗口。

章末收益：

- 高级饰品。
- 装备强化材料。
- 后宫支援技能继续升级。

### 第十五章：七大罪第三战场

- 主角进入被精神魔法污染的王都外环。
- 色欲和嫉妒怪物负责瓦解队伍关系、复制主角能力、干扰后宫支援。
- 第三战场强调支援技能组合和精神控制抗性。

Boss：

- 色欲怪物。
- 嫉妒怪物。

战术要求：

- 色欲怪物会控制角色、封锁支援，需要青梅正宫支援抵抗精神魔法。
- 嫉妒怪物会复制主角技能，需要黑魔法破除分身和伪装。

章末收益：

- 精神抗性装备。
- 后宫关系进一步确认。
- 角色好感接近满值。

### 第十六章：七大罪最终战场与国师决战

- 主角攻入王国核心。
- 暴怒怪物作为最终七大罪 Boss 登场。
- 国师亲自参战，与暴怒怪物形成一敌二最终战场。
- 七大罪被全部击破后，国师进入最终形态。
- 国师展现真正无穷无尽的魔力、魔物创造术、召唤术和王国级控制魔法。
- 主角依靠满级魔剑、装备、等级、满好感后宫支援和圣兽 / 天使祝福，与国师决战。

Boss：

- 暴怒怪物。
- 国师第一形态。
- 国师最终形态。

战术要求：

- 暴怒怪物高霸体、高伤害，需要剑盾支援和玄武祝福制造生存窗口。
- 国师会持续召唤魔物，需要白魔法续航、黑魔法控场、青梅正宫支援和王妃天使支援共同应对。
- 最终阶段要求玩家熟练使用断限追击、空界连锁、支援组合和奥义收尾。

章末收益：

- 击败国师。
- 王国控制魔法解除。
- 青梅彻底摆脱洗脑。
- 王妃正式加入后宫。
- 后宫成员好感基本满值。
- 游戏进入真正最终结局。

## 5. 主要人物

### 主角

身份：

- 现实世界学生。
- 被带入异世界。
- 天生魔剑士。

战斗定位：

- 主控角色。
- 近战和魔法双修。
- 可以使用剑技、魔法、魔剑融合技和断限追击。
- 后期技能树分为近战、魔法、机动、魔剑融合、高级空连等方向。

剧情定位：

- 寻找青梅。
- 串联所有队友。
- 逐渐从被动卷入事件，成长为打破异世界秩序的人。

### 青梅 / 正宫女主

表层身份：

- 现实世界青梅竹马。
- 开局袭击事件受害者。
- 异世界中伪装成王国骑士团魔剑士导师。
- 被大魔法师掳走的“青梅”其实是假青梅傀儡。

真实身份：

- 异世界人。
- 穿越魔法使用者。
- 把主角带回异世界的幕后核心。

性格关键词：

- 爱得很深。
- 控制欲强。
- 占有欲强。
- 不安全感重。
- 喜欢看主角为了她战斗、成长和失控。
- 扭曲性格来自国师长期洗脑和诱导。
- 本质是小鸟依人、百依百顺、逆来顺受的好女孩。
- 败北后会对主角屈服。

剧情弧线：

- 表面上被拯救对象是“青梅”，实际上那是假青梅傀儡。
- 真青梅一直以导师身份陪在主角身边，亲手送出魔剑并训练主角。
- 从“用舞台操纵主角为自己而战”，转为“被主角击败后臣服于主角”。
- 第二部揭示她从小被国师洗脑，病态控制欲是被塑造出来的污染。
- 她在国师被击败后彻底摆脱洗脑，回到温顺依赖的本性。
- 最终成为小鸟依人、百依百顺的正宫。

战斗关联：

- 后期可解锁特殊支援。
- 可以与主角的魔剑士能力、穿越魔法、断限追击最高级形态绑定。
- 可作为“空界连锁”最终形态的剧情钥匙。

### 国师 / 大魔法师

定位：

- 真正大反派。
- 第一部中伪装成国王手下、魔法师 Boss 或看似被控制的人。
- 第二部揭示他一直在示弱，实际拥有近乎无穷无尽的魔力。

能力：

- 魔物创造术。
- 魔物召唤术。
- 傀儡控制。
- 王国级精神控制。
- 七大罪怪物布置。
- 一人成军级别的魔法压制。

剧情作用：

- 从小洗脑青梅，诱导她把爱转化为控制欲和占有欲。
- 操纵王国、国王、魔法师组织和假青梅舞台。
- 在主角与青梅最终对决后的混乱时刻刺杀国王。
- 发动七大罪怪物并控制王国，成为第二部最终敌人。

设计原则：

- 他的早期失败必须回看时合理：不是弱，而是装弱。
- 前期要埋伏笔，例如魔力从不见底、战败时过于冷静、总能提前布置战场。
- 他必须比青梅更像真正黑幕，负责把第一部的扭曲恋爱反转为第二部的夺国战争。

### 王妃 / 天使转生

定位：

- 国王妻子。
- 后续加入主角后宫。
- 魔剑最终觉醒的最后钥匙。

表层身份：

- 被国王占有名义束缚的王妃。
- 王宫事件后被主角带着一起逃亡。

真实身份：

- 天使转生。
- 保留天使祝福的宿命角色。
- 国王因为诅咒或身体缺陷，从未真正占有她。

剧情弧线：

- 从王宫中的被动王妃，转为主角逃亡队伍的一员。
- 在四圣兽祝福后，被敌方法阵和天使记忆试炼揭示为天使转生。
- 与主角缔结神圣伴侣契约，流下“天使之泪”，补完魔剑最后缺失的力量。
- 正式成为后宫成员。

战斗关联：

- 后期支援角色。
- 天使祝福解锁魔剑最终技能树。
- 支援方向可偏向净化、复活、神圣伤害、精神控制免疫。

### 白魔法队友

定位：

- 治疗、护盾、净化、增益。
- 很像主角现实世界的某位异性好友。

支援技能：

- 治疗。
- 护盾。
- 清除异常状态。
- 攻击力或防御力提升。

好感度成长：

- 好感度提升后减少冷却。
- 治疗量提高。
- 治疗后附带护盾。
- 高好感时，断限追击成功后可给主角空中护盾。

### 黑魔法队友

定位：

- 输出、减益、控场。
- 很像主角现实世界的另一位异性好友。

支援技能：

- 黑炎范围伤害。
- 减速法阵。
- 破防诅咒。
- 暗影禁锢。

好感度成长：

- 好感度提升后增加伤害。
- 延长减益时间。
- 降低敌人防御。
- 高好感时可减缓 Boss 保护条增长，或延长断限追击窗口。

### 剑盾护卫队友

定位：

- 防御、格挡、反击、保护。
- 很像主角现实世界的另一位异性好友。

支援技能：

- 紧急格挡。
- 嘲讽。
- 反击斩。
- 短暂霸体。

好感度成长：

- 好感度提升后格挡强度提高。
- 支援冷却降低。
- 濒死时自动救场一次。
- 断限追击失败时可帮主角挡下一次反击。

## 6. 好感度系统

好感度不是单纯剧情数值，而是战斗系统的一部分。

核心变量：

- 每名队友独立好感度。
- 信赖阶段。
- 角色事件解锁。
- 支援技能等级。
- 路线标记。
- 后宫关系确认状态。

影响内容：

- 支援技能冷却时间。
- 支援技能伤害。
- 治疗量。
- 护盾量。
- 增益时间。
- 减益时间。
- Boss 保护条增长速度。
- 断限追击窗口。
- 断限追击失败惩罚。
- 特殊战斗台词和合体演出。

设计原则：

- 好感度要让玩家感受到角色关系变强。
- 不能让某一个队友变成唯一最优解。
- 每名队友提供不同战术价值。
- 青梅作为正宫拥有最强主线地位，但其他后宫队友也必须有实战意义。

示例：

- 白魔法队友好感 0：治疗 20%，冷却 45 秒。
- 白魔法队友好感 60：治疗 25%，附带小护盾，冷却 35 秒。
- 白魔法队友好感 90：治疗后 8 秒内提升攻击力。
- 黑魔法队友好感 60：黑炎附带破防。
- 剑盾队友好感 90：濒死时自动救场一次。

## 7. 战斗系统总览

正式战斗类型：

- 2D 横板房间制清版动作。
- 主角单人主控。
- 队友以头像支援技能参与。
- 一段跳。
- 强调浮空、连击、技能衔接、Boss 读招和高阶空连。

基础操作：

- 左右移动。
- 一段跳。
- 闪避 / 冲刺。
- 普攻连段。
- 上挑。
- 空中攻击。
- 剑技。
- 魔法。
- 魔剑融合技。
- 队友支援。
- 奥义。

玩家资源：

- HP：生命值。
- MP：魔法技能资源。
- SP：剑技、闪避、冲刺资源。
- 魔剑槽：高级取消、断限追击、魔剑融合技资源。
- 奥义槽：高成本终结技资源。
- 连击数：评分、奖励、部分机制触发条件。

敌人状态：

- 普通。
- 硬直。
- 浮空。
- 击退。
- 倒地。
- 霸体。
- 防御。
- 破防。
- Boss 保护。

基础战斗循环：

- 找机会接近或躲避。
- 普攻 / 技能起手。
- 上挑或破防制造浮空。
- 跳跃后用空中普攻 / 跳斩继续连段。
- 近战和魔法交替衔接。
- 队友支援提供治疗、破防、控场或保护。
- 资源足够时用魔剑技或奥义收尾。
- Boss 进入保护后回到立回，高手则尝试断限追击。

## 8. 第一关假玩法

当前类元气骑士 / 坦克大战模块保留。

用途：

- 作为第一关。
- 故意让玩家误以为游戏玩法很粗糙。
- 配合剧情制造反差。
- 战斗结束后揭示：刚才只是主角力量未觉醒时的异常表现。
- 下一段剧情触发真正横板战斗系统。

架构要求：

- 当前模块继续作为独立玩法模块存在。
- 后续新增正式 `SideCombat` 横板战斗模块。
- 不把假第一关逻辑混进正式横板战斗。

## 9. 正式横板战斗规则

初版动作配置：

- 普攻：3 段或 4 段连击。
- 上挑：把轻型敌人打入浮空。
- 空中普攻 / 跳斩：跳跃后按普攻自动触发，用来维持浮空硬直。
- 空中追斩：跳斩的强化派生，用来追住即将坠落的敌人。
- 冲刺斩：位移追击和连招衔接。
- 火球：基础远程魔法。
- 魔法爆发：短距离范围魔法。
- 闪避：短暂无敌帧。
- 白魔法支援：治疗 / 护盾。
- 黑魔法支援：伤害 / 破防 / 控场。
- 剑盾支援：格挡 / 反击 / 霸体保护。

跳跃规则：

- 主角普通状态只有一段跳。
- 跳跃用于躲避远程攻击、地面冲击波、陷阱和接空中连招。
- 跳跃后的 `J` 键基础攻击默认可用，不需要技能树解锁；技能树只强化它的滞空、追击和取消。
- 不设计普通二段跳。
- 只有满足高难条件触发断限追击时，才允许临时刷新一次空中跳跃。

Boss 规则：

- Boss 默认不能被无限连到死。
- Boss 拥有受击保护条。
- Boss 被持续控制、浮空、硬直时，保护条逐渐增加。
- 保护条满后，Boss 会强制坠落、恢复霸体、反击或进入短暂无敌。
- 高手可以通过断限追击临时突破这个限制，但必须付出资源、输入和风险。

## 10. 核心高级机制：断限追击

断限追击是本游戏正式战斗系统的核心高手机制。

基础原则：

- 基础移动没有二段跳。
- 普通玩家只能一段跳。
- 空中再跳不是常驻能力，而是高难连招奖励。
- Boss 保护条依然存在，防止无脑无限连。
- 断限追击允许高手在严格条件下重置跳跃、滞空、技能取消和 Boss 受击保护。

机制定位：

- 基础战斗：浮空连击。
- 高级机制：断限追击。
- 最高级表现：空界连锁。

触发条件：

- 连击数达到门槛，例如 30 Hit 以上。
- Boss 处于空中坠落或即将脱离连击的短窗口。
- Boss 保护条接近满值，或刚刚触发保护。
- 玩家在约 0.3 秒窗口内输入特定指令，例如上方向加技能键。
- 消耗至少 1 格魔剑槽。
- 当前连招中至少使用过一次近战技和一次魔法技。
- 后续可以要求特定队友支援标记 Boss，作为高难路线条件。

成功效果：

- Boss 坠落被打断。
- Boss 保护条清空一部分、延迟触发，或短暂重置。
- 主角获得一次临时空中跳跃刷新。
- 空中攻击次数刷新，特别是跳斩 / 空中追斩次数刷新。
- 空中技能取消次数刷新。
- 主角重新获得短暂滞空。
- Boss 被重新打入可连击的浮空状态。
- 播放强表现特效：魔法阵碎裂、时间停顿一瞬、剑痕锁住 Boss、空中踏步爆光。

表现目标：

- Boss 快掉下去时，主角在空中踩碎魔法阵一样再次跃起。
- 玩家感觉自己不是获得普通二段跳，而是在打破世界规则。
- 成功瞬间要有明显音效、停顿、震屏和 UI 提示。

失败效果：

- 主角落地或丢失连击。
- Boss 加速恢复。
- Boss 可能反击。
- 魔剑槽已消耗不返还。
- 高好感剑盾队友可以抵消一次失败惩罚。

递增难度：

- 第一次断限追击：窗口约 0.35 秒，消耗 1 格魔剑槽。
- 第二次断限追击：窗口约 0.25 秒，消耗 1.5 格魔剑槽。
- 第三次断限追击：窗口约 0.18 秒，Boss 开始获得抗性。
- 第四次以后：只有特定 Boss 弱点阶段、特殊装备或高好感队友辅助下才能继续。

伤害与奖励：

- 每次连续断限后，伤害倍率可以轻微降低，例如降低 10%。
- 不要削得太狠，因为玩家辛苦打出来就应该爽。
- 连击评分提高。
- 奥义槽增长提高。
- 稀有掉落评分提高。
- 战斗结算给“空界连锁”类评价。

与好感度结合：

- 白魔法队友高好感：断限成功后给空中护盾，防止被反击打断。
- 黑魔法队友高好感：延长断限窗口，或降低 Boss 保护条增长速度。
- 剑盾队友高好感：断限失败时自动格挡一次 Boss 反击。
- 青梅高好感 / 主线觉醒：解锁特殊断限技，暗示她和主角的灵魂、穿越魔法、魔剑士能力存在绑定。

玩家分层：

- 普通玩家：打浮空，打一套，Boss 保护，落地重开。
- 熟练玩家：利用队友支援和魔剑槽多延长一轮输出。
- 高手玩家：浮空连击，断限追击，再连，再断限，最后空中奥义收尾。

设计目标：

- 这不是漏洞，也不是系统被玩家玩坏。
- 这是系统承认并奖励的高端玩法。
- Boss 仍然有规则和威胁，但高手可以通过技术突破一部分限制。

## 11. 核心循环

本游戏的核心循环是：

`剧情对话 -> 做选择 -> 提升好感度 / 获得线索 -> 进入据点 UI -> 升级角色 / 强化装备 / 解锁技能 / 查看路线 -> 选择刷副本或继续剧情 -> 进入战斗关卡 -> 获得经验、装备、材料、剧情变量 -> 回到剧情或据点`

更具体的玩家流程：

- 玩家先在 VN 场景中推进剧情。
- 选项会影响队友好感度、路线标记、隐藏剧情和部分技能解锁条件。
- 一段剧情结束后，游戏进入据点 UI。
- 据点 UI 提供角色成长、装备强化、魔剑技能树、好感度确认、路线确认、副本重刷和继续剧情等入口。
- 玩家可以选择继续主线，也可以回头刷已解锁副本。
- 战斗副本中，敌人死亡会掉落装备、材料和经验。
- 战斗结束后获得副本评分、经验、材料、装备和可能的剧情变量。
- 玩家回到据点继续强化，再进入下一段剧情或再次刷副本。

设计目标：

- 喜欢剧情的玩家可以顺着主线推进。
- 喜欢刷装备和练连招的玩家可以反复刷副本。
- 喜欢角色关系的玩家可以通过好感度解锁支援强化和特殊技能。
- 视觉小说、角色养成、装备掉落和横板战斗形成闭环。

## 12. 据点 UI

每段主线剧情结束后，玩家进入一个功能型 UI 界面。这个界面相当于“章节间据点”，不是传统大地图，优先保证开发可控和功能清晰。

据点页面结构、从 VN / 战斗结算进入据点的流程、技能树和材料来源跳转、支援配置、存档字段和竖切 UI 范围见 [据点UI流程设计](../01_玩法系统/据点UI流程设计.md)。

据点 UI 功能：

- 继续剧情：进入下一段主线 VN 或下一个主线副本。
- 刷副本：选择已经解锁的战斗关卡重新挑战。
- 角色升级：消耗战斗经验提升主角等级和基础能力。
- 装备强化：使用材料强化武器、防具、饰品等装备。
- 魔剑技能树：消耗材料和条件解锁魔剑近战、魔法、融合技和高级空连能力。
- 好感度确认：查看每名队友的好感度、信赖阶段和支援技能等级。
- 路线确认：查看当前主线阶段、角色事件、后宫关系确认状态。
- 队伍支援配置：选择当前可用的支援队友和技能槽位。

据点 UI 的设计原则：

- 不做成复杂城镇探索，先做成清晰菜单。
- 所有成长和路线信息都集中在这里。
- 玩家每次从剧情或战斗回来，都知道下一步可以做什么。
- 后续如果引擎能力足够，可以把据点升级成可探索场景。

当前制作路线按“系统完整性 -> 统一美术资源升级 -> 音频与反馈升级 -> 内容扩章与商业化打磨”推进，具体执行顺序和功能完成定义见 [商业游戏化路线图](../00_总览/商业游戏化路线图.md)。

## 13. 成长系统

成长分为四条线：

- 主角等级。
- 装备强化。
- 魔剑技能树。
- 队友好感度和支援技能。

### 主角等级

来源：

- 副本战斗经验。
- 主线 Boss 经验。
- 特殊剧情奖励。

提升内容：

- ATK：物理攻击。
- MATK：魔法攻击。
- DEF：物理防御。
- MDEF：魔法防御。
- HP：生命上限。
- MP：魔法资源上限。
- SP：剑技和闪避资源上限。

设计原则：

- 等级提升提供稳定成长。
- 不能完全替代操作和技能搭配。
- 玩家刷副本可以变强，但高难 Boss 仍需要理解机制。

### 装备系统

敌人死亡和副本结算可以掉落装备。

装备槽位、品质、词条、掉落表、强化、套装和逐章掉落规划见 [装备与掉落设计](../01_玩法系统/装备与掉落设计.md)。

装备类型暂定：

- 魔剑：主角核心武器，剧情绑定，可无限升级。
- 防具：提高生命、防御、抗性。
- 饰品：提供特殊属性、资源回复、冷却缩减、连击奖励等。
- 队友信物：可作为好感事件或支援强化的剧情道具。

材料用途：

- 强化装备等级。
- 解锁装备词条。
- 进阶装备品质。
- 解锁部分魔剑技能。

设计原则：

- 魔剑是核心，不应该被普通武器替代。
- 普通装备负责提供养成深度和刷副本价值。
- 装备掉落要服务战斗风格，而不是堆无意义数值。

### 魔剑系统

真青梅在开局后以王国骑士团魔剑士导师的身份，把一把魔剑交给主角。因为她一开始就是满好感，她赠送魔剑既是剧情上的亲密证明，也是后期真相的伏笔。主角前期以为这是导师的善意，后期才知道这是青梅亲手准备的成长舞台。

魔剑定位：

- 主角唯一核心武器。
- 可以无限升级。
- 承载近战、魔法、魔剑融合和高级空连技能树。
- 与青梅的穿越魔法和真实身份存在隐藏联系。

技能树方向：

- 近战分支：普攻派生、上挑强化、冲刺斩、跳斩强化、空中追斩派生、破甲斩。
- 魔法分支：火球、冰刃、雷击、黑炎、魔力爆发。
- 魔剑融合分支：火焰剑气、雷刃突进、冰封斩、魔力爆裂。
- 机动分支：闪避强化、空中滞留、追击距离、落地取消。
- 断限分支：断限追击窗口、魔剑槽消耗降低、空界连锁次数、Boss 保护条压制。

技能解锁条件：

- 消耗指定材料组合。
- 达到主角等级要求。
- 魔剑等级达到要求。
- 已解锁前置技能。
- 部分技能要求指定队友好感度达到门槛。
- 部分终极技能要求主线剧情推进。

示例：

- 火球术：魔晶碎片 + 初级魔核。
- 冲刺斩：兽爪材料 + 铁矿。
- 黑炎剑气：黑魔法队友好感 60 + 暗影结晶 + 魔剑等级 5。
- 空界追击强化：青梅主线觉醒 + 魔剑等级 8 + Boss 材料。
- 白光护身斩：白魔法队友好感 70 + 圣水晶 + 魔剑等级 6。

### 队友好感与支援升级

队友好感度主要通过剧情选择、角色事件和主线推进提升，不需要刷材料。

角色好感阶段、支援技能升级、青梅隐藏好感、王妃 / 天使支援、组合奥义和据点好感面板见 [好感与支援设计](../01_玩法系统/好感与支援设计.md)。

好感度作用：

- 自动提升支援技能等级。
- 解锁支援技能附加效果。
- 解锁角色事件。
- 解锁部分魔剑技能条件。
- 解锁后宫关系确认剧情。

设计原则：

- 队友支援升级不消耗刷本材料，避免玩家为了恋爱线反复刷同一种材料。
- 战斗材料用于装备和魔剑，感情成长用于队友支援。
- 好感度给战斗收益，但要保持各角色定位不同。

## 14. 魔剑技能树 v0.1

魔剑技能树是主角战斗成长的核心。它不只是数值强化，而是逐步解锁玩家在横板战斗中的操作空间、连招路线、Boss 应对方式和后宫支援联动。

详细的连招接口、支援衔接、技能倍率、Boss 保护条和数值公式见 [战斗系统设计](../01_玩法系统/战斗系统设计.md)。小怪、精英怪、章节 Boss、圣兽、七大罪和国师机制见 [敌人与Boss机制表](../01_玩法系统/敌人与Boss机制表.md)。主线副本、材料副本、试炼副本、据点入口和编辑器数据字段见 [关卡与副本策划方案](../01_玩法系统/关卡与副本策划方案.md)。装备词条和掉落经济见 [装备与掉落设计](../01_玩法系统/装备与掉落设计.md)，好感路线和支援升级见 [好感与支援设计](../01_玩法系统/好感与支援设计.md)，据点 UI 流程见 [据点UI流程设计](../01_玩法系统/据点UI流程设计.md)，首个可玩版本的工程拆分见 [竖切实现清单](../02_竖切版本/竖切实现与交互记录.md)。竖切 VN 剧本见 [竖切VN剧本](../02_竖切版本/竖切VN剧本.md)，黑熊丈夫 Boss 参数见 [黑熊丈夫Boss参数表](../02_竖切版本/竖切Boss与材料副本配置.md)，黑林兽道副本配置见 [黑林兽道副本配置表](../02_竖切版本/竖切Boss与材料副本配置.md)，竖切美术提示词见 [竖切美术资源提示词](../02_竖切版本/竖切美术资源生产指南.md)。总纲只保留系统骨架，具体手感、关卡、装备、关系和制作落地以后以专项设计文档为准。

记录方式：

- 当前阶段使用 Markdown 作为企划母稿，不需要下载额外策划软件。
- 后续实现时可以把本节拆成 CSV / JSON / YAML 数据表，由编辑器读取。
- 建议数据字段：`SkillId`、`Branch`、`Tier`、`Name`、`Type`、`UnlockChapter`、`Prerequisites`、`MaterialTags`、`AffectionGate`、`BlessingGate`、`Effect`、`UpgradeNotes`。

总规则：

- 魔剑技能分为五个分支：近战、魔法、魔剑融合、机动、断限。
- 技能类型分为主动技、被动技、派生技和机制技。
- 普攻、跳跃、空中普攻 / 跳斩、闪避、断限追击等核心机制不一定占用主动技能槽。
- 剑技、魔法、魔剑融合技需要装备到技能槽后才能在战斗中主动释放。
- 每个主动技默认有 3 级：Lv1 解锁基础效果，Lv2 增强范围 / 伤害 / 冷却，Lv3 增加派生或特殊效果。
- 魔剑在第十二章天使祝福后彻底点满；第十三章到第十六章不再新增魔剑技能，只通过等级、装备、好感度和支援组合提升战力。

推荐技能槽：

- 固定操作：普攻、跳跃、闪避、上挑、空中普攻 / 跳斩。
- 剑技槽：2 个，后期可扩展到 3 个。
- 魔法槽：2 个，后期可扩展到 3 个。
- 魔剑融合槽：1 个，后期可扩展到 2 个。
- 奥义槽：1 个。
- 队友支援槽：3 个，青梅和王妃加入后可扩展或轮换。

### 14.5 机动分支

| 第二章 | 让玩家掌握普攻、上挑、跳斩、闪避、火球和第一把魔剑的基础爽感。 |
| 第三章 | 通过白魔法队友引入保命、护盾和白光联动，让新手更容易打完早期副本。 |
| 第四章 | 通过剑盾队友引入破甲、防御、反击、受身和失败保护。 |
| 第五章 | 通过黑魔法队友引入减益、控场、黑炎和 Boss 保护条压制预告。 |
| 第六章 | 正式让玩家看到 Boss 保护条，开始学习不能无脑连 Boss。 |
| 第七章 | 正式解锁断限追击，让高手玩法开始成立。 |
| 第一部终章 | 通过真青梅 Boss 战检验第一部全部技能，并解锁青梅正宫支援。 |

## 15. 掉落与副本重刷

详细的逐章副本表、房间结构、重刷副本、试炼副本和编辑器落地字段见 [关卡与副本策划方案](../01_玩法系统/关卡与副本策划方案.md)。装备槽位、词条、掉率、保底、套装和逐章掉落规划见 [装备与掉落设计](../01_玩法系统/装备与掉落设计.md)。本节只保留掉落和重刷的总规则。

副本可以无限重刷。

副本奖励来源：

- 敌人死亡掉落。
- 精英怪掉落。
- Boss 掉落。
- 副本通关奖励。
- 副本评分奖励。
- 首通奖励。

掉落类型：

- 经验。
- 金钱或通用货币。
- 装备。
- 强化材料。
- 魔法材料。
- Boss 专属材料。
- 剧情道具。

材料设计：

- 不同技能需要不同材料组合。
- 近战技能偏向兽爪、金属、骨片等。
- 魔法技能偏向魔晶、元素核心、法师残页等。
- 魔剑融合技能需要混合材料。
- 断限追击相关技能需要 Boss 材料、稀有魔晶或青梅主线材料。

副本重刷价值：

- 获取强化材料。
- 刷更好装备。
- 练习连招和断限追击。
- 提高通关评分。
- 补足技能树材料。

限制原则：

- 主线推进不能被刷材料完全替代。
- 关键技能可以要求剧情进度，避免玩家早期刷爆系统。
- 高级技能可以要求材料、等级、魔剑等级和好感度共同满足。

## 16. 圣兽祝福与天使祝福

第一部结束后，魔剑并没有彻底完成。第二部前半段的目标是获得四圣兽祝福和天使祝福，把魔剑技能树完全点满。

祝福结构：

- 青龙祝福：对应青梅正宫，强化速度、风雷、空中追击、魔剑槽循环。
- 白虎祝福：对应黑魔法队友，强化杀伐、破甲、Boss 保护条压制。
- 朱雀祝福：对应白魔法队友，强化火焰、复苏、护盾、濒死反击。
- 玄武祝福：对应剑盾护卫队友，强化守护、霸体、格挡、反击。
- 天使祝福：对应王妃，补完魔剑最终技能树，解锁净化、神圣伤害、终极支援和额外生命。

圣兽章节目标：

- 每一章培养一名后宫角色。
- 每一章强化一种支援体系。
- 每一章解锁一组魔剑高阶技能。
- 每一章提供一个大型试炼 Boss。

天使祝福目标：

- 四圣兽祝福后，玩家发现魔剑仍缺最后一块力量。
- 王妃的天使转生身份不由她主动坦白，而是通过敌方法阵反应、追兵之口和天使记忆试炼逐步揭示。
- 她与主角缔结神圣伴侣契约，产生“天使之泪”。
- 天使之泪补完魔剑技能树。
- 王妃正式进入后宫，并获得终极支援技能。
- 天使祝福提供额外生命：每场战斗可复活一次，或致命伤时保留 1 点 HP 并触发短暂无敌。
- 魔剑完全觉醒后必须安排试刀 Boss，让玩家立即体验满级魔剑的压制力。

设计原则：

- 四圣兽是角色好感和战斗系统的中后期强化。
- 天使祝福是魔剑成长的最后钥匙。
- 重要真相尽量通过事件、敌人之口、战斗反应、记忆碎片和试炼揭露，少用角色直接坦白。
- 成人向情节可以在具体剧本中用 Galgame 式暗示表达；系统文档统一使用“神圣伴侣契约”和“天使之泪”。

## 17. 七大罪决战结构

魔剑彻底觉醒后，魔剑本身不再继续升级。最终篇成长重点转为：

- 主角等级。
- 装备掉落。
- 装备强化。
- 后宫角色好感补满。
- 支援技能组合。
- 针对 Boss 机制选择队伍配置。

七大罪怪物：

- 傲慢：高防御、高压制、惩罚玩家正面硬打。
- 怠惰：减速、封技能、拖慢节奏。
- 贪婪：偷取资源、吸收掉落、干扰奖励。
- 暴食：吞噬召唤物、弹幕、地形和玩家资源。
- 色欲：精神控制、魅惑、干扰支援。
- 嫉妒：复制主角技能和后宫支援。
- 暴怒：高霸体、高伤害、持续爆发。

四个最终战场：

- 第一战场：傲慢 + 怠惰。
- 第二战场：贪婪 + 暴食。
- 第三战场：色欲 + 嫉妒。
- 第四战场：暴怒 + 国师。

战斗设计：

- 每个战场主角都要面对一敌二压力。
- 每个七大罪 Boss 都要求不同支援组合应对。
- 玩家不能再靠魔剑升级解法无脑碾压，必须理解装备、属性、祝福和支援技能。
- 好感度在最终篇逐渐满值，让后宫队伍在战斗和剧情上同步完成。
- 国师最终战要检验玩家对断限追击、空界连锁、队友支援、装备配置和奥义收尾的掌握。

示例应对关系：

- 傲慢：白虎破甲 + 黑魔法破防。
- 怠惰：青龙速度 + 白魔法净化。
- 贪婪：玄武防护 + 资源回复装备。
- 暴食：朱雀爆发 + 火焰魔剑融合技。
- 色欲：青梅正宫支援 + 天使净化。
- 嫉妒：黑魔法识破 + 高机动连招。
- 暴怒：剑盾支援 + 玄武霸体 + 断限追击爆发。
