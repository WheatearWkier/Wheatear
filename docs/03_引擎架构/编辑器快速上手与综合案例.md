# WheatearEditor 快速上手与综合案例

> 面向新用户（策划 / 美术 / 程序）：15 分钟上手编辑器，最后一章用完整案例演示如何
> 用纯编辑器操作构建一个包含剧情、事件、战斗、动作与成长系统的可玩 demo。
> 详细的面板参数说明见《编辑器操作手册.md》。

---

## 1. 快速上手

### 1.1 启动

1. 运行 `Builds\Windows\Editor\WheatearEditor.exe`。
2. 启动画面选择模式：
   - **2D 模式**（主路径）：精灵、物理、动画
   - **3D 模式**：网格、PBR / IBL、光照

### 1.2 界面布局

| 区域 | 内容 |
|---|---|
| 顶部菜单栏 | 场景 / 编辑 / 运行 / UI / 窗口 / 玩法 / 资源 / 构建 / 诊断 / 应用 |
| 视口上方悬浮工具栏 | 新建/打开/保存 ｜ 播放/暂停/步进/聚焦 ｜ 内容工具 ｜ 项目健康/打包/重置布局/内容抽屉 |
| 左侧 | 场景层级（Scene Hierarchy） |
| 右侧 | 属性（Properties）+ 统计/玩家构建 |
| 底部 | 资源浏览器（Content Browser） |
| 中央 | 视口（Viewport）+ UI 画布编辑器 |

所有面板可拖动停靠；「窗口」菜单可弹出/停靠任意工具；「重置窗口布局」恢复默认。

### 1.3 全局快捷键

| 按键 | 功能 |
|---|---|
| Ctrl+N / Ctrl+O / Ctrl+S / Ctrl+Shift+S | 新建 / 打开 / 保存 / 另存为场景 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做 |
| Ctrl+Enter | 播放 / 停止 |
| F6 / F7 | 暂停 / 单帧步进 |
| F | 聚焦选中（无选中则聚焦全场景） |
| Ctrl+D | 复制选中实体 |
| Delete | 删除选中实体（编辑模式） |
| Q / W / E / R | gizmo：无 / 移动 / 旋转 / 缩放 |
| Esc | 关闭内容抽屉 → 退出播放 → 取消选择 |
| 视口 Alt+左键 / Alt+中键 / Alt+右键 | 旋转 / 平移 / 缩放相机 |
| 视口按住右键 | 飞行模式（WASD 移动、Q/E 上下、Shift 加速、Ctrl 减速） |

> 任何输入框激活时全局快捷键自动让路（不会误触删除/保存）。

### 1.4 资源浏览器要点

- **缩略图**：图片显示真实预览；场景 / 预制体 / UI 模板 / 模型会**自动渲染离屏缩略图**（逐帧生成，浏览时稍等即出现）
- **双击**：目录=进入；场景=打开；预制体/UI 模板=实例化；.vn/.wts=打开对应编辑器
- **右键**：打开 / 资源管理器显示 / 复制路径 / 重命名（F2）/ 删除（Del，带确认）
- **键盘**：Enter 打开、Backspace 后退、Del 删除、F2 重命名
- **拖拽**：拖到视口（场景/预制体/纹理）或动画编辑器图集区
- **内容抽屉**：工具栏文件夹图标，底部弹出式抽屉（UE 风格），Esc/点外部关闭

## 2. 场景搭建

1. **新建场景**：Ctrl+N（有未保存修改会先询问）。
2. **创建实体**：层级窗口右键空白 →「创建空实体 / 2D Object（精灵、圆形）/ 相机 / UI（画布、面板、图片、文本、按钮、滑块…）/ 游戏模板」；或右键实体 →「创建 UI / 复制 / 另存为 Prefab / 删除」。
3. **改属性**：选中实体 → 右侧 Properties：
   - 改名：Tag 输入框，或选中后按 **F2 行内重命名**（Enter 提交）
   - 加组件：**Add Component**（弹窗带搜索框，按分类分组）
   - 组件值修改自动支持 Ctrl+Z 撤销
4. **层级操作**：↑↓ 键移动选择；搜索框过滤；「UI」勾选只看 UI；UI 子节点可拖拽换父；行内 Hide/Show 按钮。
5. **视口**：单击选实体、双击聚焦；Q/W/E/R 切 gizmo，**Ctrl 吸附**（旋转 45°、移动 0.5）；右键视口=创建实体菜单；Alt 键组合旋转/平移/缩放相机。
6. **播放**：Ctrl+Enter 进入播放，F6 暂停，F7 单帧，Esc 退出。

## 3. 内容制作工具

所有工具入口：主菜单「玩法」或工具栏图标；也常可从属性组件上的按钮直达。

### 3.1 VN 剧情（Visual Novel Script Editor）
- 新建：工具栏 Script 字段输入新路径（如 `assets/vn/my_story.vn`）→ 点 Save（自动创建文件）
- 编辑：**Timeline** 页签用顶部「+ 对白 / + BGM / + 选项 / + 角色 / + 显示 / + 隐藏 / + 表情 / + 跳转 / + 标签 / + 结束 / + 变量 / + 条件 / + 速度 …」在当前行后插入；右侧编辑字段
- 选项带条件：Required Flag / Required Condition（如 `gold >= 5`、`not flag FLAG_X`）
- 悬空跳转目标会显示黄色徽章警告
- 保存后场景实体挂 **Visual Novel 组件**（Add Component 搜索 "Visual Novel"）绑定脚本路径

### 3.2 事件编排（Event Script Graph）
- 新建：资源浏览器右键 →「New Event Script (.wts)」自动打开编辑器
- 画布：右键/中键拖平移、Ctrl+滚轮缩放；**节点调色板**添加：Scene 跳转 / Event Call / Set Flag / Dungeon / Save / Raw Command / Add Wait / Add If / Add EndIf
- **Wrap In If** 给节点包条件分支；if/endif 不配对有自动修复按钮
- 选中节点：Type 下拉可转换、命令构建器自动补全 `scene:`/`event:`/`progression:` 等前缀
- Delete 键删节点（详情面板聚焦时）；Save Graph 写回
- 场景实体挂 **Event Script 组件**绑定脚本与 Start Event

### 3.3 战斗调参（Side Combat Tuning Editor）
- 打开：玩法 → Side Combat Tuning Editor（或选中 Side Combat Level 实体 → 组件按钮）
- 7 个页签：**Feel**（手感：移动/跳跃/冲刺/挑空/断连）、**Rules**（规则：伤害/连段/敌人数值/拾取）、**Attacks**（攻击：命中框/伤害帧数据/VFX/SFX）、**Animations**（动画：id 下拉 + Add 新建，配置图集与帧）、**Skills**（技能：输入/连段角色/章节解锁）、**Progression**（成长：默认配置/解锁/显示开关）、**Advanced Raw**
- 保存写回 YAML（解析失败会强制进 Raw 修复）

### 3.4 HUD 预设（Side Combat HUD Preset Editor）
- **Bindings** 绑定场景实体名（玩家/血条/连段文本…）
- **Layout** 布置 HUD 矩形（归一化坐标）；**Slots** 配置技能槽/物品槽（按键、命令、图标）；**Text** 改全部文案
- 组件上「Apply HUD Preset」一键应用

### 3.5 WAO 动作（WAO Action Editor）
- 打开：玩法 → WAO Action Editor
- **Action Set 下拉**选写入的 YAML 组 →「New Action」新建（自动唯一 id）→「Edit Recipe」进入编辑：
  - 基本信息、Timing（前后摇/取消窗）、Params 表格、Effects（Add Damage / Add Heal / Add State / Add Signal）
- **Validation** 页签检查错误/警告；**Preview** 看时序条与沙盒（**Run in Sandbox** 免进播放测试效果）
- Rename 会自动替换项目内所有点分引用；Save YAML 写回

### 3.6 成长内容（Progression Content Editor）
- 打开：玩法 → Progression Content Editor
- **文件列表**选类型（skillNodes / equipment / materials / dungeons / defaults / upgrades …）
- **Skill Tree 页签**（技能树画布）：Add Skill 建节点、**拖拽节点布局**、点选改字段（名称/分支/解锁章节/父节点/坐标）、**Bake Layout To YAML** 写回坐标；重复 id 有红色警告
- **Content 页签**：equipment 物品（名称/插槽/属性/图标）、dungeons 副本（章节/奖励/剧情旗标）、relationships 好感度
- **defaults**：初始技能/装备/旗标；**upgrades**：升级配方（消耗/属性加成/解锁技能）

### 3.7 动画与序列帧
- 动画编辑器绑定带 **Sprite Animator** 组件的实体：`+ Add Clip` → 时间线双击加关键帧/事件、拖拽移动、右键编辑；**空格**播放/暂停；Save Clip As 存 .wtanim
- **图集生成器**：从资源浏览器拖纹理进去 → 设置行列 → Generate Frames
- **序列帧选择器**：点击格子选帧（黄色框）→ Apply To SpriteRenderer / Apply To UI Image / Replace Clip With Sequence（替换会弹确认）

## 4. UI 制作

1. 层级右键 → UI → Canvas 创建画布；再建 Panel/Text/Button 等。
2. 工具栏「UI 画布编辑器」打开画布（或双击 UI 实体）：
   - **单击选择**（按层级取最上层）、拖拽移动/缩放（8 个手柄）、自动联动锚点
   - 顶部 Use Selected Canvas 换画布；Undo/Redo/Ctrl+Z 生效；Save 存场景
   - 菜单「UI → UI Edit Outlines」开关所有部件的青色线框与名称标签
3. 布局用归一化坐标（Position/Size 0~1），缩放字号自动适配。

## 5. 项目健康与打包

- **项目健康**（工具栏图标）：10 个页签查缺失引用/重复资源/未使用资源/硬编码路径等；**Asset Hygiene** 可生成清理计划并归档
- **打包**（工具栏图标）：自动保存场景 → 选 Startup Scene（`assets/scenes/` 下）→ Build Configuration（Debug/Release/Dist）→ 异步构建 → 打开玩家目录运行

## 6. 综合案例：用编辑器构建一个 sandbox 级可玩 demo

> 目标：从空场景开始，用纯编辑器操作做出一个包含**开场剧情（VN）→ 据点（技能树/背包）→ 战斗（SideCombat + WAO 动作）**的完整玩法闭环，并打包运行。全程不写代码。

### 第 1 步：规划与场景骨架

1. Ctrl+N 新建场景，Ctrl+S 保存为 `assets/scenes/MyDemo.wt`。
2. 层级窗口右键空白：
   - **2D Object → Sprite**：创建「Ground」（地面，Properties 里拖入一张图片纹理并设 Position）
   - **2D Object → Sprite**：创建「Player」（玩家，放地面之上）
   - **Camera → Camera**：创建「Main Camera」
   - **UI → Canvas**：创建 UI 画布（后续放血条/对话底）
3. 选中 Camera，Properties 勾选 Primary（主相机）；播放一次（Ctrl+Enter）确认画面。

### 第 2 步：开场剧情（VN）

1. 玩法 → VN Script Editor；顶部 Script 字段输入 `assets/vn/my_demo_intro.vn` → 点 **Save**（自动创建）。
2. Timeline 页签依次添加：
   - `+ 角色 Character`：id `hero`，显示名「勇者」
   - `+ 对白 Dialogue`：Speaker 选 hero，输入台词
   - `+ 选项 Choice`：两个选项——「出发冒险」和「先去商店」（第二项加 Required Flag 或 Condition 做分支）
   - 选项后各接 `+ 跳转 Goto` 指向 `@adventure` / `@shop` 标签；用 `+ 标签 Label` 建两个标签
   - 末尾 `+ 结束 End`
3. Save 保存；检查黄色悬空跳转徽章（有则改 Target Label）。
4. 层级创建实体「IntroTrigger」，Add Component 搜索 **Visual Novel**，Script Path 填 `assets/vn/my_demo_intro.vn`。

### 第 3 步：据点与技能树 / 背包（Progression）

1. 玩法 → Progression Content Editor。
2. 文件列表选 `skillNodes` 文件 → **Skill Tree 页签**：
   - Add Skill 建「基础剑术」「冲刺」「二段跳」三个节点
   - 选中节点改 Name / Branch / Unlock Chapter；Parent 下拉把「冲刺」「二段跳」挂到「基础剑术」下
   - **拖拽节点**排布 → **Bake Layout To YAML**
3. 文件列表选 `equipment` → Content 页签：Add Record 建「铁剑」（Slot 选 weapon、Icon 选一张图片、Stats 加攻击力）与「治疗药水」（Slot item）。
4. 选 `defaults`：Initial Unlocked Skills 加「基础剑术」；Initial Owned Equipment 加「铁剑」与「治疗药水」。
5. Save Manifest。
6. 剧情串联：VN 选项「先去商店」后加一行 `+ 变量 Set`（如 `gold = 5`）与 `+ 条件 If`（`gold >= 5` → 跳转）——条件/旗标与 Progression 联动；事件脚本里用 `progression:set_flag FLAG_HUB_UNLOCKED` 解锁据点。

### 第 4 步：事件编排（Event Script）

1. 资源浏览器右键 → **New Event Script (.wts)**（自动打开事件图）。
2. Add Event「on_start」；节点调色板依次添加：
   - **Set Flag**：`progression:set_flag FLAG_DEMO_STARTED`
   - **Add Wait**：0.5 秒（开场停顿）
   - **Add If**：`flag FLAG_HUB_UNLOCKED` → 里面加 **Event Call**（调用商店事件）→ **Add EndIf**
   - **Raw Command**：输入 `scene:assets/scenes/MyDemo.wt`（跳场景）
3. Save Graph。
4. 场景实体（如 Player）Add Component 搜索 **Event Script**，Script Path 填该 .wts、Start Event 填 `on_start`。

### 第 5 步：战斗配置（SideCombat + WAO）

1. **调参**：玩法 → Side Combat Tuning Editor：
   - Feel 页：调移动速度、跳跃、冲刺（看着舒适即可）
   - Attacks 页：Attack 下拉选攻击，调伤害/前摇/后摇
   - Animations 页：Player Animations 输入框输入 `player_attack` → **Add** → 配置图集（拖一张序列帧图、行/列/帧率）
   - Skills 页：Skill 下拉 → 设 Input、Attack Ids
2. **WAO 动作**：玩法 → WAO Action Editor：
   - Action Set 选 SideCombat 组 → **New Action**（id 如 `side_attack`）
   - **Edit Recipe**：Animation Id 填 `player_attack`（与调参面板一致）；Effects 区 **Add Damage**（设数值）；Add Target Rule 保持 EnemySingle
   - **Run in Sandbox** 测试效果（绿色+红色属性变化）→ Save YAML
3. **HUD**：玩法 → Side Combat HUD Preset Editor：Bindings 把玩家/血条/连段文本绑定到场景实体名；Slots 给「冲刺」「治疗」绑按键（命令 `side:skill:dash` 等）；Save Preset。
4. 场景创建战斗区域：Add Component 搜索 **Side Combat Level**，Tuning 路径指向调参文件、HUD Preset 指向预设——播放即进入横版战斗。

### 第 6 步：把剧情与战斗串起来

在 VN 编辑器里给结局选项接 `+ 原始 Raw` 行输入 `side:enter_battle`（或通过事件图的 Event Call + 命令构建器）——**对话结束后直接进战斗**；战斗胜利后可用旗标/Progression 发放奖励（物品进背包，背包数据在 defaults / equipment 里已配好）。

### 第 7 步：打包运行

1. 工具栏「Package Player + Editor」：自动保存场景 → Startup Scene 选 `MyDemo.wt` → Build Configuration 选 Debug → Package。
2. 完成后点 **Open Player Folder** 运行玩家包——完整 demo 闭环：开场剧情 → 据点/商店（技能树与背包生效）→ 事件触发 → 横版战斗（WAO 动作 + HUD）。

> 关键理念：**所有内容都是数据**——场景是 .wt、剧情是 .vn、事件是 .wts、战斗是 YAML、动作是 recipe、成长是 manifest；编辑器面板只是这些数据的可视化编辑界面。内容改完点保存，运行即生效。
