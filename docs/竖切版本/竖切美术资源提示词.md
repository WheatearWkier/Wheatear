# 《Wheatear 异世界项目》竖切美术资源生成提示词 v0.1

## 0. 文档定位

本文档负责第一个可玩竖切所需美术资源的生成提示词、规格、命名和打包标签。

目标：

- 替换当前 demo 中的方块和临时素材。
- 让 VN、正式横板战斗、据点 UI 和掉落图标风格统一。
- 优先生成能直接放入 Wheatear 项目的 2D 资源。

注意：

- 不使用任何现有商业作品角色名或特定画师名。
- 统一使用原创二次元幻想风。
- 所有图像避免文字、水印、logo。
- 角色年龄表现使用青年，不做低龄化或擦边设计。

## 1. 全局美术风格

统一风格关键词：

```text
original anime fantasy game art, clean cel shading, expressive character design, polished visual novel illustration, vibrant but readable colors, sharp silhouette, consistent lighting, high detail, game-ready asset
```

统一负面词：

```text
text, logo, watermark, signature, blurry, low resolution, extra fingers, malformed hands, duplicate face, bad anatomy, cropped head, overexposed, underexposed, photorealistic, 3d render, western comic style
```

色彩方向：

- 现实世界：清晨、柔和、干净、淡蓝和暖阳。
- 异世界黑林：冷绿、暗紫、少量魔法蓝光。
- 魔剑觉醒：黑银、青蓝魔光。
- 据点：夜色、篝火、暖橙和深绿对比。
- UI 图标：清晰、高对比、边缘干净。

## 12. 生成与筛选规则

生成后筛选标准：

- 角色脸部可读，表情明确。
- 立绘透明背景干净。
- 战斗 Sprite 轮廓清楚，缩小后还能识别动作。
- 背景留出对话框和 UI 空间。
- 图标在 64x64 下仍然能看懂。
- 同一角色不同表情五官一致。
- 同一敌人不同动作体型一致。
- 不出现文字、水印、logo。

不合格直接重生：

- 手指明显错误。
- 角色左右脸差异太大。
- Sprite 动作看不出攻击方向。
- 背景过暗导致角色看不清。
- UI 图标像照片或 3D 渲染。
