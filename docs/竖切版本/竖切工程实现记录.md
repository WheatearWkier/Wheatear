# 《Wheatear 异世界项目》竖切工程实现记录 v0.6

## 0. 文档定位

本文档记录竖切版本在工程中的实际落地位置，避免策划文档、代码模块、场景资源和临时美术脱节。

当前竖切目标：

`主菜单 -> 序章 VN -> 第一章假玩法 -> 第二章正式横板战斗 -> 掉落结算 -> 据点 UI -> 魔剑/装备强化 -> 重刷副本 / 继续剧情`

## 1. 工程模块

### 1.1 新增运行时模块

| 模块 | 路径 | 职责 |
| --- | --- | --- |
| `SideCombat` | `Wheatear/src/Wheatear/Modules/SideCombat/` | 正式横板战斗，不进入引擎基础 `Systems` |
| `Progression` | `Wheatear/src/Wheatear/Modules/Progression/` | 竖切阶段的进度、材料、经验、魔剑升级、据点状态刷新 |

`SideCombat` 当前组件：

| 组件 | 职责 |
| --- | --- |
| `SideCombatLevelComponent` | 关卡边界、纵深战斗带、调参表路径、UI 绑定、胜负跳转、连击和奖励运行态 |
| `SideCombatantComponent` | 玩家和敌人的生命、攻防、脚下碰撞、空中高度、浮空速度、硬直、受控状态、Boss 保护条运行态 |
| `SidePlayerControllerComponent` | 一段跳、横向推进、纵深走位、普攻、上挑、魔法弹、支援冷却、魔剑槽运行态 |
| `SideEnemyAIComponent` | 小怪 / Boss 基础 AI、纵深追踪、攻击距离和纵深容差 |
| `SideHitboxComponent` | 攻击判定、伤害、空中命中区间、浮空速度、硬直、Boss 保护增长、特效序列帧 |
| `SidePickupComponent` | 掉落材料、吸附半径、拾取速度 |

`Progression` 当前职责：

| 文件 | 职责 |
| --- | --- |
| `GameProgress.*` | 竖切内存进度：等级、经验、属性、材料、首通/重刷、副本解锁、魔剑 Lv2、旅人护衣 +1 |
| `ProgressionSystem.*` | 据点 UI 刷新：目标、材料、属性、按钮文案和升级结果 |

注意：当前 `Progression` 是竖切可玩闭环，不是最终存档格式。未来正式化时应继续拆出持久化 `SaveGame`、背包 `Inventory`、装备实例 `Equipment` 和好感 `Relationship`，但据点 UI 可以先按这套接口跑通。

## 3. 当前战斗输入

| 输入 | 行为 | 设计目的 |
| --- | --- | --- |
| `A / D` 或左右方向键 | 左右推进 | 横向推进和追击 |
| `W / S` 或上下方向键 | 纵深走位 | 接近《机甲旋风》式横向清场视角 |
| `Space` | 一段跳 | 躲避远程攻击，也可接空中连击 |
| `J` 或鼠标左键 | 地面普攻三段；空中跳斩 | 每段都能续连，跳斩负责基础空中续连 |
| `K` | 地面裂空上挑；空中追斩 | 主要浮空起手，空中用于续住快下落的目标 |
| `U` | 魔法弹 | 远程续连和补刀 |
| `I` | 真青梅支援 | 较长冷却的浮空续连 |
| `L` | 竖切断限追击调试键 | 当前默认隐藏 UI 提示，只用于测试后期断限底层能力 |
| `Esc / P` | 暂停切换 | 调试和试玩用 |

竖切暂不开放普通二段跳。未来“断限追击”会作为高手机制重置空中行动，而不是常驻二段跳。

### 3.1 当前战斗视角实现

v0.2 已从“平台式 X/Y 重力”改成“横向推进 + 纵深战斗带 + 独立空中高度”：

- `RuntimeGroundPosition.x` 表示左右推进。
- `RuntimeGroundPosition.y` 表示地面纵深站位。
- `RuntimeAirHeight` 表示浮空高度，不再把角色当作平台游戏那样直接改地面 Y。
- 攻击判定同时检查 X 距离、纵深距离和空中高度区间。
- 角色脚下阴影会根据浮空高度淡出，帮助玩家看清 Boss 是否真的被挑起来。

这套结构是后续“浮空连击、断限追击、Boss 保护槽”的基础。普通玩家可以地面立回通关，高手玩家可以研究如何把 Boss 留在空中。

## 4. 资源目录规范

所有竖切专用资源放在：

```text
WheatearEditor/assets/vertical_slice/
```

当前目录：

| 目录 | 内容 |
| --- | --- |
| `vn/portraits/` | VN 立绘和表情差分 |
| `vn/backgrounds/` | VN 背景 |
| `side_combat/characters/` | 横板玩家角色 |
| `side_combat/enemies/` | 横板敌人和 Boss |
| `side_combat/effects/` | 攻击、魔法、支援、敌人特效序列帧 |
| `side_combat/ui/` | 材料、魔剑、UI 图标 |
| `data/` | 竖切资源清单和后续数据输入 |

资源清单：

```text
WheatearEditor/assets/vertical_slice/data/vertical_slice_manifest.json
```

正式横板战斗调参表：

```text
WheatearEditor/assets/vertical_slice/data/side_combat_tuning.yaml
```

人类手动调参优先改 `side_combat_tuning.yaml`，不要直接改 C++：

- `player`：玩家移速、一段跳高度、重力、空中控制、普攻 / 上挑 / 魔法 / 支援 CD、连招窗口。
- `combat`：连击保留时间、受击无敌、防御减伤公式、最小伤害。
- `airCombo`：空中动作次数、跳斩 CD、空中追斩 CD、断限冷却、断限窗口、低空威胁线、高空安全线。
- `protection`：Boss 保护条上限、保护衰减、满槽脱离时间、断限压回保护条、保护 HUD 调试开关。
- `enemy`：敌人追击速度、攻击距离余量、Boss 血量阶段、冲撞和震波触发距离。
- `pickup`：掉落拾取半径、吸附半径、吸附速度。
- `movement`：纵深边界、纵深速度、排序尺度。
- `visuals`：脚下阴影透明度和浮空淡出。
- `reactions`：Boss 受击浮空修正。
- `attacks`：每个招式的判定大小、偏移、伤害、硬直、浮空力度、特效序列帧、帧率。
- `skills`：技能定义，记录技能名、输入、连招职责、关联攻击 ID、首次解锁章节和是否核心动作。
- `progression.profiles`：章节解锁配置，按 `LevelId` 决定本场战斗开放哪些技能、哪些机制可见、哪些后期能力仅供开发调试。

调跳跃高度优先改：

```yaml
player:
  jumpImpulse: 7.8
  gravity: 20.0
```

`jumpImpulse` 越高，起跳越高；`gravity` 越高，下落越快。竖切仍保持常规一段跳，未来只有“断限追击”会临时刷新空中行动。

运行时读取规则：

- 编辑器或直接运行 Sandbox：战斗场景启动时读取工程内的 `side_combat_tuning.yaml`。
- 打包开发版：打包器会把调参表同时写入 `content.wtpack`，并复制一份 loose 文件到 `Builds/Windows/Player/assets/vertical_slice/data/side_combat_tuning.yaml`。
- 打包运行时优先读取 loose 调参表；没有 loose 文件时才读取包内资源。
- 调参缓存会检查文件修改时间。改表后重进战斗场景即可稳定生效；攻击判定类参数会在下一次生成攻击时读取到新值。

第二章竖切的机制开放边界：

- `breakLimitEnabled: false`，断限追击不作为第二章正式玩法开放。
- `breakLimitDebugKeyEnabled: false`，避免全局绕过章节配置。
- `progression.profiles.CH02_MAIN_BearAwakening.debugSkills: [break_limit]`，只在第二章竖切 profile 下保留 `L` 键方便开发测试断限底层逻辑。
- `showBreakLimitHint: false`，默认不向玩家提示断限。
- `showBossProtectionHud: false`，默认不把 Boss 保护条显示成正式 UI。
- `showCombatStateHud: false`，默认不显示 Boss 内部运行状态。
- Boss 保护条仍然在后台运行，用来防止教程 Boss 被无限浮空；第六章再显性教学保护条，第七章再正式开放断限追击。

当前 profile 规划：

| Profile | 章节 | 正式开放 | 隐藏调试 | 机制显示 |
| --- | --- | --- | --- | --- |
| `CH02_MAIN_BearAwakening` | 第二章 | 三段斩、跳斩、上挑、空中追斩、火球、真青梅支援 | `break_limit` | 不显示保护条，不提示断限 |
| `CH02_MAT_BeastPath` | 第二章材料本 | 同第二章主线 | `break_limit` | 不显示保护条，不提示断限 |
| `CH06_MAIN_MageLair` | 第六章 | 基础技能 | 无 | 显示 Boss 保护条 |
| `CH07_MAIN_PalaceAssault` | 第七章 | 基础技能 + 断限追击 | 无 | 显示 Boss 保护条，提示断限 |

后续替换正式美术时优先保持同名同路径，避免重新改场景、脚本和打包引用。

## 5. 临时美术生成

VN 临时素材由脚本生成：

```text
tools/vertical_slice/generate_vertical_slice_assets.py
```

正式横板战斗临时素材由脚本生成：

```text
tools/vertical_slice/generate_side_combat_assets.py
```

用途：

- 提供可运行、可打包、可替换的占位 PNG。
- VN 立绘提供 `neutral / happy / serious / surprised / thinking` 五种表情。
- 横板战斗提供玩家、Boss、小怪、战斗带背景、脚下阴影、技能特效序列帧、掉落图标。

注意：

- 这些图是程序化占位图，不是最终美术质量。
- 生成脚本保留在工程内，是为了保证任何人能重新生成同一批临时资源。

## 6. 当前实现边界

已实现：

- 正式横板战斗模块骨架。
- 横向推进、纵深走位、一段跳、普攻、上挑、魔法、支援。
- 空中 `J` 已拆为基础跳斩 `air_basic`，地面 `J` 仍是三段斩。
- 空中 `K` 已拆为 `air_chase`，地面 `K` 仍是裂空上挑。
- 竖切断限测试键 `L` 已接入：满足连击和下落窗口时，刷新一次跳跃和空中动作次数。
- 空连高度资源已接入：空中命中会维持连招但逐步下坠；低空空连可被地面怪打断，高空空连可避开普通地面怪。
- 浮空控制规则已接入：非霸体敌人被击飞后，在落地前不移动、不攻击，保持受击表现；未来只有明确配置的空中反击 / 霸体技能可以例外。
- 受控状态机已接入：`Normal / HitStun / Launched / Knockdown / Recovery / SuperArmor / Broken / Dead`。
- Boss 隐藏保护条已接入：玩家连续控制 Boss 会积累保护，满槽后 Boss 强制脱离连击并进入短暂保护恢复。
- 魔剑槽已接入：命中可回复魔剑槽，断限调试键会消耗魔剑槽。
- 断限追击已做成可配置机制：正式开关、调试键、UI 提示和保护 HUD 分离，便于按章节解锁。
- 章节 / 技能解锁数据层已接入：运行时按 `SideCombatLevelComponent.LevelId` 查 `progression.profiles`，未解锁技能不会响应输入，调试技能可用但不会进入玩家 HUD。
- 三维判定模型：X 距离、纵深距离、空中高度区间。
- 攻击特效序列帧播放。
- 伤害、防御、硬直、浮空、连击计数。
- Boss 基础三阶段倾向：普通爪击、中血震波、低血冲撞。
- Boss 死亡掉落材料，材料向玩家吸附。
- 掉落拾取会写入 `GameProgress`，据点可以读取真实材料数量。
- 胜利结算会记录首通/重刷经验、最佳连击、剧情标记和黑林兽道解锁。
- `Progression` 竖切内存进度已接入：等级、经验、属性、材料、通关记录、魔剑 Lv2、旅人护衣 +1。
- 据点 UI 会读取 `GameProgress` 刷新当前目标、材料、属性、按钮状态和升级结果。
- 据点技能按钮会通过 `progression:upgrade_magic_sword` 消耗黑熊材料升级魔剑 Lv2。
- 据点装备按钮会通过 `progression:upgrade_traveler_armor` 消耗兽类材料强化旅人护衣 +1。
- 胜利后跳转据点 UI。
- 据点 UI 可重刷当前战斗或继续到第三章预告。

暂未实现：

- 真正持久化存档，当前进度只在本次运行中保留。
- 完整背包、装备实例、词条、装备页和技能树页。
- 多房间材料副本。
- 断限追击完整正式内容，包括断限失败惩罚、连续断限递增难度、章节解锁演出和正式教学流程。
- 敌人配置表自动导入。

这些不应继续塞进 `SideCombatSystem`，后续应拆到：

| 未来模块 | 计划职责 |
| --- | --- |
| `Inventory` | 材料、装备实例、掉落入包 |
| `Progression` | 等级、经验、魔剑技能树 |
| `Relationship` | 好感、支援技能等级 |
| `Hub` | 据点面板、路线确认、重刷副本 |

## 7. 打包要求

打包入口仍建议使用：

```text
assets/scenes/VisualNovelMainMenu.wt
```

打包器会从入口场景递归解析：

- `.wt` 场景。
- `.vn` 剧本。
- `.json` 数据。
- `assets/...` 资源引用。
- `{expression}` 这类模板立绘引用。

因此竖切资源不要手动复制进 `Build/assets`，应由 `.wtpack` 根据引用自动收集。
