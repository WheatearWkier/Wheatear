# 《Wheatear 异世界项目》竖切实现清单 v0.2

## 0. 文档定位

本文档负责把当前企划拆成第一个可玩竖切版本的工程计划、内容范围、数据资产、里程碑和验收标准。

竖切版本目标不是做完整游戏，而是证明以下闭环真实可用：

`主菜单 -> VN 剧情 -> 第一章假玩法 -> 第二章正式横板战斗 -> Boss -> 掉落结算 -> 据点 UI -> 装备 / 技能强化 -> 重刷副本 -> 继续剧情 -> 打包运行`

只要这条链路跑通，后续扩章节、角色、美术和 Boss 就有稳定底座。

| 模块 | 内容 |
| --- | --- |

- 全 60 个魔剑技能。
- 全部圣兽试炼。
- 七大罪战场。
- 国师最终战。
- 可探索据点。
- 复杂 AI 行为树编辑器。

## 2. 推荐工程边界

### 2.1 引擎核心

引擎核心只提供通用能力：

- 场景。
- 实体和组件。
- 渲染。
- 输入。
- 音频。
- 资源。
- 序列化。
- UI。
- 打包。

不把具体游戏规则塞进核心 `Systems`。

### 2.2 游戏模块

建议保持如下模块边界：

| 模块 | 职责 |
| --- | --- |
| `VisualNovel` | VN 对话、选项、场景跳转 |
| `ArcadeCombat` | 第一章假玩法 |
| `SideCombat` | 正式横板战斗 |
| `Progression` | 等级、经验、魔剑、技能树 |
| `Inventory` | 材料、装备、掉落 |
| `Relationship` | 好感、支援、角色事件 |
| `Hub` | 据点 UI 和流程 |

如果代码层现在还没有这些模块，竖切阶段可以先用较薄的数据结构和服务类实现，但命名和职责要按这个方向走。

### 2.3 建议目录

```text
Wheatear/src/Wheatear/Modules/SideCombat/
Wheatear/src/Wheatear/Modules/Progression/
Wheatear/src/Wheatear/Modules/Inventory/
Wheatear/src/Wheatear/Modules/Relationship/
WheatearEditor/src/Modules/Hub/
WheatearEditor/src/Modules/Dungeon/
WheatearEditor/src/Modules/Inventory/
```

注意：

- `Systems` 目录只放游戏引擎必须的基础系统。
- VN、假玩法、正式横板、装备、好感、据点都属于可选游戏模块或编辑器工具模块。

## 5. 里程碑

### M0：数据骨架

目标：

- 确定数据结构。
- 能加载基础 JSON / YAML / 内置表。
- 能保存最小存档。

验收：

- 能读取一个副本定义。
- 能读取一个敌人定义。
- 能读取一个掉落表。
- 能保存章节标记、材料数量、已解锁技能。

### M1：VN 与场景跳转

目标：

- 主菜单进入序章。
- VN 对话、选项和场景跳转稳定。
- 第一章假玩法可从 VN 进入，再返回 VN。

验收：

- 新游戏能完整走到第一章假玩法。
- 假玩法结束后能写入剧情标记。
- 能跳到第二章魔剑觉醒 VN。

### M2：SideCombat 最小战斗

目标：

- 建立正式横板战斗最小模块。
- 主角能移动、一段跳、闪避、普攻。
- 敌人能受击、死亡、掉落。

验收：

- 主角不会穿地或卡死。
- 小怪可被普攻击杀。
- 上挑能造成浮空。
- 跳跃后按 `J` 能打出基础跳斩，并能接在上挑后维持浮空。
- 火球能补 hit 或打断远程。

### M3：教程副本和黑熊 Boss

目标：

- 完成 `CH02_MAIN_BearAwakening`。
- 做出黑熊丈夫三阶段 Boss。
- 做出基础结算。

验收：

- 玩家能按教程完成移动、跳跃、闪避、上挑、跳斩、火球。
- 黑熊丈夫有 P1/P2/P3 行为变化。
- 普通玩家用短空连和读招能打赢。
- Boss 死亡后掉落材料并触发结算。

### M4：掉落、背包、装备

目标：

- 材料进入背包。
- 装备进入背包。
- 装备可穿戴。
- 装备可强化到 +3。

验收：

- 打完 Boss 能获得初级魔核和装备。
- 据点能显示材料数量。
- 穿戴装备后属性变化。
- 强化装备消耗材料并提升属性。

### M5：魔剑技能树简版

目标：

- 做出 6-8 个基础技能节点。
- 技能可通过材料解锁。
- 技能解锁后能在战斗中使用或生效。

验收：

- 玩家可用材料把魔剑升到 Lv2 或 Lv3。
- 缺材料时显示缺什么和去哪刷。
- 解锁技能后快捷栏或战斗行为更新。

### M6：据点 UI 闭环

目标：

- 战斗结算后回据点。
- 据点能继续剧情、进副本、强化装备、解锁技能。

验收：

- 打完第二章主线后回据点。
- 可从据点进入黑林兽道。
- 黑林兽道结算后回据点。
- 可从据点继续到第三章入口。

### M7：打包与运行

目标：

- 编辑器能把竖切项目打包。
- 打包只包含引用资源。
- `content.wtpack` 可被运行时加载。

验收：

- 打包目录不复制整个 `assets`。
- 包内包含 VN、场景、贴图、音频、数据表、字体、UI 图标等引用资源。
- 打包后的 `WheatearSandbox` 能从主菜单跑完整竖切。
- 无脚本路径、资源路径、中文路径崩溃。

## 6. 系统依赖顺序

推荐先后顺序：

```text
Data / Save
-> VN Scene Flow
-> SideCombat Player Controller
-> Enemy / Hit / Damage
-> Dungeon / Room Flow
-> Loot / Inventory
-> Hub UI
-> Skill Unlock
-> Equipment Enhance
-> Package Smoke Test
```

原因：

- 没有数据和存档，后面所有系统都无法串起来。
- 没有战斗最小闭环，装备和技能没有验证场景。
- 没有掉落和据点，副本重刷没有意义。
- 没有打包验证，就不能证明编辑器能产出游戏。

## 7. 验收用玩家流程

最终竖切验收时，按这个玩家流程测试：

1. 启动打包后的游戏。
2. 进入主菜单。
3. 点击新游戏。
4. 看完序章上学路。
5. 进入异世界第一章假玩法。
6. 假玩法结束后主角吐槽。
7. 假青梅被大魔法师掳走。
8. 进入第二章，导师送魔剑。
9. 按教程学习正式横板战斗。
10. 击败黑熊母熊。
11. 魔剑吸收材料。
12. 黑熊丈夫登场。
13. 击败黑熊丈夫。
14. 进入结算页面。
15. 获得材料和装备。
16. 回到据点 UI。
17. 解锁或升级一个魔剑技能。
18. 穿戴或强化一件装备。
19. 进入黑林兽道重刷。
20. 结算后回据点。
21. 点击继续剧情进入第三章入口。

只要这 21 步全部稳定，竖切就合格。

## 9. 风险和预案

| 风险 | 表现 | 预案 |
| --- | --- | --- |
| SideCombat 范围膨胀 | 一直想做更多技能和敌人 | 竖切只做 8 个技能和 1 个 Boss |
| 据点 UI 太复杂 | 页面多但流程跑不通 | 首页、结算、副本、装备、技能树优先 |
| 掉落系统太随机 | 玩家刷不到关键材料 | 首通关键材料必给，重刷做追求 |
| 好感系统过早展开 | 竖切内容被角色线拖慢 | 第三章前只预留入口 |
| 打包资源遗漏 | 打包后贴图或数据缺失 | 所有定义都带资源引用，打包前校验 |
| 战斗手感不足 | 空连不顺，玩家不爽 | 先打磨上挑、跳斩、火球、受击反馈 |
| 路径和中文资源问题 | 本机能跑，打包不能跑 | 竖切阶段就用中文场景和资源名做测试 |
