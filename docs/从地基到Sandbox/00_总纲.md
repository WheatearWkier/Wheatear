# Part 0 · 总纲：从地基到 Sandbox

> 本系列文档的目标：**从零讲解 Wheatear 引擎如何一步步构建出 Sandbox 演示及其中的全部玩法**。
> 它既不是 API 手册，也不是策划案——而是按「建造顺序」走的施工记录：
> 每一层解决什么问题、代码怎么走、美术素材从哪来、编辑器里怎么操作。
>
> 阅读方式：按 Part 顺序阅读。每个 Part 末尾有「当前状态」小结——
> 读完该 Part 时引擎应该具备的能力。代码路径均标注真实文件位置，可随时对照。

## 0.1 这个 Demo 到底是什么

Sandbox 是一个**可完整游玩**的 2D 竖切演示，跑通了一条完整游戏链路：

```
主菜单 → VN 剧情 → 假玩法 → 正式横板战斗 → Boss → 结算
      → 据点（技能树 / 装备 / 关系）→ 成长 → 继续剧情 → 存读档
```

它由 **22 个场景文件**（`Projects/WheatearDemo/assets/scenes/*.wt`）组成，
每个场景是一个 YAML 文件：实体、组件、层级关系全部序列化在其中。运行时
（`WheatearSandbox.exe`）从第一个场景开始，通过**事件脚本**（`.wts`）串起整个流程。

| 场景（节选） | 作用 |
| --- | --- |
| `VisualNovelMainMenu.wt` | 主菜单：开始 / 继续 / 设置 |
| `VerticalSliceIntro.wt` | 序章 VN：立绘、对话、分支选项 |
| `VerticalSliceFake.wt` | 假玩法段（过渡演出） |
| `SideCombatBeastPath.wt` | **核心展示**：横板战斗（主角 + Boss + HUD） |
| `VerticalSliceResult.wt` | 战斗结算 |
| `VerticalSliceHub.wt` | 据点：入口汇聚 |
| `VerticalSliceSkillTree.wt` / `Equipment` / `Relationship` | 成长系统 |
| `VerticalSliceSaveLoad.wt` | 存读档 |

## 0.2 三个运行时与一个编辑器

```
┌─────────────────────────────────────────────────────────┐
│  Wheatear（静态库）                                       │
│  渲染 / ECS / 资产 / 动画 / 输入 / 物理 / 玩法模块          │
├─────────────────────────────────────────────────────────┤
│  WheatearSandbox.exe      WheatearEditor.exe             │
│  独立运行器               编辑器（同样的引擎静态库）         │
│  · 加载 assets/ 数据       · 场景编辑 / 资产生产 / 调参     │
│  · 播放完整流程            · 导出 .wt / .wtsheet / .wtanim │
└─────────────────────────────────────────────────────────┘
```

关键设计：**游戏与编辑器共用同一个引擎静态库**。编辑器不是"另一套代码"，
而是引擎之上的一层 ImGui 面板——所以编辑器里看到的（动画预览帧、碰撞框跟随、
格子条带）就是运行时将要发生的，两套系统集共用同一份场景数据（详见 Part 3）。

**项目形态**：Wheatear 是面向弹幕/回合/战旗/横板格斗的轻量引擎——玩法模块
编译在引擎内（类似引擎插件），**项目 = 一个含 `assets/` 的目录**。编辑器
启动器可选择/新建项目（`Projects/<名>/`），命令行 `--project <目录>` 可
直接打开；引擎内置资源（shaders/字体）按引擎根解析，新项目无需复制
（详见 Part 4.7）。Sandbox 就是第一个项目（默认资产目录）。

## 0.3 美术素材从哪来

Sandbox 的全部视觉素材分四类，在 Part 13 详细展开：

| 来源 | 内容 | 处理方式 |
| --- | --- | --- |
| 程序化生成 | 部分图标、VFX、动作帧 | 脚本/代码生成，仓库内可重建 |
| GPT-Image-2 | 立绘、背景、UI sheet | 人工整理为图集 |
| 豆包生成 | 部分动作帧序列 | 抠图、排布成网格图集 |
| 引擎工具 | 图集网格定义 / 裁切 / 碰撞框 | 编辑器分割器产出 `.wtsheet` |

所有素材最终都变成**引擎资产**（PNG + `.wtsheet` 定义），不再以"散图"存在。

## 0.5 如何运行

```powershell
# 生成解决方案（premake5）
vendor\bin\premake\premake5.exe vs2022

# 构建编辑器（含引擎静态库）
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\Build-WheatearEditor.ps1

# 运行
bin\Debug-windows-x86_64\WheatearEditor\WheatearEditor.exe    # 编辑器
bin\Debug-windows-x86_64\WheatearSandbox\WheatearSandbox.exe  # 直接跑 demo
```

> 注意：编辑器与运行器的工作目录都是仓库根目录（资产路径按
> `assets/...` 相对根目录解析），所以从任意入口启动都能找到资产。
