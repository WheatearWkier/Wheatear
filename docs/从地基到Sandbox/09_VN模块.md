# Part 9 · VN 模块：剧本脚本、立绘、选项与存档

> 目标：理解视觉小说模块的数据驱动设计——剧本是文本资产、
> 运行时是解释器、编辑器是文本工具。结尾用一段真实剧本的
> 解析与播放走读收束。

## 9.1 剧本即文本：.vn 脚本格式

VN 剧本是**纯文本资产**（`assets/vn/*.vn`），不是场景文件。
看一段真实剧本（`intro.vn`，节选）：

```text
@label start
@background assets/sandbox/vn/backgrounds/bg_modern_schoolroad_morning.png
@music assets/sandbox/audio/bgm/vn_school_morning.wav "晨路微光"

@character Mira 青梅 assets/sandbox/vn/portraits/aoba_{expression}.png
@character Leo 主角 assets/sandbox/vn/portraits/protag_school_{expression}.png
@show Mira:smile Leo:neutral

Mira: 今天也一起走吧。你要是再赖床，我就把你的早餐拿去喂楼下的猫。
Leo: 你这人说话怎么总像在宣布命令。
Mira: 因为你总是要被命令才会动呀。
@expression Mira worried

@choice 进入第一章假玩法 -> event:go_fake_combat | 先吐槽两句 -> roast
@label roast
Leo: 等一下。为什么我的武器看起来像从隔壁小游戏借来的？
Mira: 也许这是命运给你的试炼。
@choice 行吧，先把假玩法打完 -> event:go_fake_combat
```

指令集（节选常用，完整列表见解析器 `VisualNovelScript.cpp`）：

| 指令 | 作用 |
| --- | --- |
| `@label name` | 定义跳转标签 |
| `@goto name` | 跳转到标签 |
| `@background path` | 切换背景（纹理路径） |
| `@music path "曲名"` / `@bgm path "曲名"` | 切换 BGM（`@music none` 停止） |
| `@character 名 显示名 模板` | 注册角色（`{expression}` 占位符） |
| `@show 名:表情 ...` | 立绘登场（表情模板替换） |
| `@hide 名` / `@hide all` | 隐藏立绘 |
| `@expression 名 表情` | 切换表情 |
| `@choice 文本 -> 目标 \| 文本 -> 目标` | 分支选项（支持 `if` 条件门控） |
| `@set 变量 = 值` / `@if 条件 -> 标签` | 变量赋值与条件跳转 |
| `@speed 值` | 文字速度 |
| `@end` | 剧本结束 |

编辑器当前把这些文本指令映射成结构化行。`VisualNovelScriptEditorPanel`
支持的行类型包括 Raw、Label、Background、Music/BGM、Speed、Character、
Show、Hide、Expression、Dialogue、Choice、Goto、End、Set、If、Sheet、
Char。新人可以这样理解：**常见剧情行用 Timeline 按钮建，暂时没有专门控件的
命令用 Raw 行保留原文**。保存后仍然是一份普通 `.vn` 文本，运行时解析器不需要
知道这行曾经是不是从编辑器按钮生成的。

**文本行的设计**：`Mira: 台词` 是"可见行"，`@` 指令是"控制行"。
所有 `@` 指令都是**数据**——运行时不认识"晨路微光"是什么曲子，
只执行"换 BGM + 显示曲名"；`{expression}` 模板让表情切换
零代码（`aoba_{expression}.png` → `aoba_smile.png`）。

## 9.2 运行时：解释器三件套

`Modules/VisualNovel/` 下三个角色：

- **VisualNovelScript**：解析器。把文本行解析成
  `VisualNovelLine` 结构（类型：Dialogue/Background/Choice/Character...），
  `GetLines()` 输出扁平指令流。**解析一次，播放读流**。
- **VisualNovelRuntime**：状态机。`Advance()` 推进当前行、
  `Choose(index)` 处理分支（TargetLabel 跳转）、`IsWaitingForChoice()`
  挂起等待。维护当前立绘/背景/音乐状态。
- **VisualNovelSystem**：桥接层。每帧采样输入（Part 1/7 的链路）、
  驱动 Runtime、把状态写入场景实体（立绘 SpriteRenderer、
  对话框 UIText、按钮 UIButton）——**VN 不自己画任何东西**，
  全部通过场景实体和组件表达。

`Advance()` 的核心（`VisualNovelRuntime.cpp`）：

```cpp
void VisualNovelRuntime::Advance()
{
    if (m_Finished) { Restart(); return; }
    NormalizeCurrentNode();                 // 处理标签跳转
    const VisualNovelLine* line = GetCurrentLine();
    if (!line) { m_Finished = true; return; }
    // ...按行类型执行：对话行推文本；指令行执行并继续推进...
}
```

## 9.3 立绘与表情：模板替换 + 动画优先

- 角色注册时给**纹理模板**：`aoba_{expression}.png`。
  表情切换 = `ResolveCharacterTexturePath` 替换 `{expression}`
  为表情名 → 加载 PNG（纹理缓存命中，Part 2）。
- **表情动画优先**（Part 6 提过）：如果立绘实体有名为 `smile`、
  `surprised` 的 `AnimationClip`，VN 优先播放 Clip；没有则回退
  静态 PNG 差分。**同一条 VN 指令，素材可以是图片也可以是动画**——
  玩法数据不变，表现升级零改动。

## 9.4 选项与条件显示

`@choice` 解析成 `VisualNovelChoice`（文本 + TargetLabel），
运行时 `IsWaitingForChoice()` 挂起 → 场景里生成按钮实体
（`UIButtonComponent`，Part 2 的 HUD 例子同款）→ 点击 →
`Choose(index)` 跳转。

选项还有**条件门控**（`CollectVisibleChoiceIndices`，
Part 1 端到端例子见过）：

```cpp
if (!choice.RequiredFlag.empty())
    visible = flags.count(choice.RequiredFlag) > 0;      // 剧情标记
else if (!choice.RequiredCondition.empty())
    visible = EvaluateVNExpression(choice.RequiredCondition, vars);  // 变量表达式
```

**剧情标记（StoryFlags）与全局状态（GameProgress）**跨场景共享
（Part 12 详讲）——VN 的选项结果影响战斗（好感→伤害），
战斗的掉落影响后续 VN 文本，数据全部走 `GameProgress::GetState()`。

## 9.5 存档

VN 的"当前进度" = 剧本文件路径 + 行号 + 状态变量快照。
存读档系统把 `VisualNovelRuntime` 的播放位置与 `GameProgress`
状态一起序列化（Part 12 的存档细节），竖切里有完整的
存/读/自动档 UI（`SaveLoad.wt`）。

## 9.6 编辑器：文本即工具

VN 剧本用**结构化行编辑器面板**（`VisualNovelScriptEditorPanel`）编辑：
Timeline 行列表（新增/删除/排序台词、BGM、选项、角色登场、隐藏、表情、
背景、标签、跳转、变量、条件、速度和结束命令）+ 行级编辑区
（说话人/台词/表情/路径/选项目标）+ Raw 文本预览 + 标签跳转。
保存后 **500ms 热重载**（Part 4 的降频表）——改一行台词，回到游戏下一句就是新的。
这就是"数据驱动"的日常形态：**没有 VN 编译器，只有解释器 +
文本工具**。

## 9.7 实例：一段剧本的播放走读

玩家在 `Intro.wt` 里点"开始"：

```
场景启动 → VisualNovelSystem::OnRuntimeStart
        → VisualNovelRuntime 加载 intro.vn（解析一次）
        → 执行 @label start / @background / @music / @character / @show
        → 立绘实体（Mira/Leo）出现，背景/BGM 就位
每帧：  OnUpdateRuntime → Sample 输入 → Advance 推进
        → 对话行：UIText 实体更新文本 + 打字机效果
        → @expression：表情模板替换纹理 / 播放表情 Clip
        → @choice：生成选项按钮 → 玩家点击 → Choose → 跳转标签
        → 第一个选项目标 event:go_fake_combat → CommandBus 切场景
```

> 面试可讲：剧本是数据不是代码（解释器 + 文本编辑器，热重载）；
> 表现层全部走场景实体（立绘/文本/按钮是组件不是 VN 私有绘制）；
> 跨场景状态（StoryFlags）与战斗/成长共享 GameProgress。
