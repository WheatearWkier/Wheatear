# 《Wheatear 异世界项目》角色好感路线与支援升级表 v0.1

## 0. 文档定位

本文档负责定义后宫角色的好感度、信赖阶段、角色事件、支援技能升级、魔剑技能门槛和战斗联动。

它承接以下既定规则：

- 主角单人主控，队友以头像和支援技能参与战斗。
- 好感度不是单纯剧情数值，而是战斗系统的一部分。
- 好感度主要通过剧情选择、角色事件和主线推进提升，不靠刷材料。
- 队友支援升级不消耗刷本材料。
- 青梅是正宫，其他异性队友进入后宫关系，最终不是互斥单女主路线。
- 普通玩家不用把所有好感刷满也能通关，但高好感会明显提高容错、连招上限和特殊解法。

## 1. 系统目标

好感系统要达到四个目标：

- 让玩家的剧情选择影响战斗手感。
- 让每名角色都有不可替代的战术价值。
- 让后宫关系不是只存在于文本里，而能在战斗 UI、支援技能、组合奥义和 Boss 解法里体现。
- 让玩家愿意看角色事件，但不把主线推进变成强制刷好感。

好感系统不做的事：

- 不做互斥女主线。
- 不用好感惩罚玩家战斗失败。
- 不让某个角色成为所有战斗唯一最优。
- 不把刷副本作为主要好感来源。

## 2. 核心变量

### 2.1 RelationshipState

| 字段 | 说明 |
| --- | --- |
| `CharacterId` | 角色 ID |
| `Affection` | 0-100 的好感值 |
| `BondStage` | 当前信赖阶段 |
| `SupportLevel` | 支援技能等级 |
| `EventFlags` | 已完成角色事件 |
| `RouteFlags` | 路线标记 |
| `HaremConfirmed` | 是否确认后宫关系 |
| `SupportUnlocked` | 支援技能是否可用 |
| `UltimateUnlocked` | 终极支援或组合奥义是否可用 |

### 2.2 好感阶段

| 好感 | 阶段 | 剧情含义 | 战斗解锁 |
| --- | --- | --- | --- |
| 0-29 | 相识 | 认识但未完全信任 | 支援 Lv1 |
| 30-59 | 信赖 | 愿意把力量交给主角 | 支援 Lv2 |
| 60-79 | 联动 | 与魔剑技能产生共鸣 | 支援 Lv3，魔剑联动技能门槛 |
| 80-99 | 誓约前 | 开始影响断限、Boss 机制和特殊战斗台词 | 支援 Lv4 |
| 100 | 后宫确认 | 关系确认，进入最终队伍体系 | 支援 Lv5，终极支援或组合奥义 |

### 2.3 支援数值公式

沿用战斗文档公式：

```text
SupportPowerRate = 1.00 + Affection * 0.003
SupportCooldownRate = 1.00 - Affection * 0.002
```

示例：

| 好感 | 支援强度 | 冷却倍率 |
| --- | --- | --- |
| 0 | 100% | 100% |
| 30 | 109% | 94% |
| 60 | 118% | 88% |
| 80 | 124% | 84% |
| 100 | 130% | 80% |

支援等级提供的是机制升级，公式提供的是数值平滑成长。

## 3. 好感来源

| 来源 | 建议数值 | 说明 |
| --- | --- | --- |
| 主线首次相遇 | +10 到 +20 | 角色加入时给基础值 |
| 关键剧情选择 | +3 到 +8 | 体现玩家态度 |
| 角色事件完成 | +8 到 +15 | 主要好感来源 |
| 对应章节 Boss 首通 | +5 到 +10 | 角色并肩作战成果 |
| 圣兽试炼首通 | +15 到 +25 | 对应角色大幅推进 |
| 后宫确认事件 | 直接补到 100 或解锁上限 | 终盘关系确认 |

不建议：

- 重刷普通副本直接给好感。
- 用材料购买好感。
- 用装备词条提高好感值。

可以保留：

- 首次完成某个角色专属副本给好感。
- 特定副本中完成保护、连携、救援等副目标给一次性好感。
- 据点角色事件根据前置战斗和剧情标记解锁。

## 4. 支援槽与战斗调用

### 4.1 支援槽位

| 阶段 | 支援槽 |
| --- | --- |
| 第二章 | 导师提示 / 临时支援，不开放完整配置 |
| 第三章 | 1 个主动支援槽 |
| 第四章 | 2 个主动支援槽 |
| 第五章 | 3 个主动支援槽 |
| 第一部终章后 | 青梅正宫支援加入，可作为主动或被动支援 |
| 第十二章后 | 王妃 / 天使支援加入，可配置为终极支援 |

建议最终形态：

- 3 个主动支援槽：玩家手动按键调用。
- 1 个誓约被动槽：青梅或王妃可提供特殊被动，但同一时间只能装备一个。
- 1 个组合奥义槽：满足条件时触发，不占普通支援按键。

这样按钮不会爆炸，同时后期角色仍然有存在感。

### 4.2 调用规则

- 支援默认不打断主角当前动作。
- 支援可以在地面、空中、受击保护、技能后摇、断限窗口中调用，但不同支援有自己的限制。
- 攻击型支援必须提供硬直、补 hit、吸附、浮空、破防、减速中的至少一种。
- 防御型支援必须提供护盾、格挡、霸体、净化、复活、受身中的至少一种。
- 支援不能把敌人打到玩家追不到的位置。
- 支援对 Boss 的控制时间缩短，但必须保留连招接口价值。

## 5. 青梅 / 魔剑士导师

角色定位：

- 正宫。
- 魔剑来源。
- 第一部隐藏操盘者。
- 第一部终章 Boss。
- 第二部洗脑真相揭示后回归本性，成为主角最强精神和断限支援。

特殊规则：

- 青梅真实好感从开局就是满值，但前期被剧情伪装和身份隐藏锁住。
- 前期面板不显示“青梅好感”，只显示“导师信赖”或不显示数值。
- 她的支援成长不靠刷好感，而靠主线节点解锁。
- 第一部终章战胜她后，青梅正宫支援正式加入。

## 11. 组合支援与奥义

组合支援不宜太多，初版先做少数高价值组合。

| ID | 名称 | 条件 | 效果 | 用途 |
| --- | --- | --- | --- | --- |
| COMBO-WH-SH | 圣盾守护 | 白魔法 60 + 剑盾 60 | 护盾 + 格挡反击 | 普通玩家保命 |
| COMBO-BL-SH | 黑铁破阵 | 黑魔法 60 + 剑盾 60 | 聚怪后破防 | 高防敌人 |
| COMBO-WH-BL | 光暗束缚 | 白魔法 70 + 黑魔法 70 | 净化异常并定住敌人 | 法师和召唤物 |
| COMBO-OS-BL | 誓约黑印 | 青梅解锁 + 黑魔法 80 | 断限窗口延长并压制保护条 | Boss 高手路线 |
| COMBO-OS-AN | 誓约圣环 | 青梅 + 王妃 80 | 抵抗精神控制，复活后回槽 | 色欲、国师 |
| COMBO-FINAL | 五祝一闪 | 五位核心后宫满足条件 | 最终奥义收尾 | 国师最终战 |

组合奥义原则：

- 不要让组合奥义替玩家自动打完 Boss。
- 组合奥义应当从破防、空界连锁或最终阶段自然接出。
- 普通玩家可以用它作为安全收尾。
- 高手玩家可以用它追求高评分。

## 12. 据点 UI 表现

好感面板必须显示：

- 角色头像。
- 好感值。
- 信赖阶段。
- 当前支援等级。
- 下一阶段解锁内容。
- 当前可触发的角色事件。
- 与魔剑技能树的关联条件。

锁定内容要显示原因：

- 剧情未到。
- 好感不足。
- 角色尚未加入。
- 圣兽 / 天使祝福未获得。
- 前置事件未完成。

不要让玩家猜“为什么点不了”。

## 13. 竖切范围

第一个竖切只实现最小好感系统：

- 青梅导师提示，不显示完整青梅好感。
- 第二章中记录 `MentorTrustFlag` 和 `MagicSwordGivenFlag`。
- 据点 UI 预留好感入口，但可只显示“尚未有正式队友加入”。
- 第三章进入制作时，再完整开放白魔法队友好感和支援面板。

竖切数据：

| 字段 | 用途 |
| --- | --- |
| `Flag_MagicSwordGiven` | 魔剑已获得 |
| `Flag_MentorTutorialComplete` | 导师教程完成 |
| `Flag_CH02_BossDefeated` | 黑熊丈夫已击败 |
| `Support_MentorHintEnabled` | 导师提示可用 |
| `SupportSlotCount` | 当前支援槽数量 |

## 14. 数据校验规则

编辑器保存好感和支援数据时应检查：

- 每个支援技能必须绑定角色。
- 攻击型支援必须填写连招接口。
- 防御型支援必须填写触发窗口。
- 好感 60 以上的支援必须至少有一个机制升级，不只是加数值。
- 支援技能不能引用未加入角色。
- 组合支援必须检查所有前置角色和好感。
- 青梅正宫支援不能在第一部终章前正式显示。
- 王妃 / 天使支援不能在第十二章前完整开放。
- 好感事件不能用普通材料解锁。

## 15. 后续实现顺序

建议实现顺序：

1. 角色关系数据结构。
2. 支援技能定义。
3. 支援槽配置。
4. 战斗中支援调用。
5. 支援冷却和好感数值修正。
6. 据点好感面板。
7. 角色事件解锁。
8. 组合支援。
9. 终极支援和组合奥义。

竖切只需要做到第 1-5 步，并预留第 6 步 UI 入口。
