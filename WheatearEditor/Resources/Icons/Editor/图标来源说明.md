# 编辑器图标来源说明

- `Source/` 下的 SVG 源文件来自 Lucide 图标库，许可证见 `Source/LICENSE`。
- 当前 PNG 与 ICO 为 WheatearEditor 专用的统一风格栅格化资产，只用于编辑器界面和可执行文件图标。
- 这些资源不属于游戏运行素材，不放入 `WheatearEditor/assets/vertical_slice`。

## 2026-08 图标管线更新

- 全部图标由 `scripts/Generate-EditorIcons.ps1` 生成：从 Iconify API 拉取 Lucide SVG，
  内嵌 C# 距离场描边光栅化器转 96x96 PNG（浅色 #E6EDF3 描边适配深色主题；
  play/pause/step 用薄荷绿、stop 用珊瑚红保留运行状态语义）。
- 运行 `powershell -File scripts/Generate-EditorIcons.ps1` 可重新生成或扩充图标。
- 旧版深色图标（浅色主题遗留）已被覆盖；未用图标已删除。
