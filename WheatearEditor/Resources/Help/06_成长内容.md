# 成长内容（技能树 / 背包 / 装备）

打开：玩法 → Progression Content Editor。

默认清单是 `assets/gameplay/progression/progression_content.yaml`。运行时 `ProgressionContent` 先读这个 manifest，再加载其中列出的分文件；编辑器保存 manifest 或分文件后会触发运行时内容重载。

当前 Demo manifest 包含：

- `defaults`：初始技能、装备、材料、副本、剧情旗标和目标
- `materials` / `upgrades`：材料定义与装备升级配方
- `dungeons` / `dungeonRewardSummary`：副本、首通/重复奖励与结算摘要
- `relationships`：好感与支援数据
- `skillNodes`：技能树节点和坐标
- `equipmentSlots` / `equipment`：装备槽位与装备记录

## 技能树（skillNodes）

Skill Tree 页签：

- **Add Skill** 建节点（选中节点时生成 `<id>_child` 子节点并自动设父）
- 选中节点：Id（改名自动更新子节点）/ Name / Branch / Requirement / Unlock Chapter / Parent
- **拖拽节点**调整布局 → **Bake Layout To YAML** 写回坐标
- 重复 id 红色警告；缺 id 临时节点黄色警告；**Duplicate / Delete Selected**

## 装备与物品（equipment / materials）

Content 页签：Add Record / Duplicate / Delete；字段含名称、插槽、属性（Stats）、来源、图标、描述。图标字段走资源选择器和别名解析，打包器会沿引用收集。

## 副本（dungeons）

Name、章节、推荐等级、锁定/解锁状态、首通/重复奖励、解锁旗标、目标与通知。

## 默认状态（defaults）

初始技能（Initial Unlocked Skills）、初始装备/物品、初始副本、初始剧情旗标、主目标。

## 升级配方（upgrades）

Add Upgrade：消耗（Costs）、属性加成（Attribute Bonus）、解锁技能（Unlock Skills）。

> 保存后运行时数据自动重载，进播放即生效。
