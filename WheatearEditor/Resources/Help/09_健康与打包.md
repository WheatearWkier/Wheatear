# 项目健康与打包

## 项目健康检查

工具栏「项目健康」打开（12 个页签）：

- **Missing**：引用但找不到的资源
- **Asset Registry**：资源注册表（类型/UUID/引用/被引用）
- **Packed Assets**：打包闭包内的资源
- **Scene Links**：场景跳转目标 + 缺失跳转
- **Entity Bindings**：实体名 / UUID 绑定检查
- **System Bindings**：运行时系统所需绑定缺失检查
- **Unused Assets**：未使用资源
- **Parsed Text**：文本资源解析状态
- **Warnings**：警告汇总
- **Asset Hygiene 资源卫生**：Generate Cleanup Plan 生成清理计划 → Select/Apply（归档重复与废弃资源）；Duplicates 重复文件；Largest Files 大文件；Source Paths 硬编码路径
- **Alias Manifest**：别名编辑（改名自动重定向）
- **Source Sync**：源码与工程文件同步

顶部可设 Scan Scope（启动场景/脚本资产/未使用扫描）与 **Refresh** 重扫。

## 打包玩家 + 编辑器

工具栏「Package Player + Editor」：

1. 自动保存场景（有未保存先另存）
2. 弹窗只选 **Startup Scene**（路径须以 `assets/scenes/` 开头）
3. GUI 打包固定生成 Release 玩家包；命令行打包可用 `--configuration Debug|Release` 显式指定
4. 后台异步构建（Player Build 窗口显示状态）
5. 完成后 **Open Player Folder / Open Editor Folder**

> 打包期间工具栏按钮禁用；再次打包需等完成。
