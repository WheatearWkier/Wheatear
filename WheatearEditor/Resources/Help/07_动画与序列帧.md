# 动画与序列帧

## 序列帧选择器（分割器）

打开方式：
- 选中实体 → 工具栏「Sprite Sheet Picker」图标按钮（自动同步实体纹理）
- 资源浏览器**双击 `.wtsheet`**，或右键 → 「打开分割器」

操作：
- 顶部投放区**拖入纹理** → 调 Columns / Rows 切网格 → 点击格子选中（黄色框），序列帧青色预览
- 右列 Sequence：模式（Horizontal / Row Major / Vertical）、帧数、时长、Append 追加
- **Apply**：Apply To SpriteRenderer / Apply To UI Image / Replace Clip With Sequence（替换弹确认）/ Sync Texture From Target

## 可复用图集 (.wtsheet)

把网格定义存成资产文件，实体和动画只存**引用**（图集路径 + 格子号），运行时实时解析——**改网格，所有引用方下一帧自动更新**。

- 分割器底部 Reusable Sheet 区：输入路径 → **Save As Sheet** 保存；**Load Sheet** 重新载入
- 生成序列到动画时，若已绑定图集，每帧自动写入 `Sheet + CellIndex` 引用（改网格动画自动适配）

### 动画资产 (.wtanim)

- 动画编辑器 **Save Clip As** 导出 .wtanim 并自动绑定到当前实体
- 复用给其他实体：动画编辑器 **Load .wtanim**；或直接在 Inspector 的 Sprite Animator 组件里用 **「加载 .wtanim」** 字段快速绑定（选文件即绑定并播放）
- 资产浏览器中 .wtanim 显示**第一帧缩略图**

### 格子条带（Unity 式）

- 资源浏览器中 `.wtsheet` 缩略图右上角 **▸/▾** 展开：行内显示全部格子（缩略图+序号）
- 每个格子可**拖到视口** → 自动创建绑定该格子的精灵实体（选中状态）
- 右键 `.wtsheet` → 打开分割器 / 重命名 / 删除

## 内容裁切（trim）与真实尺寸

美术给的图集内容不在格子中央（如跳跃动画人物位置逐帧漂移），或形状变化（站立→躺下），直接播放会跳动、露白边。

### 内容裁切（逐格）

- 分割器「内容裁切」区点 **检测内容边界**：自动计算每格不透明内容包围盒
- 手动微调选中格的 左/上/宽/高；**重置裁切** / **清除全部裁切**
- 预览中：**紫色框 = 内容框**，**绿色框 = 碰撞框**
- 播放时按内容框裁剪：未锚定帧自动对齐（跳跃动画不跳）、无留白

### 像素/单位（PPU）

Sprite Renderer 组件 **Pixels Per Unit**：
- `0` = 旧行为（quad 1×1×缩放）
- `>0` = 按真实内容尺寸渲染（内容像素 ÷ PPU），动画播放时**每帧尺寸自动跟随内容**（站姿高瘦、躺姿矮宽）

建议先定 PPU（如 100 像素 = 1 单位）再调格子，动画与碰撞全部自洽。

### 碰撞跟随动画

- 分割器每格可勾选 **碰撞框** 并微调（默认 = 内容框）
- 实体 Box Collider 2D 勾选 **跟随动画**（需 PPU > 0）：静态精灵和动画精灵每帧按格子碰撞框更新——人倒地碰撞盒跟着变，不会穿模

## 动画编辑器

选中带 **Sprite Animator** 组件的实体即绑定（否则提示选择实体）。

- 工具条：Play On Start / Fire Events；**+ Add Clip**（自动命名）；clip 下拉；重命名（回车生效）；**Delete Clip**
- 播放：**> Play / || Pause / [] Stop**（面板聚焦时空格切换）；Loop；Set Default / Clear Default

### 时间线

- 标尺拖拽=滚动播放头；Ctrl+滚轮缩放；Zoom 滑条
- **Frames 帧轨道**：每帧一格显示纹理缩略图，当前帧绿色高亮
- **Events 事件轨道**：双击空白=添加事件；拖拽移动；右键编辑（Time/Name/Command，命令如 `anim:play:@UUID:attack`）
- **属性轨道**：双击空白=加关键帧；拖拽横向移动；右键编辑（Time/Value/插值模式 Linear/Step/Ease*）

## 综合示例：从图集到带动画的角色

1. 资源浏览器拖入序列帧纹理 → 工具栏打开序列帧选择器 → 切好网格
2. **Save As Sheet** 存为 `assets/sprites/hero.wtsheet`
3. 点**检测内容边界**（内容不齐时）→ 调好碰撞框 → 再 Save
4. 场景新建实体：Sprite Renderer（设 PPU）+ Sprite Animator
5. 分割器选好序列 → **Replace Clip With Sequence**（帧自动带 sheet 引用）
6. 动画编辑器 **Save Clip As** 导出 hero_run.wtanim
7. 其他实体复用：Inspector Sprite Animator → **加载 .wtanim** 选 hero_run.wtanim
8. Box Collider 2D 勾**跟随动画** → 播放：尺寸、碰撞盒全部跟帧走
9. 以后改网格/裁切 → 重存 .wtsheet → 所有实体与动画实时更新
