# 动画与序列帧

## 动画编辑器

选中带 **Sprite Animator** 组件的实体即绑定（否则提示选择实体）。

- 工具条：Play On Start / Fire Events；**+ Add Clip**（自动命名）；clip 下拉；重命名（回车生效）；**Delete Clip**
- 播放：**> Play / || Pause / [] Stop**（面板聚焦时空格切换）；Loop；Set Default / Clear Default
- **Save Clip As** 存 .wtanim 到 assets/animations/；**Load .wtanim** 载入

### 时间线

- 标尺拖拽=滚动播放头；Ctrl+滚轮缩放；Zoom 滑条
- **Frames 帧轨道**：每帧一格显示纹理缩略图，当前帧绿色高亮
- **Events 事件轨道**：双击空白=添加事件；拖拽移动；右键编辑（Time/Name/Command，命令如 `anim:play:@UUID:attack`）
- **属性轨道**：双击空白=加关键帧；拖拽横向移动；右键编辑（Time/Value/插值模式 Linear/Step/Ease*）

### 图集生成器（下方折叠区）

从资源浏览器**拖纹理**进去 → Cols/Rows/Start/Frame Count/Dur → **Generate Frames**。

## 序列帧选择器

打开：工具栏「序列帧选择器」。

- 左列大图预览：点击格子=选中（黄色框）；序列帧青色预览；顶部投放区拖入纹理
- 右列参数：Columns / Rows / Zoom / Top-origin rows；Sequence：模式（Horizontal / Row Major / Vertical）、帧数、时长、Append 追加
- **Apply 操作**：Apply To SpriteRenderer（写入选中格纹理+UV）/ Apply To UI Image / Replace Clip With Sequence（替换弹确认）/ Sync Texture From Target
