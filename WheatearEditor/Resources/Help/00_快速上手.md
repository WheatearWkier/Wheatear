# 快速上手

## 启动

运行编辑器后，启动画面选择模式与项目：

- **2D 模式**（主路径）：精灵、物理、动画
- **3D 模式**：网格、PBR / IBL、光照
- **项目**：显示当前项目目录；`Projects/` 下的项目可一键切换；
  输入名字点「创建」新建项目（自动生成 `assets/scenes/Start.wt` 模板场景）

命令行方式：

```powershell
WheatearEditor.exe --project <项目目录>       # 直接打开指定项目
WheatearSandbox.exe --project <项目目录>      # 从引擎仓库直接运行项目（loose 资产）
```

项目 = 一个含 `assets/` 的目录。引擎内置资源（shaders/字体）按引擎根
解析，新项目无需复制；项目内同名资产可覆盖内置资源。

## 界面布局

| 区域 | 内容 |
|---|---|
| 顶部菜单栏 | 场景 / 编辑 / 运行 / UI / 窗口 / 玩法 / 资源 / 构建 / 诊断 / 应用 / 帮助 |
| 悬浮工具栏 | 新建/打开/保存 ｜ 播放/暂停/步进/聚焦 ｜ 内容工具 ｜ 健康/打包/重置布局/内容抽屉 |
| 左侧 | 场景层级 |
| 右侧 | 属性 + 统计/玩家构建 |
| 底部 | 资源浏览器 |
| 中央 | 视口 + UI 画布编辑器 |

「窗口」菜单可弹出/停靠任意工具；「重置窗口布局」恢复默认。

## 全局快捷键

- Ctrl+N / O / S / Shift+S：新建 / 打开 / 保存 / 另存为场景
- Ctrl+Z / Ctrl+Y：撤销 / 重做
- Ctrl+Enter：播放 / 停止；F6 暂停；F7 单帧步进
- F：聚焦选中；Ctrl+D：复制实体；Delete：删除实体
- Q / W / E / R：gizmo 无 / 移动 / 旋转 / 缩放（Ctrl 吸附）
- Esc：关内容抽屉 → 退出播放 → 取消选择
- 视口：Alt+左键旋转 / Alt+中键平移 / Alt+右键缩放；按住右键飞行（WASD+QE）

> 输入框激活时快捷键自动让路，不会误触删除/保存。

## 资源浏览器要点

- 图片显示真实预览；场景/预制体/UI 模板/模型自动渲染离屏缩略图
- 双击：目录进入 / 场景打开 / 预制体实例化 / .vn/.wts 打开编辑器
- 右键：打开 / 复制路径 / 重命名(F2) / 删除(Del 带确认)
- 键盘：Enter 打开、Backspace 后退、F2 重命名
- 拖拽到视口或动画图集区；工具栏文件夹图标=内容抽屉
