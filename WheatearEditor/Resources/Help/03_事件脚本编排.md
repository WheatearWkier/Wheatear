# 事件脚本编排

打开：工具栏「事件脚本编辑器」；资源浏览器右键 →「New Event Script (.wts)」自动打开。

## 画布操作

- 右键/中键拖拽平移；Ctrl+滚轮缩放
- 单击节点选中（黄色高亮）；节点纵向连接，右侧显示源码行号
- If/EndIf 画金色分支框

## 节点调色板（在当前选择后添加）

- **Scene**：`scene:assets/scenes/xxx.wt` 场景跳转
- **Event Call**：调用其它事件
- **Set Flag**：`progression:set_flag FLAG_XXX`
- **Dungeon / Save**：副本 / 存档命令
- **Raw Command**：自由命令（带前缀补全）
- **Add Wait**：等待秒数
- **Add If / Add EndIf**：条件分支（条件构建器支持旗标/技能/副本/装备/章节等）

## 节点编辑

选中节点：Type 下拉可转换类型；Command 用命令构建器自动补全；Wait 显示秒数拖条。

行内按钮：Move Up / Down、**Wrap In If**（包一层条件）、**Insert EndIf After**、**Delete Node**（或聚焦时按 Delete 键）。

if/endif 不配对有自动修复：缺 EndIf 时「Append Missing EndIf」，多余时「Remove Unmatched EndIf」。

## 绑定与保存

Save Graph 写回 .wts；场景实体挂 **Event Script 组件**，填 Script Path 与 Start Event（如 `on_start`）。
