# 综合案例：构建一个 sandbox 级可玩 demo

> 从空场景开始，用纯编辑器操作做出「开场剧情（VN）→ 据点（技能树/背包）→ 战斗（SideCombat + WAO）」的完整闭环，全程不写代码。

## 第 1 步：场景骨架

1. Ctrl+N 新建场景，Ctrl+S 保存为 `assets/scenes/MyDemo.wt`
2. 层级右键创建：**Sprite**「Ground」（拖入地面图片）、**Sprite**「Player」、**Camera**「Main Camera」、**UI → Canvas**
3. 选中 Camera 勾选 Primary；Ctrl+Enter 播放确认画面

## 第 2 步：开场剧情（VN）

1. 玩法 → VN Script Editor；Script 字段输入 `assets/vn/my_demo_intro.vn` → Save 自动创建
2. Timeline 依次添加：**+ 角色**（hero 勇者）→ **+ 对白** → **+ 选项**（「出发冒险」/「先去商店」，可加条件）→ 各接 **+ 跳转 Goto** 指向 **+ 标签 Label** → **+ 结束 End**
3. Save；层级建「IntroTrigger」实体，Add Component 搜索 **Visual Novel**，Script Path 填脚本

## 第 3 步：据点与技能树/背包（Progression）

1. 玩法 → Progression Content Editor；文件列表选 `skillNodes` → **Skill Tree** 页签
2. **Add Skill** 建「基础剑术」「冲刺」「二段跳」；改 Name/Branch/Unlock Chapter；Parent 挂层级；**拖拽排布 → Bake Layout To YAML**
3. 选 `equipment`：Add Record 建「铁剑」（Slot weapon、Stats 攻击）与「治疗药水」（Slot item）
4. 选 `defaults`：Initial Unlocked Skills 加「基础剑术」、Initial Owned Equipment 加铁剑与药水；Save Manifest

## 第 4 步：事件编排（Event Script）

1. 资源浏览器右键 → **New Event Script (.wts)** 自动打开事件图
2. Add Event `on_start`；节点：**Set Flag**（`progression:set_flag FLAG_DEMO_STARTED`）→ **Add Wait** 0.5 → **Add If**（`flag FLAG_HUB_UNLOCKED`）→ 内加 **Event Call** → **Add EndIf** → **Raw Command**（`scene:assets/scenes/MyDemo.wt`）
3. Save Graph；Player 实体 Add Component 搜索 **Event Script**，填路径与 Start Event

## 第 5 步：战斗配置（SideCombat + WAO）

1. 调参（玩法 → Side Combat Tuning Editor）：Feel 手感、Attacks 伤害帧、Animations 输入 `player_attack` → **Add** → 拖序列帧图配图集、Skills 设输入
2. WAO（玩法 → WAO Action Editor）：Action Set 选 SideCombat → **New Action**（`side_attack`）→ **Edit Recipe**：Animation Id 填 `player_attack`、Effects **Add Damage** → **Run in Sandbox** 测试 → Save YAML
3. HUD（玩法 → Side Combat HUD Preset Editor）：Bindings 绑定实体名、Slots 绑技能按键；Save Preset
4. 场景建战斗区实体：Add Component **Side Combat Level**，填 Tuning/HUD 路径

## 第 6 步：串联闭环

VN 结局选项接 **+ 原始 Raw** 输入 `side:enter_battle` → 对话结束直接进战斗；战斗胜利后可用旗标/Progression 发奖（物品进背包）。

## 第 7 步：打包运行

工具栏「Package Player + Editor」→ Startup Scene 选 `MyDemo.wt` → Debug → Package → **Open Player Folder** 运行。

> 核心理念：所有内容都是数据（.wt/.vn/.wts/YAML/manifest），面板只是可视化编辑界面；保存即生效。
