# 场景搭建

## 基本流程

1. Ctrl+N 新建场景（有未保存修改会先询问）。
2. 层级窗口右键空白创建实体：
   - 创建空实体 / 2D Object（精灵、圆形）/ 相机 / UI（画布、面板、图片、文本、按钮、滑块…）/ 游戏模板
3. 选中实体 → 右侧属性：
   - 场景设置：Properties 顶部的 **存档策略** 控制本场景是否允许保存/读取、存档目录、自动读取槽位
   - 改名：Tag 输入框，或选中后按 F2 行内重命名（Enter 提交）
   - 加组件：Add Component 按钮（弹窗带搜索框，按分类分组）
   - 组件值修改支持 Ctrl+Z 撤销

## 层级操作

- ↑↓ 键移动选择；搜索框过滤；「UI」勾选只看 UI 实体
- UI 子节点可拖拽换父；每行 Hide/Show 按钮（编辑器隐藏）
- 右键实体：创建 UI / 重命名 / 隐藏显示 / 复制 / 另存为 Prefab / 另存为 UI 模板 / 删除

## 视口操作

- 单击选实体；双击聚焦；右键=创建实体菜单
- Q/W/E/R 切 gizmo；Ctrl 吸附（旋转 45°、移动/缩放 0.5）
- Alt+左/中/右键：旋转 / 平移 / 缩放相机；按住右键飞行
- Ctrl+Enter 播放，F6 暂停，F7 单帧，Esc 退出

## 存档策略

存档/读档是全局进度服务，不属于某一种玩法组件。每个场景都有自己的 Save Policy：

- **Can Save**：本场景是否允许保存。
- **Can Load**：本场景是否允许读取。
- **Save Directory**：剧情运行状态写入目录，默认 `assets/saves`。
- **Auto Load Slot**：进入场景后自动读取的槽位，0 表示不自动读取。

剧情、据点、菜单可以按需求开放；战斗中不允许存取时，直接在战斗场景关闭 Can Save / Can Load。
