# VN 剧情制作

打开：玩法 → VN Script Editor；或资源浏览器双击 .vn 文件。

## 新建脚本

工具栏 Script 字段输入新路径（如 `assets/vn/my_story.vn`）→ 点 Save，自动创建文件。

## 编辑时间线

Timeline 页签用顶部按钮在当前行后插入（自动选中新行）：

- **+ 对白**：Speaker 下拉（已有角色）+ 多行台词
- **+ 选项**：Prompt + 每选项 Text / Target（label 下拉）/ Required Flag / Required Condition
- **+ 角色**：Id、显示名、立绘样式（下拉选择）
- **+ 显示 / + 隐藏**：角色下拉（含 all）
- **+ 表情**：角色 + 表情下拉
- **+ 跳转 / + 标签**：目标标签下拉
- **+ 背景**：纹理资源字段
- **+ 变量 / + 条件**：如 `gold >= 5`、`not flag FLAG_X`
- **+ 速度 / + 图集 / + 角色格 / + 原始**：进阶行

行操作：Move Up / Move Down / Delete；悬空跳转目标显示黄色徽章。

## 绑定到场景

1. 层级创建实体（如 IntroTrigger）
2. Add Component 搜索 **Visual Novel** 组件
3. Script Path 填脚本路径，保存场景

> 运行时对话由组件驱动，保存即生效。

## 剧情与存档

VN 是一种玩法模块，负责对白、选项、立绘、历史、自动播放和剧情运行状态。是否允许玩家此刻保存/读取，由场景的 **存档策略** 决定，不写在 Visual Novel 组件里。

常见配置：

- 剧情场景：Can Save / Can Load 都开启，玩家可以随时存读。
- 战斗场景：Can Save / Can Load 都关闭，避免战斗中回滚进度。
- 据点或菜单：按流程开放保存、读取或只允许读取。
