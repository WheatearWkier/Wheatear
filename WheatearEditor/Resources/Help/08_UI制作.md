# UI 制作（画布编辑器）

## 创建 UI

层级右键 → **UI** 子菜单：

- Canvas 画布 → Panel 面板 / Image 图片 / Text 文本 / Button 按钮 / Slider 滑块 / Checkbox / Progress Bar / Scroll View / Path / Pager…
- Templates 子菜单：Titled Scroll Text、Paged Grid、Skill Button、Equipment Slot、Tooltip、Save Slot、Skill Tree Node…

## 画布编辑

工具栏「UI 画布编辑器」打开（或双击 UI 实体）：

- **单击选择**（按层级取最上层）；Alt 按住不选
- 拖拽移动/缩放：8 个方形手柄 + 中心移动区，自动联动锚点与归一化坐标
- 选中显示青色高亮 + 名称标签；光标自动变缩放/移动箭头
- 画布空白单击=清除选择
- 顶部：Use Selected Canvas 换画布；Undo/Redo（Ctrl+Z/Y）；Save 存场景
- **UI Edit Outlines**（菜单 UI 开关，默认开）：所有部件青色线框 + 名称标签，纯文本虚线框

## 运行时行为

- 面板/按钮/图片/进度条按组件颜色填充预览
- 文本字号随缩放自动适配；UI 组件支持动画（UI Animator：fade_in / slide_fade_in / result_pop / pulse…）
- 归一化坐标（0~1）保证不同分辨率布局一致
