# Fonts

`wqy-microhei.ttc` is the default packaged Chinese UI font for the vertical slice.

Source: WenQuanYi Micro Hei, from the WenQuanYi Project.

License files are stored under `assets/fonts/licenses/WenQuanYiMicroHei/`.
The upstream README states the font is licensed under Apache 2.0 or GPLv3 with font embedding exceptions.

`NotoSansSC-VF.ttf` and `Open-Sans-2.ttf` are kept as fallback fonts.
